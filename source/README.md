# source —— 原文

## ★ 这个目录是只读的 ★

全项目的事实基准。任何脚本都不许改这里的文件，任何下游产物有疑问一律回这里对。
原则二（严格遵守原文）的「原文」指的就是它。

| 文件 | 是什么 |
| --- | --- |
| `穿越后，系统变成白噪音了怎么办.txt` | 从 ixdzs8 抓下来的原始文本，GB18030 编码，5.5 MB |
| `novel.json` | 标准化产物，**1200 个分析单元**，后续一切的输入，9.0 MB |
| `novel.index.json` | 轻量目录：只有标题和字数，没有正文，0.3 MB |

做全书规划时**加载 `novel.index.json`**，它比 `novel.json` 小 30 倍，
只有真要读正文时才加载后者。

由 `pipeline/s1_normalize_novel.py` 从 txt 生成，字段含义见
[`../doc/09_数据字典.md`](../doc/09_数据字典.md) 第二节。

## 动手前必须知道

**全书不是 1232 章，是 1222 个章节标题、1200 个分析单元。**
作者自己有 14 处重号、5 处跳号，站点又把部分章节合并在一页。
所以主键是文件顺序 `seq`（1~1200），不是作者的章号——
按章号索引一定会错位。

**第 1115~1205 章之间有 41 章正文被截**，缺约 5.0 万字，影响第六季。
待补章号清单见 [`../doc/11_待补原文清单.md`](../doc/11_待补原文清单.md)。

两条的完整明细见 [`../doc/01_原文数据说明.md`](../doc/01_原文数据说明.md)。
