# 统一风格提示词：高质量 3D 国漫电影渲染

## 完整版

```text
整体采用高质量东方奇幻3D国漫院线电影渲染质感，成熟的电影级CG动画美术，精致而克制的中国古典审美。角色、建筑、山水和自然物采用风格化写实造型：比例可信，轮廓柔和优美，既有三维体积和真实空间关系，又避免照片般坚硬写实。材质细腻但不过度锐利，布料、木材、石材、青瓦、水面、云雾和植被具有清楚的材质差异；表面保留轻微动画化概括，不出现塑料、蜡像或廉价游戏建模质感。

使用院线动画电影级全局光照、物理可信的柔和光影、自然间接光、体积雾、空气透视、环境散射和精细轮廓光。明暗层次丰富，亮部带克制的柔和辉光，暗部保留细节，不死黑、不过曝。通过雾气、光线和色彩建立清晰的前景、中景、远景层次，远景适度柔化，主体轮廓明确。画面具有宽银幕电影构图、严谨透视、宏大空间尺度、明确叙事感和动画电影定帧美感。

色彩采用高级东方电影调色，根据场景形成冷暖对比与统一色调；颜色浓郁但不荧光、不脏乱，饱和度适中，人物、天空、山体和环境光相互协调。细节丰富、画面干净、边缘柔顺、抗锯齿良好，使用适度景深，呈现高预算、高完成度、精修级3D国漫电影画面。16:9横幅，超高清，高质量渲染，主体结构准确，构图稳定。

画面不是追求真人照片级真实，而是保留东方3D动画电影特有的柔化轮廓、概括纹理、梦幻空气透视和含蓄诗意；整体如高质量国漫电影中的场景定帧。

避免真人摄影感，避免二维平涂动漫，避免厚重油画笔触，避免儿童卡通、Q版、欧美卡通、低多边形、游戏截图、廉价CG、塑料材质、蜡像脸、过度磨皮、过度锐化、过度HDR、荧光色、杂乱构图、错误透视、重复物体、结构变形、模糊主体、噪点、压缩痕迹、文字、字幕、Logo、水印、边框和播放器界面。
```
