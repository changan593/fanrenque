# image-2.0 场景图片反推提示词

## 使用说明

- 全部原图均为 **2346×1320，约 16:9 横幅**。生成时选择最接近的 16:9 横图、高质量模式。
- 下列提示词按原图逐张反推，已把主体、机位、布局、色彩、光线和质感写进每条提示词，可直接单独使用。
- 文生图具有随机性，仅靠文字无法保证像素级一致。若系统支持参考图或“基于图片编辑”，请上传对应原图，并在提示词开头加：**“严格保持参考图的镜头位置、主体比例、空间布局和色彩分区，只重绘细节。”** 这是最接近一次生成成功的方法。
- 除《荷塘水乡全景》外，提示词默认不生成文字、水印、Logo、边框或播放器界面。
