# image-2 场景风格参考包

## 资产定位

这是一套用于《凡人阙》视觉开发的**候选风格参考资产**，包含：

- 20 张 16:9 东方奇幻三维动画场景参考图；
- 一份统一的高质量 3D 国漫电影渲染风格提示词；
- 20 张图片逐图反推的场景提示词。

它属于人工整理、无法由项目管线完整重建的资产，因此存放在 `production/style_assets/`，而不是可重新生成的 `data/`。

## 与现有风格规范的关系

本参考包**不是已经定稿的全片画风**，不会自动覆盖以下配置：

- `doc/04_风格规范.md`
- `doc/12_参考片画风研究.md`
- `production/style_test/matrix.json` 中的 S9～S11

现有项目总基调强调“朴素、克制、反奇观”。本参考包中的部分画面具有高饱和秋色、梦幻体积雾、强辉光、花瓣或宏大仙境，因此使用时应拆分取用：

- **可直接参考**：16:9 构图、远中近空间层次、东方建筑与自然景观、三维体积、动画电影材质、空气透视、冷暖光组织。
- **需按剧情控制**：强体积光、光晕、粒子、花瓣、星河、仙境奇观、高饱和色彩。
- **不得反向覆盖**：原文证据、角色身份、场景时代、光源出处、奇观额度和项目负面清单。

## 推荐使用顺序

1. 从 `images/` 选择构图、光线或空间气氛最接近目标场景的参考图。
2. 从 `场景反推提示词.md` 复制对应场景结构，删除与原文不符的内容。
3. 追加 `统一风格提示词.md` 中的风格段。
4. 再追加项目正式负面约束，并按 `doc/04_风格规范.md` 检查光源、磨损、朴素度和奇观额度。
5. 若图像模型支持参考图编辑，优先使用参考图锁定机位与构图；纯文生图不能保证像素级复刻。
