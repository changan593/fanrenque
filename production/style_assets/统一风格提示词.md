# 统一风格提示词：高质量 3D 国漫电影渲染

## 资产定位

本文件定义《凡人阙》**场景与环境的渲染方式**，回答的是"画面应该被怎样渲染出来"。
它不定义任何具体场景里有什么——建筑、山水、人物、动作、光源出处由分镜提示词和场景资产决定。

与同级的 `统一角色提示词.md` 是并列资产：

- 本文件负责建筑、山水、空间、构图、空气透视和环境光；
- `统一角色提示词.md` 负责人物骨相、皮肤、眼睛、头发、服装材质、表演和跨镜头身份稳定；
- 两者冲突时，不得以通用风格覆盖原文证据和已批准的角色身份母版。

**状态：已定稿。** 画风载体选型（`doc/04_风格规范.md` 待定项 A）已落槌为国风三维，
本文件是全片场景风格段的唯一来源。

## 完整版

```text
整体采用高质量东方奇幻3D国漫院线电影渲染质感，成熟的电影级CG动画美术，精致而克制的中国古典审美。角色、建筑、山水和自然物采用风格化写实造型：比例可信，轮廓柔和优美，既有三维体积和真实空间关系，又避免照片般坚硬写实。材质细腻但不过度锐利，布料、木材、石材、青瓦、水面、云雾和植被具有清楚的材质差异；表面保留轻微动画化概括，不出现塑料、蜡像或廉价游戏建模质感。

使用院线动画电影级全局光照、物理可信的柔和光影、自然间接光、体积雾、空气透视、环境散射和精细轮廓光。明暗层次丰富，亮部带克制的柔和辉光，暗部保留细节，不死黑、不过曝。通过雾气、光线和色彩建立清晰的前景、中景、远景层次，远景适度柔化，主体轮廓明确。画面具有宽银幕电影构图、严谨透视、宏大空间尺度、明确叙事感和动画电影定帧美感。

色彩采用高级东方电影调色，根据场景形成冷暖对比与统一色调；颜色浓郁但不荧光、不脏乱，饱和度适中，人物、天空、山体和环境光相互协调。细节丰富、画面干净、边缘柔顺、抗锯齿良好，使用适度景深，呈现高预算、高完成度、精修级3D国漫电影画面。16:9横幅，超高清，高质量渲染，主体结构准确，构图稳定。

画面不是追求真人照片级真实，而是保留东方3D动画电影特有的柔化轮廓、概括纹理、梦幻空气透视和含蓄诗意；整体如高质量国漫电影中的场景定帧。

避免真人摄影感，避免二维平涂动漫，避免厚重油画笔触，避免儿童卡通、Q版、欧美卡通、低多边形、游戏截图、廉价CG、塑料材质、蜡像脸、过度磨皮、过度锐化、过度HDR、荧光色、杂乱构图、错误透视、重复物体、结构变形、模糊主体、噪点、压缩痕迹、文字、字幕、Logo、水印、边框和播放器界面。
```

## 项目克制版追加约束

用于《凡人阙》正式镜头时，**必须**在完整风格段后追加（原则三「严禁浮夸」是硬约束，不是可选项）：

```text
服从《凡人阙》朴素、克制、反奇观的总体基调：所有光必须有明确来源，降低无依据的辉光、镜头光晕、粒子、花瓣、飘带和仙气；不过度美化人物，不使用统一网红脸；木石、布料与金属保留真实使用痕迹、磨损、灰尘和氧化；市井空间要有人间生活感，宗门庄重但不奢华；除原文明写的异境与天地异象外，不主动制造宏大仙境和高饱和奇观。
```

## 使用原则

- 本文件定义的是"如何渲染"，具体人物、场景、动作和光源仍由分镜提示词决定。
- **正式镜头 = 完整版 + 项目克制版追加约束**，两段缺一不可。只用完整版会出高饱和奇观画面，违反原则三。
- 与 `production/style_test/matrix.json` 的 S9～S11 关系：S9~S11 是**选型实验的候选项**，本文件是**选型结论**。
  两者措辞不同（S9 偏克制、本文件偏丰富），以本文件 + 克制版追加约束为准；matrix.json 保留作为选型留痕，不再作为生产依据。
- 与 `refs_场景参考_image2/` 的关系：那 20 张图是本风格段的**视觉锚点**，
  但其题材配比与本剧需求不符（市井 2 张、奇观 7 张，而 `doc/04` 第 5.2 节说市井是最重要的一档）。
  取其渲染质感，不取其题材倾向。
