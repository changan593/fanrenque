# image-2 场景风格参考包

## 资产定位

这是《凡人阙》画风载体的**视觉锚点包**：20 张 16:9 东方奇幻三维动画场景参考图，
外加 20 张图片逐图反推的场景提示词。

它属于人工整理、无法由项目管线完整重建的资产，因此存放在 `production/` 而不是可重新生成的 `data/`。

> **风格段不在这个目录里。** 从这批图里抽出的通用风格段已提升为项目级资产，
> 见上一级的 [`../统一风格提示词.md`](../统一风格提示词.md)。本目录只保留与这 20 张图绑定的东西。

## 与现有风格规范的关系

画风载体已定稿为国风三维（`doc/04_风格规范.md` 第 3.1 节），本参考包是那个决定的视觉依据之一。
但**参考图本身不是画风规范**，它不覆盖 `doc/04_风格规范.md`，也不覆盖 `../统一风格提示词.md`。

项目总基调是"朴素、克制、反奇观"。本参考包中的部分画面具有高饱和秋色、梦幻体积雾、强辉光、花瓣或宏大仙境，因此使用时必须拆分取用：

- **可直接参考**：16:9 构图、远中近空间层次、东方建筑与自然景观、三维体积、动画电影材质、空气透视、冷暖光组织。
- **需按剧情控制**：强体积光、光晕、粒子、花瓣、星河、仙境奇观、高饱和色彩。
- **不得反向覆盖**：原文证据、角色身份、场景时代、光源出处、奇观额度和项目负面清单。

## 推荐使用顺序

1. 从 `images/` 选择构图、光线或空间气氛最接近目标场景的参考图。
2. 从 `场景反推提示词.md` 复制对应场景结构，删除与原文不符的内容。
3. 追加 [`../统一风格提示词.md`](../统一风格提示词.md) 的**完整版 + 项目克制版追加约束**（两段缺一不可）。
4. 再追加项目正式负面约束，并按 `doc/04_风格规范.md` 检查光源、磨损、朴素度和奇观额度。
5. 若图像模型支持参考图编辑，优先使用参考图锁定机位与构图；纯文生图不能保证像素级复刻。

**配比与本剧需求是反的**：最高频的市井只有 2 张，且都是南方繁华城（朱红梁柱、银杏、红灯笼），
而第一季主场景北阳城是北方小城——土坯墙、参差灰瓦、破庙、码头。

所以：**这是渲染质量参考，不是场景覆盖参考。**
