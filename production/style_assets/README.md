## 一条镜头提示词是怎么拼出来的

越靠前优先级越高。任何一段都不得覆盖比它靠前的段。

```
1. 原文章节证据与当前镜头事实        ← 原则二，最高
2. 身份母版引用 + 身份一致性段        ← ../characters/CNN_角色名/00_身份母版/
3. 当前阶段允许变化项、服装、标志物    ← ../characters/CNN_角色名/NN_阶段名/
4. 画面内容：构图、景别、动作、表情、光源出处
                                     ← production/s01/prompts/EXX/NN_幕别_幕题.md
5. 统一角色提示词（完整版或短版）      ← 本目录
6. 角色卡 / 剧情镜头专用追加段         ← 本目录，二选一
7. 《凡人阙》项目克制版追加约束        ← 本目录，必须
8. 公共负面约束                       ← 本目录
9. 统一风格提示词（含环境时）          ← 本目录，完整版 + 克制版追加约束
```

第 4 步的画面内容层刻意**不含风格词**，见
[`../s01/prompts/00_总则与模板.md`](../s01/prompts/00_总则与模板.md) 第一节。
第 5~9 步由程序统一追加，所以风格段改一次全季生效，不必回改 12,958 条镜头提示词。

## 三条纪律

1. **不把某个角色的五官、服装或配色写进公共段。** 唐真的紫云袍、黑印、白色抹额只属于唐真的对应阶段卡。
2. **克制版追加约束不是可选项。** 原则三「严禁浮夸」是硬约束，正式镜头必须带。
   只用完整版会出高饱和奇观画面。
3. **参考图必须逐张声明职责。** 身份图、服装图、姿势图、风格图不得不加区分地混用；
   冲突时身份母版优先，禁止把不同参考图的脸混合成一张新脸。

## 加新资产包的规矩

放进 `refs_*/` 的每个参考包都要自带 `README.md`，写清四件事：

1. **来源**：谁做的、什么工具、什么时候归档的
2. **适用范围**：能取什么、必须按剧情控制什么、绝不能反向覆盖什么
3. **与正式规范的关系**：是锚点、是候选，还是已定稿
4. **覆盖缺口**：它覆盖不到的题材，明确列出来当待补清单

图片入库规矩沿用 [`../style_test/refs/README.md`](../style_test/refs/README.md) 第一节：
JPEG、长边 1080~1440、单张 ≤1 MB、不加滤镜不裁边。

**例外：角色卡 PNG 不压缩。** 角色卡是身份最高权威，卡上的中文标签、三视图和色板
需要原始分辨率，重压缩会毁掉判读依据。

**已入库的图不要回头重压。** 图片是二进制，改一次历史里就多存一份全量；
定规矩是给新图用的。
