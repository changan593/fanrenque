# 统一角色提示词：高质量 3D 国漫电影人物

## 资产定位

本文件定义《凡人阙》角色的**共同塑造方式、渲染方式和身份一致性规则**，回答的是“人物应该怎样被稳定地画出来”。它不定义任何具体角色的脸、服装、年龄、伤痕、饰品或剧情状态；这些内容必须来自角色深度档案、身份母版、阶段角色卡和当前镜头。

统一角色提示词与同级的 `统一风格提示词.md` 是并列资产：

- 场景统一风格负责建筑、山水、空间、构图、空气透视和环境光；
- 本文件负责人物骨相、皮肤、眼睛、头发、服装材质、表演和跨镜头身份稳定；
- 两者冲突时，不得以通用风格覆盖原文证据和已批准的角色身份母版。

## 完整版

```text
角色采用高预算中国3D动画院线电影的人物制作与渲染标准，整体为风格化写实、半写实比例和精致但略带动画化概括的东方脸部塑形。头骨、五官、身体结构、关节活动和服装受力遵循现实；造型轮廓清楚优美，但细节密度低于真人摄影，不追求真人演员、扫描人像或照片级毛孔。人物必须保持明确的东亚骨相与个体差异：眼裂、眼距、眉骨、鼻梁、面中、颧骨、下颌和下巴依据角色身份单独塑造，不套用统一网红脸、偶像脸或西式英雄模板。人物可以好看，但美感只能来自该角色已经批准的骨相和气质，不得自动磨皮、瘦脸、增大眼睛、垫高鼻梁、削尖下巴或抬高身材比例。年龄、阶层、劳作、伤病与生活状态要如实体现在皮肤、体态和衣物上，老人、普通人和疲惫者不得被无依据地年轻化、美化或贵族化。

使用物理材质渲染。皮肤具有细腻、克制、透光尺度正确的次表面散射，面部保留自然色差、眼下变化、唇色和轻微使用痕迹；不做蜡像、塑料、油亮磨皮，也不强化到真人摄影级毛孔、粉刺和汗毛。眼球结构与虹膜比例可信，角膜高光稳定，眼白不过亮，视线在所有角度准确一致；禁止玻璃眼、玩偶眼、发光眼、超大动漫眼和左右视线漂移。嘴唇、牙齿和口腔材质自然克制，笑容不得出现整齐发亮的广告牙。

头发采用电影动画可控的成束毛发：发际线、分缝、鬓角、束发根部、长度和整体轮廓稳定；大束、中束、小束层级清楚，有真实体积和重力。允许少量受控碎发，不做真人摄影式满头飞丝，不做二维块状头盔发、不做塑料雕刻发。胡须、眉毛和睫毛遵循角色年龄与原文，不自动添加或浓密化。

人体使用可信骨骼、肌肉和软组织结构。头身比、身高、肩宽、胸廓、腰胯、四肢长度、手脚尺寸必须服从角色身份资产；不统一拉成九头身，不展示健身海报式肌肉切割。站姿、重心和动作要符合人物的体能、伤势、职业和性格。双手结构完整，手指数量正确，握持关系与物体受力可信。

衣物版型遵循中国古代服装的交领、右衽、层次、系带与受力逻辑，具体朝代感和门派制式以项目设定为准。麻、棉、绢、丝、皮革、金属和木材必须有可辨认的粗糙度、织纹、厚薄、垂坠和反射差异；布料褶皱从肩、肘、腰带、膝和动作受力点自然产生。普通衣物保留合理的磨损、洗旧、灰尘、补丁和褪色，宗门服庄重但不过度奢华。除非原文明写，不自动增加金边、刺绣、铠甲、披风、珠宝、冠冕、武器、法器、飘带、发光纹样或仙气。

面部表演由真实肌肉和目光驱动。表情变化必须建立在同一张脸上，笑、怒、怀疑、疲惫和惊讶不能改变眼距、鼻型、脸宽、下颌和年龄。优先使用眼睑、眉头、嘴角、下颌张力和呼吸带来的微表情，不使用二维动漫符号、夸张鬼脸、偶像营业笑、邪魅歪嘴笑或欧美卡通式大幅拉伸。角色气质通过目光、重心、肩颈和动作节奏表达，不用无依据的光效代替表演。

使用院线动画电影级全局光照与物理可信的柔和光影。人物受光必须服从场景中的真实光源，肤色与衣物接受一致的环境色反弹；暗部保留结构，不死黑，亮部不过曝。轮廓光只在有明确逆光来源时出现，禁止常驻描边光、彩色边缘光和游戏角色选取光。景深、运动模糊与镜头畸变由当前分镜决定，不得为了“电影感”遮掉脸部身份特征。

画面保持干净稳定的动画电影渲染：边缘柔顺，抗锯齿良好，材质清楚但不过度锐利；无摄影噪点、无胶片颗粒、无压缩痕迹、无明显锐化光晕、无笔触。不要转成真人摄影或真人剧照，不要二维动漫、二维厚涂、水墨、赛璐璐平涂、儿童卡通、Q版、美式三维卡通、低多边形、游戏引擎截图、游戏宣传海报、廉价CG、塑料模型或蜡像。
```

## 身份一致性段

生成具体角色时，在完整版之前加入以下段落，并将方括号内容替换为当前资产信息：

```text
Image 1 is [角色名] 的已批准身份母版，也是脸部、头骨、发际线、耳朵和身体比例的最高视觉权威。必须逐项保留同一个人的脸长脸宽、颧骨位置、眼裂与眼距、眉形与眉眼距离、鼻梁与鼻翼、嘴唇厚薄与嘴角高度、下颌收束、下巴体积、耳位、发际线、固定轻微不对称、肤色基准、身高、头身比、肩宽、腰胯和四肢比例。不要重新设计、平均、理想化或“优化”这张脸。

Image 2（如有）只负责 [阶段服装／发型附件／伤痕／道具]，不得提供或覆盖脸部身份。Image 3（如有）只负责 [构图／动作／机位／环境]，不得提供或覆盖脸部身份。多个参考图之间若发生冲突，身份母版优先；禁止把不同参考图的脸混合成一张新脸。

当前允许变化的只有：[本阶段或本镜头允许变化项]。除此之外均为不可变量。疲惫、污渍、衰老、伤痕、表情、妆发和光照只能改变表面状态，不得改变头骨和五官几何。角色在远景、中景、近景、正面、三分之四和侧面都必须可被识别为同一人。
```

### 身份优先级

```text
原文章节证据
> 已批准身份母版图片
> 已批准阶段角色卡图片
> 角色深度档案与阶段提示词
> 当前镜头的动作、表情和光照要求
> 本统一角色提示词
> 通用场景风格与模型默认审美
```

身份母版只决定跨时期不变项；黑印、抹额、伤势、胡须、服装、桃枝、武器等阶段变量必须由阶段资产决定，不能因为某张参考图中出现过就永久继承。

## 角色卡专用追加段

制作身份母版或阶段角色卡时，在“完整版”和“身份一致性段”后追加：

```text
制作横版 3:2 的生产级角色设定卡，使用浅暖灰摄影棚背景、细而克制的中性分隔线和稳定网格。85mm 等效焦距，视平线机位，无广角畸变、无透视夸张、无景深，人物全身不得裁脚。

同一张卡内只出现同一个角色：左侧为大幅三分之四胸像及必要的脸部、发型、服装、标志物和材质特写；中右为同尺度、同地线、同一套服装的正面、90°侧面和背面全身中性站姿；底部为同一机位、同一焦距、同一光照的表情组；右下为从实际角色材质提取的色板。三视图的身高、头身比、肩宽、腰线、袖长、衣摆、发型根部、附件位置和图案走向必须一致，侧面与背面必须是同一件衣服的真实延续。

所有面板的脸部拓扑、肤色、发际线和耳位完全一致。表情组只改变面部肌肉，不改变脸型。技术三视图使用中性表情与自然下垂的手掌，不使用战斗姿势、法术特效、强戏剧光、环境叙事或海报构图。中文标签只使用任务明确提供的文字，要求逐字清晰，不得增加乱码、英文副标题、Logo、水印或装饰性印章。
```

## 剧情镜头专用追加段

将已批准角色放入分镜时追加：

```text
这是已批准角色资产在剧情镜头中的演出，不是重新设计角色。保持身份母版与当前阶段卡中的脸、体型、发型结构、标志物、服装版型和材质；只根据分镜改变姿势、表情、视线、衣物受力、局部污损和场景光照。景别变化不得触发换脸：近景保留固定细微不对称，中景保留五官比例和发型轮廓，远景保留头身比、肩宽、服装色块和标志性剪影。人物必须接受场景中的主光、辅光、环境反弹和遮挡阴影，不得像单独贴在背景上的角色立绘。
```

## 短版

当具体角色、阶段和镜头信息已经很长时，使用下面的短版替代“完整版”，但仍应保留身份一致性段：

```text
高预算中国院线3D动画电影人物，风格化写实、半写实比例、精致但略带动画化概括的东亚骨相；人物按原文年龄、阶层和生活状态如实塑造，无统一美型模板。身份母版绝对锁定头骨、五官、发际线、耳位、固定不对称与身体比例，所有角度、景别和表情必须是同一人；阶段变化只改指定服装、标志物和表面状态，不换脸。PBR皮肤与克制SSS，稳定眼球高光，成束动画毛发，麻棉丝皮革具有正确织纹、粗糙度和使用痕迹；真实服装受力与人体结构，柔和电影级全局光照。无自动美化、网红脸、蜡像、塑料、真人摄影、二维动漫、美式卡通、游戏宣传感、笔触、噪点和无依据仙侠装饰。
```

## 推荐拼装顺序

正式生成单张角色图时，按以下顺序拼装，越靠前优先级越高：

1. 原文章节证据与当前镜头事实；
2. 身份母版引用与“身份一致性段”；
3. 当前阶段允许变化项、服装和标志物；
4. 构图、景别、动作、表情和光源；
5. 本文件“完整版”或“短版”；
6. 角色卡或剧情镜头专用追加段；
7. 《凡人阙》项目克制版追加约束；
8. 公共负面约束；
9. 若包含完整环境，再追加同级 `统一风格提示词.md` 中与该镜头相符的场景段，删除会覆盖原文的奇观描述。

## 使用原则

- 本文件定义的是“如何塑造和稳定渲染人物”，不替代角色深度档案、身份母版和阶段角色卡。
- 不把某个角色的五官、服装或配色写入公共段；唐真的紫云袍、黑印、白色抹额等仍只属于唐真的对应阶段。
- 参考图必须逐张声明职责。身份图、服装图、姿势图和风格图不得不加区分地混用。
- 先生成身份母版，再由母版派生阶段卡，最后由阶段卡进入剧情镜头；不要从不同剧情截图反向平均出一张新脸。
- 同一角色跨镜头一致性主要依靠已批准参考图与阶段资产，本提示词用于减少漂移，不能替代视觉参考。
- 本文件是**已定稿**的项目级公共资产（画风载体已定为国风三维，见 `doc/04_风格规范.md` 第 3.1 节）。短版应同步到角色资产模板、镜头提示词模板和相关生成脚本。
