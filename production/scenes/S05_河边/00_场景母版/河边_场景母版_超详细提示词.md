1. 河湾**内侧**的一处凹岸，几丛**高芦苇与低垂柳枝**形成天然遮挡——"避人"靠它成立。
2. 水面平静微有涟漪，**浅水处可见河底卵石与淤泥**，水色浑浊偏绿。
3. 岸边几块**被水磨圆的灰白大石**，石上有水渍与深色水线。
4. 远处隐约可见码头轮廓（同一条河，与 `S03`／`S04` 天际线对得上）。

## 可直接生成提示词

```text
中式古代内河一处僻静河湾，盛夏正午，空景无人物，16:9 横幅；
河道向内凹进形成的一处小湾，几丛高过人的芦苇与几条低垂的柳枝从两侧探出，把这块水面从主河道遮挡开来——从岸上走过看不见这里；
水面平静，只有极细的涟漪；靠岸的浅水处能透过水看见河底的圆卵石与深色淤泥，水色浑浊偏绿；水面有零星漂过的草屑；
岸边有几块被水长年磨圆的灰白色大石，石面有深色的水线与湿渍，石缝里长着短草；岸土湿软，有细小的水鸟脚印；
远处透过芦苇的缝隙隐约可见码头的木栈桥与货船桅杆的轮廓，与本场景同属一条河；
光线：正午强光，唯一光源是头顶的太阳，芦苇与柳枝在水面投下细碎摇动的影，水面有零散的细碎反光但不做粼粼波光特效；
配色：浑浊的绿、灰、土黄，无鲜艳色；
质感：卵石有水磨的圆钝与湿润感，芦苇叶有细长的纤维纹，柳叶被暑气晒得发闷，一切自然物都不做装饰化处理；不加莲花、不加水鸟、不加光斑特效
```

## 一致性锁定项

1. 芦苇 + 低垂柳枝形成的**遮挡**（"避人"靠它成立）
2. 浅水见底：卵石与淤泥
3. 被水磨圆的灰白大石
4. 远处码头轮廓，与 `S03`／`S04` 对得上

## 验收

- [ ] 遮挡关系成立——从主河道看不见这里
- [ ] 浅水处真的能看见河底
- [ ] 水是浑浊偏绿，不是清澈碧蓝
- [ ] 没有莲花、水鸟、粼粼波光一类的装饰

## 硬性拒收条件

- 水被画成清澈见底的碧蓝溪流
- 出现莲花、荷叶、白鹤、锦鲤一类的南方园林元素
- 做成粼粼波光、丁达尔光束的抒情空镜
