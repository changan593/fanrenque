# production/scenes —— 场景视觉资产

已批准的**场景卡图片**与**超详细提示词**，一场景一个目录，跨全六季通用。
结构与 [`../characters/`](../characters/README.md) 完全对称：**一个母版 + 若干状态**。

**为什么在 `production/` 不在 `data/`**：`data/scenes/` 是 `s4_build_assets.py`
从逐章分析算出来的 1364 个 json（重跑就有）；本目录是人工出图、人工裁定的，删了就没了。

---

## 结构

```text
production/scenes/
└── SNN_场景名/
    ├── 00_场景母版/          ★ 跨季不变的几何与固有物
    │   ├── 场景名_场景卡.png
    │   └── 场景名_场景母版_超详细提示词.md
    └── NN_状态名/            时段／天气／人在不在／剧情状态
        ├── 场景名_状态名_场景卡.png
        └── 场景名_状态名_超详细提示词.md
```

**母版锁什么**：面阔、梁架、门窗、地面、固有陈设、破损位置与尺寸——
一句话，**这个地方是什么样**。

**状态改什么**：时段、光源、天气、有没有人、人在哪、剧情带来的临时变化——
一句话，**这一刻它是什么样**。

**状态卡不许动几何。** 这与角色的「阶段卡不许换脸」是同一条纪律。

## 三条纪律

1. **渲染锁逐字共用。** 每张卡的渲染锁都是
   [`../style_assets/统一风格提示词.md`](../style_assets/统一风格提示词.md) 的短版原文，
   一字不改。要改风格请改那份文件，不要在单张卡里改——那正是画风漂移的起点。
2. **克制版追加约束不是可选项。** 每张卡都带，原则三是硬约束。
3. **原文没写的不发挥。** `S10_紫云仙宫大堂` 是这条的样板：原文零描写，
   所以它的几何锁锁的是「不许有什么」——永远只给局部，永远不给全景。
