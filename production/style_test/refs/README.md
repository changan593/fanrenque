# 参考片截图 —— 采集清单

用户指定的八部国产动画电影，逐片列出**要截哪些图、存到哪个目录、叫什么名字**。
文件名可以直接复制，不要改——改了我按名字找图会漏。

拆解与共性抽象见 [`doc/12_参考片画风研究.md`](../../../doc/12_参考片画风研究.md)。
这个目录是那份研究的**原始依据**，也是后续判图的人眼比对基准。

---

## 一、先看这几条

**优先级**：★ = 必拍，○ = 有余力再拍。
全表 **91 张**，其中 ★ **56 张**。
只拍 ★ 就够我改定风格段；全拍够建完整的验收基准。
实在只想拍一小批，就先拍《长安三万里》和《白蛇：浮生》两部的 ★
（共 23 张）——反美化与材质这两个最关键的量都在里面。

**格式**

| 项 | 要求 | 为什么 |
| --- | --- | --- |
| 格式 | **JPEG**（`.jpg`） | PNG 截图动辄 5-10 MB，八十张就把仓库撑爆 |
| 尺寸 | 长边 **1080~1440 px** | 判画风够用，再大是浪费 |
| 单张体积 | **≤ 1 MB** | 全套控制在 100 MB 以内 |
| 画面 | **原始截图** | 不加滤镜、不调色、**不裁边**——构图信息在画面边缘 |
| 字幕 | **尽量避开** | 有字幕也能用，但会干扰我读画面 |

**一条 git 的注意**：图片是二进制，改一次就在历史里存一份全量。
所以**尽量一次拍定，不要反复替换同名文件**。拍错了删掉重来比覆盖好。

**找不到就跳过。** 我写的画面提示是凭对影片的印象，可能记错。
宁可少一张，不要硬凑一张不对的——那比没有更糟。

**同一条想多存几张**，在文件名末尾加 `_2` `_3`，例如
`长安三万里_高适老年_面部特写_2.jpg`。
