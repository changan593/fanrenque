**这一集是这部剧的旁白系统在故事里出生的一集。**

前二十三集里，唐假只是一个口径——一个替唐真说出他说不出口的话的声音。
观众听了他二十三集，从没见过他。
这一集他走进画面，坐在唐真对面，用第三人称讲述唐真正在想什么：

> **「唐真依然不觉得恐慌，他只要坚信谁拿着抹额谁就是唐真，其他的一切都是『唐假』就好。」**

**名字是唐真自己起的，而说出这句话的正是被起名的那个。**

唐假不是心魔。他是罗生门投射的思想，理论上全知全能，
条件是有人好奇、有人渴望。他什么都能给——破除「无法」、杀了人魔尊、
说出是哪几位圣人出卖了他、说出南红枝会不会复活。
代价不用唐真付。

**代价由这个世界付。也没多大代价，只是变成一本书而已。**

### 这一集是唐假的出生证明

前二十三集里，`doc/05` 的那套「唐假旁白系统」只是一个**制作口径**：
一个替唐真说出他说不出口的话的声音，观众听了二十三集，从没见过他。

**这一集他走进画面**，坐在竹屋里唐真的对面，用第三人称讲述唐真正在想什么
（镜054、镜056、镜060），而名字是唐真自己在那句话里起的：

> 「唐真依然不觉得恐慌，他只要坚信谁拿着抹额谁就是唐真，其他的一切都是『唐假』就好。」

原文接着补了一句：**「『唐假』还在平静的讲述着唐真的想法。」**（镜057）

**这一镜的处置是全集最要紧的一条：**
镜054、镜056、镜060 三句台词必须用**前二十三集唐假旁白的完全相同的语速、语气与停顿**，
让观众在听到名字之前就先认出这个声音。

### 本集查到的三类抽取问题

1. **抽取把唐假的两句台词记在了唐真名下，而原文当场就否认了。**
   `seq93[54]` 与 `seq93[56]` 在 `dialogues` 里 `speaker` 都写「唐真」，
   可原文第 55 行紧接着说：**「唐真此时是这么想的，可是这话是对面的自己开口说的。」**
   **这是全集最重要的一场戏，也是抽取错得最要命的一处**——照它办，
   整场戏就变成唐真在自言自语。剧本按原文办：说话人是唐假。
2. **抽取给一句无主的台词指派了一个不在场的人。** `seq94[35]`
   「狗安，你怎么样了？」的 `speaker` 写的是**齐渊**，而下一幕（`seq94[54]` 起）
   齐渊正在另一个州的茶摊上被妖圣追着跑。原文没有交代是谁在敲门。
   **剧本用「画外」当说话人，不指定**——这一声救了整个世界，而说话的人不知道。
   （与 E23 那条「心魔（假设）」是同一类：抽取不肯留空。）
3. **第一例条目文本被从头截断。** `seq93[46]` 的 `narration` 正文是
   「原来如此。”唐真笑了……」——**开头那个引号丢了**，原文是
   「“原来如此。”唐真笑了……」。`norm()` 会剥掉引号，所以对账不受影响，
   但这说明抽取在处理「引号台词 ＋ 紧跟叙述」的行时，切分点可能落在引号中间。

**另外，`seq93` 七十一行只抽出 8 条 `narration`，`seq94` 七十二行抽出 12 条**，
而这两章几乎全部是识海、竹屋、茶摊三个不可见场景的描述——
剧本里 132 处 `【画】` 与 64 处 `【白】` 大半来自这两章。
这是 doc/03 待办 2 里「反方向漏抽」的又一例。

## 附三：一次没有问出口的提问

唐假开的价，是这部剧到此为止最大的一笔：

| 他能给的 | 出处 |
| --- | --- |
| 破除「无法」 | 唐真两年来最想要的东西 |
| 杀了人魔尊 | 那个把大道点在他额头上的人 |
| 是哪几位圣人出卖了你 | E02 那场圆桌会议的名单 |
| 十二面七彩琉璃灯有何用 | 从 E02 挂到现在的谜 |
| **南红枝会不会复活** | 全剧唯一一件他不敢想的事 |

**而这些都不要钱。**「你完全不需要支付任何代价！只要你在此时问出口，我现在就都告诉你！」

代价由这个世界付：

> 世界会支付怎样的代价呢？
> **也没多大代价，只是变成一本书而已。**

原文把唐真被推到边上的那几秒写得很老实——**他认输了**：

> 只要问了，南红枝也许会活，只要问了，他便一朝成了尊者，
> 只要问了，感情道德的包袱便可以抛之脑后，
> 只要问了，便可以将一切锁定回小白文的轨道上，再不脱轨。
> **代价只是，一切皆无意义。**
> 问吧。
> **问吧！**

**然后有人敲门，问了一句「狗安，你怎么样了？」。**

这一声不是救兵，不是法宝，不是圣人。它只是玉屏观里某个人半夜过来看看他怎么样。
**原文没写是谁，本集也不指定。**

### 这一集回答了「唐假是什么」，也埋下了他会怎样

| 问题 | 本集给出的答案 |
| --- | --- |
| 唐假是心魔吗？ | 不是。「我就是你的罗生门啊。」 |
| 他为什么全知全能？ | 「我的全知必须是有人好奇，我的全能必须是有人的渴望」——**而「人」不是唐真，不是红儿，也不是他自己** |
| 他为什么会出现？ | 齐渊替唐真补齐了后六卷的理解，唐真被迫以《罗生门精解》成尊，**「唐假」便被尊者境的罗生门直接投射了出来** |
| 他为什么会消失？ | 唐真戴回抹额，野狐禅师的大道压住了「无法」，他瞬间落回入道 |
| 那他还会回来吗？ | **「若是一路修上去，早晚唐假会成为唐真。」** |

最后一行是这一集埋得最深的一根钉子。它由唐真自己的声音说出来，
说的却是**他自己会被这个声音替换掉**。

而这一集的收尾同样不讲情面：三天前唐真随口说「我看她不是去挖死人的坟，
她是去给活人挖预备的坟啊」（E22 镜036）——这一集镜头终于跟着姚安饶
走到了那条溪水的尽头，看见了那道**刚好够一个人钻进去**的裂隙。

**然后一顶草帽从山间走了上来，问她：这座山是玉屏山吗？**

## 附四：六次现身档的分配理由

**第三次用满 `doc/05` 5.7 的六次上限**（前两次是 E20、E23）。
这一集有资格用满，理由很特别：**它是唐假自己的一集**——
六次静止里有四次，唐假说的都是关于他自己的事。

| 镜 | 承载 | 为什么要停下世界 |
| --- | --- | --- |
| 014 | seq93[14] | **全剧的世界观底牌。** 「不是你的思想投射到现实，而是你的现实是别人投射的思想」——**这一句必须在唐假现身之前说，因为它就是唐假的定义** |
| 089 | seq94[18-19]（非正条，两条都写了 `※`） | **全剧到此为止最越界的一次。** 唐假不在画面里，竹屋里只剩唐真一个人。「世界会支付怎样的代价呢？」——「也没多大代价，只是变成一本书而已。」**必须说得很平常** |
| 102 | seq94[32-33]（非正条，两条都写了 `※`） | **压力的顶点，两个字，两遍。** 这不是任何人说出口的话，是他脑子里那个越来越大的声音。第二遍要更近、更响——**然后被一声敲门打断** |
| 134 | seq94[65-66] | **全集唯一一次为一个笑话停下世界。** 「妖，本就不是十分讲理。妖圣，则是十分的不讲理。」两句话给一位圣人定了性，而她此刻长着一张可爱小女孩的脸 |
| 214 | seq95[75] | **全集最凉的一次，也是唐假第一次「不出现地出现」。** 唐真刚说完「只要我能忍住不被『心魔』蛊惑，便没有大碍」——**紧接着耳边有人轻笑，像是自己** |
| 251 | seq95[112]（非正条，写了 `※`） | **最后一根钉子。** 「若是一路修上去，早晚唐假会成为唐真。」由唐真自己的声音说出来，说的却是他自己会被替换掉——**说完不留余韵，直接接下一镜的解法** |

**为什么镜 071「我就是你的罗生门啊」没有现身档**：
它是第二幕的落点，八个字，也是这个角色的自我介绍。
**但世界不能为唐假自己的台词停下**——`doc/05` 5.7 里现身档的含义是
「唐假让世界停下来听他说」，而这一镜他已经**在画面里坐着**了。
一个已经现身的人不需要再现身一次；停下来反而会把这句话变成宣告，
而原文里它是一句很温和的解释。

**为什么镜 108「齐渊！」没有现身档**：
两个字，全集唐真唯一一次失态，也是竹屋外的红儿唯一听见的东西。
**这一镜的重量全在音量和突然**，前面十七镜都是低语和对坐。
停一下就等于给它加了个框，而它需要的是把观众吓一跳。
