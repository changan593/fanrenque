**九洲的顶尖宗门一个接一个走进广场，然后一个接一个地看向同一个方向。**

第一个进来的龙场先扔下一团太阳，让所有人都遮住眼睛——
**因为在无尽光明里最方便看清别人**。然后那位老学究吟了一首诗：

> **「二载残红被替身，移花接木古今频。偷梁换柱差充好，改姓涂名假冒真！」**

儒师吟诵自有天地，于是满地桃花卷成海浪扑向二楼那个白裙姑娘。
她没有躲。**在她眼里那不是花海，是火焰。**

后面的人如出一辙。茅草堂那位见谁都熟的书生走到唐真身后行了个礼，
喊了声「唐苟安前辈」，然后**看都不看红儿一眼**，只留下三个字：「并不久。」

唐真很生气——不是因为被指摘，是因为**有人用红儿算计他**。
而那个人昨晚给每一家都送了一句话：**「你身旁常伴女子，疑似红替。」**
消息还说，那女子修的疑似魔功。

于是他给斗法报了名，境界那一栏填的是「筑基」。
**他现在是入道。**

## 附三：一整天的忍，和一壶酒的账

这一集分成两半：**上半集全是忍，下半集一次结清。**

### 上半集：九家顶尖宗门，一个接一个地看向同一个方向

| 谁 | 做了什么 |
| --- | --- |
| 龙场 | 先扔下一团太阳让所有人遮眼——**「站在无尽光明处窥视别人」**；然后老学究吟诗，儒师吟诵自有天地，满地桃花卷成海浪扑向二楼 |
| 茅草堂 杜有才 | 见谁都熟，连副峰的名字和事迹都叫得出来；走到唐真身后行书生礼喊「唐苟安前辈」，**然后看都不看红儿一眼**，留下三个字：「并不久。」 |
| 剑山 | 装作没看见红儿，也没搭理唐真，**一副老子就是来旅游的表情** |
| 玉蟾宫 | 步履匆匆走过，只有萧不同在场间吹了首《凤求凰》 |
| 其余各家 | 「大多明里暗里的对着唐真所在的方向表达了不满」 |

**而红儿从头到尾只做了一件事：坐直，不移开视线。**

> **她像是要用眼神告诉每一个走入广场的天仙境修士，我没错！**

那首诗她背了下来，走到平台边缘一遍一遍地念。
然后不痴来了，第一句话是替她把那首诗批了一顿
（「用词粗浅，既无格调也无内涵，只是酸腐儒士的卫道之作」），
第二句话是知了和尚托他带的：

> **「像与不像非人之过，若要脱身，唯有正果。」**
> 注解：**「若有一日姑娘成仙，天下自不会以像或不像议论二位，只会感叹天下好女子，多出红字。」**

### 中场：唐真算出了是谁干的

他生气的不是被指摘，是**有人用红儿算计他**。
推理只用了六镜：来的人是冲他来的，注意力不该在红儿身上；
除非有人提前送了「添油加醋的观点」，让他们带着疑问来，**然后得到一个提前布置好的结果**。

吕藏锋带回来的证据是一句话：**「你身旁常伴女子，疑似红替。」**
消息还说，那女子修的疑似魔功。
**能在一夜之间给每一家送信的，只有玉皇顶。**

而理由唐真自己写得很清楚：他两次想跟农圣谈玉屏山的未来，
一次被冷笑着问「真君有何教我」，一次被拒绝，**于是他没有问第三次，自己出手保下了玉屏山**。
不出两天，账就来了：

> **为了展示自己的权威与不满，丝毫不介意用伤害一个十几岁的姑娘的手段来敲打唐真。**

### 下半集：一只白玉酒壶

那壶酒他边讲边喝，喝到「最后一杯倒满，正好喝干」。
玉皇顶的修士来叫他下场，他做了三件事：**松开抹额、从红儿手里拿走红钗、提上那只空酒壶。**

对手是金浩，金桧的哥哥，筑基巅峰，来这里是为了灵溪洞的名额。
唐真报的是「玉屏山，唐苟安，**马上筑基境**」。

| 步骤 | 他做了什么 |
| --- | --- |
| 一 | 对方冲到面前，他在鼓捣酒壶和红钗，**只来得及说一个字：「滚！」** |
| 二 | 「我好了。」——红钗塞进酒壶，举起来向四周展示，然后在阳光下摇 |
| 三 | 微风紧贴地砖向他汇聚，**广场的地砖开始出现细小裂痕** |
| 四 | 打开盖子闻了闻，仰头，**当着所有人把一壶天地灵气喝了下去** |
| 五 | 脸更红了，打了个酒嗝，**然后筑基有为** |
| 六 | 扭头冲二楼廊道喊：「可曾学会？」——**「学会了！」** |
| 七 | 举起空酒壶冲主殿二楼喊：**「此乃吞灵诀！各位可曾见过？」** |

**红钗是滤芯，酒壶是滤嘴，广场底下那条灵脉是农圣的大道。**
他站在一幅天门山脉的堪舆图上，从图里抽了一壶灵气喝掉，
用的是那套被人说成魔功的功法，当着九洲九家顶尖宗门的面。

> **是了，你们不是以为她是魔修吗？那我便亲自修一修，给你们看一看！**
> **若是魔功，各位便莫要安坐，且来与我论一论！**

**二楼沉默，无人回应。**

**为什么镜022 那首诗没有现身档**：
二十八个字，全集最重的一次羞辱。
但它是**一个人当众念出来的**，力量全在「儒师吟诵，自有天地」——
念完就起风，风卷着桃花砸过来。**停下世界会切断这个因果链。**
真正需要停下来的是下一层：**在她眼里那不是花海，是火焰**（镜026），
而那一镜给的是主观画面，不是旁白。

**为什么镜288「此乃吞灵诀！各位可曾见过？」没有现身档**：
它是本集标题，也是全集最响的一句喊。
**但它是喊给二楼听的，必须留在现场的空气里**——
喊完之后是「二楼沉默，无人回应」，那八个字才是它的回响。
唐假的结账放在再下一镜（镜290），**先让沉默落地，再说理由。**

**为什么最后一句用字幕卡而不是现身档**：
镜290 刚停过一次世界，紧接着再停一次就成了拖沓。
`seq126[67]` 是一句挑战书——**「若是魔功，各位便莫要安坐，且来与我论一论！」**
黑底白字停满二十秒然后黑场，**比任何配音都更像一份战书**。
