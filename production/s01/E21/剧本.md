**这一集有一半的视角不在玉屏山这边。**

剑山来玉屏山拜山，一个人上山，一个人下山。
上山那一段，他在山道转角差点撞上一个扛着锄头的白裙姑娘，
对方连看都没看他一眼。下山那一段，他不敢抬头。

这个人叫吕藏锋，本集第一次出场，
**全集 62 处内心音里有 24 处是他的，只比唐真少七处。**
摄影机在前二十集里也离开过唐真，但没有一次把一个陌生人的心事跟到这个程度。

中间那一剑，他扭身慢了几丝，
**于是天门山脉三天来第一次响起了两声雷。**

整座山脉都在抬头找那位隐居的高人。
**只有观众知道，那不是高人，那是一个人回头看了一眼。**

### 本集查到的六类抽取问题

1. **第二例 `para` 错位。** `seq86` 的 `narration` 里，`para` 记作 43 的那条
   （「如今在一个副峰被人拦了两剑？」）在原文里是第 42 行。
   E20 刚查出第一例（`seq78[44]`），两集连着两例，说明这不是偶发。
   剧本段号仍以 `analysis` 为准，括号内注明原文行号。
2. **同一段文字被同时判成旁白与台词。** `seq83[20]`「他们来他们的呗。」
   既在 `narration` 里，也在 `dialogues` 里。按 `【台】` 处置。
3. **同一段文字被同时判成旁白与心理活动。** `seq83[21]`（唐真为什么不肯见剑山的人）
   两边一字不差。按内心音处置，账上记「内心音」。
4. **内心话被判成台词。** `seq84[39]`「郭师兄，我可把机缘搬到你面前了！」与
   `seq84[55]`「别吧，郭师兄没必要这个时候吧！」在 `dialogues` 里，
   `speaker` 写的是「未明说」——原文写得很清楚，一个是心里喊的，一个是「他在心里嘀咕道」。
   两条同时也在 `monologues` 里。剧本按内心音处置。
5. **旁白条里裹着一句台词。** `seq84[12]`「“哎。”一声叹息响。」整行被判成 `narration`，
   而那声「哎」是唐真出场前的第一个音。剧本把它拆成台词 ＋ 画面。
6. **`seq85` 只抽出 6 条 `narration`。** 那一章 52 行，是全集动作密度最高的一章
   （破关、报名、举剑、留手），剧本里 162 处 `【画】` 大半来自这里。
   这是 doc/03 待办 2 里那个「反方向漏抽」的又一例。

### 原文自身的两处用字出入（按原则二逐字保留，不统一）

- **剑名**：`seq85[28][38][39]` 写作「**雷响**」，`seq86[29][30][52]` 写作「**响雷**」。
  剧本两处都照抄，不做统一。**分镜时按各自出现的写法上字幕与配音。**
- **农具**：`seq83[24]` 姚安饶拿的是「**铁锹**」，`seq83[46]` 与 `seq85[50]`
  吕藏锋看到的是「**锄头**」。同一件东西，两个人叫法不同——
  **可以就这么拍**：观众看到的是同一把，而他记住的是他自己的说法。

## 附三：这一集只有一个秘密，而且永远不会被揭穿

原文把因果写得干干净净，一步不省：

1. **姚安饶扛着铁锹出门**（seq83[24]）——她自己的事，和玉屏山无关。
2. **吕藏锋在山道转角与她擦肩**（seq83[42-47]）——他道歉，她走了，连头都没回。
3. **她中途折返回来看热闹**（seq86[17-19]）——理由是「我落东西了」，被唐真当场戳穿。
4. **他扭身挥剑时看见了她**（seq85[50-52]）——**「剑也慢了些，似乎怕光太亮晃了姑娘的眼睛。」**
5. **于是郭师兄的剑先到**（seq86[6]）——他必须挡，挡完再发力弹回去，这就成了两剑。
6. **于是天门山脉响了两声雷**（seq86[36]）。

**这条链上的每一环都有人在场，但没有一个人看见完整的链。**

| 谁 | 他以为发生了什么 |
| --- | --- |
| 屏姐 | 「那个吕什么锋就是原地转了一圈」（镜240） |
| 郭师兄 | 「他留手颇多，本无需两剑败我的」（镜238） |
| 唐真 | 以为对方那一瞬认出了自己（镜242） |
| 剑山长老 | 以为副峰里藏着一位返虚境的高人（镜225） |
| 整座天门山脉 | 「是谁？」（镜220） |
| 吕藏锋 | 知道，但他只跟自己的剑道了歉（镜210） |
| 姚安饶 | 全程不知道，也不会知道 |

**观众是唯一一个从头看到尾的人。**
这一集所有的喜剧和所有的凉，都建立在这个信息差上——
**它不需要任何一个角色在片尾恍然大悟，反而必须保证没有人恍然大悟。**

### 另外两件这一集顺手办完的事

**第一件，郭师兄这个人第一次被拍完整了。**
他修剑不是为了斩天斩地——「他实在不擅长回答这些文绉绉的话，
而且他也并不清楚自己的剑意剑理之类的是什么」（镜160）。
理由只有一句：**「他郭守安，守的便是玉屏山上所有人的平平安安。」**（镜167）
起完这个头，他给自己那柄剑起的名字是——「此剑。。。黑剑。」

**第二件，红儿全集闭着眼，却被同一个人点评了两次。**
上山时他说她「天赋一般，但心性尚可」，还输白裙女子一筹（镜099-100）；
下山时他说「心性尚不如红裙女子，怎敢胡乱点评人家」（镜204）。
**中间隔着的，就是他自己那一次回头。**

**为什么镜 179「剑也慢了些，似乎怕光太亮晃了姑娘的眼睛」没有现身档**：
它是这一集所有后果的唯一原因，按理最该停下世界。**但它不能停。**
原文把这句写得像一句随口的比喻，前后两行都在讲扭身的角度；
**一停，观众就知道要出事了，后面那三十镜的惊讶全部作废。**
所以它只是一句 `【白】`，画面不停，剑还在往下落。

**为什么镜 058「甚至未曾看他一眼」没有现身档**：
那是全集最残忍的一镜，而且没有人做错什么。
**它靠的是长度，不是重量**——让他保持抱拳的姿势，让那一拍长过舒适区，
然后由一个五六岁的孩子来收场：「师兄，人家走了。」
