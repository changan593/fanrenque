**本集是第一季的换气口。**

E13 结束时唐真走出北阳城，只留下一阵清风。这一集他走出黑幕，
发现整个天下都站在城南的土路上等他：一个把他当偶像的青云榜第二、
两位天仙、一位圣人，以及一只从北边一拳砸碎月亮的凤凰。

**这些都不是他的麻烦。**

麻烦是那个从头到尾一句话没说、穿着缝缝补补破裙子的姑娘。
山道上三个人拼命找话讲，只为了不让它安静下来——
因为一安静，那个问题就会显出来。最后它还是被问出口了。

## 附三：为什么这一集唐假说了这么多

**64% 是全季最高，比 E12 的 17% 高出近四倍。这不是失手，但值得写清楚。**

先说判据没有松。`doc/05` 第五节那句话仍然是唯一的尺子：
**「这条旁白携带的信息，摄影机拍得出来吗？」** 本集能拍的都给了画面——
两轮明月怎么升起、凤凰怎么撞碎月亮、姜羽怎么擦手、黑子怎么点住玉珠、
石桌怎么无声断开，一律 `【画】`，一个字没让唐假说。

真正的原因是**这一集要交付的东西大多没有形状**：

| 要交付的 | 为什么拍不出 |
| --- | --- |
| 「天仙」「圣人」这两个层级 | 画面里是两个亮点和一个白发中年人。层级是数字，不是形象 |
| 天下后台榜 | 一个人的靠山有多硬，只能说 |
| 紫云仙宫与棋盘山三十年的相看两厌与后来的和好 | 这是一段历史，montage 只能给情绪给不出因果 |
| 无道六魔在不同地界的六种叫法 | 名字本身就是听觉材料 |
| 白玉蟾为什么不能在这里动手 | 一件**没有发生**的事 |
| 野狐禅师为什么输了却赢了 | 同上 |

这六项加起来就是本集 `【白】` 的大头。它们有一个共同点：
**都是「这个世界有多大」的信息**，而唐真在前十三集里被按在一个码头上，
观众也就跟着被按了十三集。E14 是这一季第一次把镜头抬起来看整个南瞻部洲，
抬头这件事，本来就得有人报名字。

**15 处白描留声也是同一个原因，但还多一层。** 冷开场那五句
（`seq55[4]~[8]`）是全季语气最特别的一段：第二人称、爱情比喻、PTSD。
它们不属于 `analysis.narration`，抽取时被归成了唐真的心理活动，
但只要念一遍就知道不是——唐真不会用「你」来说自己，
更不会给自己下「也算是一种PTSD吧」这种诊断。这是叙述者在对观众说话。
按 `doc/05` 的口径，这正是唐假存在的理由，所以五句全部留声，逐条写了理由。

**最后一件事：唐假说得多，不等于这一集是唐假的。**
全集最重的三句话都不是他说的——

- 「我为所欲为只是单纯的因为——你们两个打不过我。」（姜羽，镜095）
- 「师兄，她是你新收的徒弟吗？」（姜羽，镜194）
- 「我不是你的师侄。」（红儿，镜269）

唐假讲了一整集这个世界有多大，是为了让最后这三句听起来有多小。
