**这一集有两个姚安饶。**

一个在竹林里，刚刚求死不成。唐真看着她，说了三个字：**「我帮你。」**
理由是一笔旧账——半条命——而她当场又添了一笔：
「如果有一天，她找来，我会替你还她半条命。」

另一个在南洲梨园总庭的戏台上，白裙已经沁满了血，一只眼睛看不见了。
她面前摆着一件红色戏袍，身后站着一个画满浓妆的男人。
**没有人对她说「我帮你」。**

中间隔着大半集：一个和尚认出了唐真，一个剑修的拳头留在竹子上，
一个道人溜进玉屏观，发现主殿里只剩一座白玉蟾的神像，
一位玉蟾宫的高徒从午时走到酉时，也没能走出那片竹林。

然后天黑了，天门山迎客，
**白裙的姑娘扛着锄头下了山，走进一条会发光的地缝。**

## 附三：两个姚安饶

这一集把同一个人拆成两半，放在一头一尾。

**第一幕，竹林里。** 一个刚刚求死不成的二开分身，站在原地提着一柄旧剑。
唐真看了她很久，脑子里过了一整套推理——

| 他想到的 | 对不对 |
| --- | --- |
| 七囚箱的分身一定越来越邪性 | 对，但她是例外 |
| 例外的原因是红儿妹妹的身份，或者玉屏观的幸福 | **错** |
| 这样下去她会自杀或者疯掉 | 对，刚才就是 |
| 她的执念来自自己在北阳城竹亭里说的诛心之言 | 对（E16 镜156-161） |

真正的原因唐假只说了一次，而且是当着一个不知道的人说的：

> **「他并不知道姚安饶从修炼开始就偏离了系统复制的修炼方法，
> 她的七囚箱似乎更注重执念，而非恶念，导致她的分身也有些不同。」**

**执念，不是恶念。** 这一句解释了从 E08 一开分身「带着佛意清净明华」
到 E27 第八幕十七镜心事的全部东西。

然后他说了三个字：**「我帮你。」**
她问「凭什么」，他现场编了一套算法——半条命，分开看是两个人救了他，
合起来看还给谁都一样。**编完他自己都觉得这理由不错。**

**第七幕，戏台上。** 另一个姚安饶跪在血里，一只眼睛已经看不见眼瞳。
她面前是一件比人还贵重的红色戏袍，身后站着一个画满浓妆的男人。

| 万大家试过的 | 结果 |
| --- | --- |
| 术法操纵身体学戏 | 能，但没用——那和自己分身表演有什么区别 |
| 疼痛（碰一下耳朵就滴血） | **「这个女孩不会屈服，起码不会因为疼痛屈服。」** |
| 直接改灵魂 | 不行，改了就当不了徒弟 |
| **后手：把她父亲拽到台下** | —— |

她的对白全集只有五句，其中三句是「穿你妈」「问你妈」「想你妈」。
第四句是对着失散多年的父亲说的：**「呦，好久不见。」**

而她真正输掉的地方不是疼，是这两镜：

> 她又看了看师姐手里的人，那人抬起头，咧嘴苦笑了一下，摇了摇头，
> 似乎在说别管他，**如今仔细打量，她竟然觉得那人长得陌生。**
> **她可能很久都没有仔细打量过自己的父亲了。**

第五句是唱出来的。

**两个姚安饶，同一天。一个有人对她说「我帮你」，一个没有。**
而那个有人帮的，正在琢磨怎么替本体去死；
那个没人帮的，刚刚穿上了一件让她再也脱不下来的衣服。

**为什么镜202「穿你妈」、镜243「想你妈」没有现身档**：
这三句脏话是第七幕唯一的抵抗，它们的力量全在**快**和**平**——
「声音依旧平缓动听，这要感谢职业」。停下世界会让它们变成宣言，
**而她说这三个字的时候，语气和报菜名没有区别。**

**为什么镜257 那句戏词没有现身档**：
它是全集最后一句，也是本幕的题目。
但唱出这句词的人已经走进了红帷幔，**画面上根本看不见她**——
世界已经替她停下来了，唐假不需要再停一次。
