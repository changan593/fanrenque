# E01-E02 场景资产（可直接生成版）

**使用方式**：每个场景先出 3-5 张**空景基准图**（不含人物），人工选定一张作参考图，
此后该场景的所有分镜都以它为垫图，只改机位、时段、人物。这是场景一致性的唯一可靠办法。

**标注规则**同角色资产：`【原】` = 原文明确写了，不可改；`【补】` = 为可生成而补全。

**全局负面词**与**全局风格后缀**见 `02_角色资产.md` 开头，此处不再重复。

**场景类负面词追加**：

```
现代建筑, 玻璃, 水泥, 电线, 沥青路, 整齐的砖墙, 规则排列, 对称构图,
新建筑, 崭新, 干净, 无人打理的整洁, 日式建筑, 韩式建筑, 欧式建筑, 奇幻城堡
```

## 一致性锁定项 ★

1. **屋顶正中偏右一米见方的破洞**——位置尺寸永不变，它是本场景的坐标原点
2. 断右手、脸熏黑、彩绘剥落的城隍泥塑
3. 光柱中的浮尘
4. 满地草席破碗稻草
5. **金晃晃的是光，庙本身必须是脏的、破的**
