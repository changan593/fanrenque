# 分镜提示词总则与模板

本目录存放第一季每一幕的**画面内容提示词**（幕文档）。
一集一个目录（`E01/`~`E47/`），一幕一个目录，里面一份 `提示词.md` 逐镜给出可直接用于生图/生视频的提示词
（E01 另有 `分镜草图.svg`）。已写 E01~E10 共 77 幕。剧本与幕文档的格式约定见 `doc/13_剧本格式规范.md`。

**上游**：`production/s01/EXX/剧本.md`（分镜脚本，镜号/景别/时长/表演/声音的唯一事实来源）。
**资产对位**：`02_角色资产.md`、`03_场景资产.md`（E01-E02 实体）、
`04_视觉基准_E03-E10补充.md`（E03-E10 新增实体）、
`production/characters/CNN_角色名/`（已批准的身份母版与阶段卡）。
**规范上游**：`doc/04_风格规范.md`、`doc/05_唐假旁白系统.md`。本文件与它们冲突时以它们为准；
它们与原文冲突时以原文为准。
**风格段**：`production/style_assets/统一风格提示词.md`（环境）与
`统一角色提示词.md`（人物）。**不要往本目录的提示词里抄它们**，理由见下。

## 一、最重要的一条：不含风格

**画风已定稿为国风三维**（`doc/04` 第 3.1 节，原待定项 A）。
**但本目录所有提示词仍然只写"画面内容"，不写"怎么画"。**

定稿了为什么还是不写？因为风格段由程序在出图时**统一追加**到每条提示词末尾。这样：

- 风格段改一次，全季 12,958 镜同时生效，不必回改任何一个文件
- 12,958 镜不会各写各的风格词，从源头上杜绝画风漂移
- 内容层与风格层可以分别校验——内容对不对查原文，风格对不对查一份文件

拼装顺序（越靠前优先级越高）见
[`../style_assets/README.md`](../style_assets/README.md)。本目录的产出是其中第 4 步。

所以：

### 1.1 正向提示词内禁止出现的词（黑名单，程序会校验）

**这份黑名单在定稿后依然有效**——它拦的是"在内容层写风格词"这个行为，
不是拦某一种画风。"三维""渲染""CG"现在是对的画风，但它们仍然不许出现在这里。

```
厚涂, 笔触, 写实, 半写实, 水墨, 油画, 插画, 赛璐璐, 二次元, 动漫, 漫画风,
CG, 渲染, 三渲二, 建模, 滤镜, 胶片, 颗粒感, 画质, 高清, 超清, 4k, 8k,
杰作, masterpiece, best quality, artstation, octane, 虚幻引擎,
低饱和, 高饱和, 饱和度, 调色, 色调统一, 色彩风格, 画风, 风格, style,
任何画家/工作室/作品名
```

### 1.2 允许写、且必须写细的（这些是内容，不是风格）

- **固有色**：裙子是红的、道袍是青灰的、咸鸭蛋壳是青蓝色的——物体本身的颜色照写
- **材质与使用痕迹**：粗麻织纹、木料开裂、墙皮脱落、油渍、补丁、包浆
- **光**：光源是什么（日/月/灯/火/术法）、从哪来、什么方向、硬光软光、影子落在哪
- **空气介质**：浮尘、水汽、油烟、雨幕、雾
- **光学**：景深虚实、焦点位置、边缘失焦（回忆镜头用）
- **比例**：Q 版唐假的二头身是角色设定，不是画风，照写

### 1.3 后期规则单独标注，不进提示词

降饱和、降亮度、色相偏冷这类**调色动作**属于后期，不写进生图提示词。
需要时在该镜的「后期规则」一行单独标注（如静止世界、梦境回忆），供后期统一处理。

## 四、生图提示词的写法（每一条都要过的关）

一条合格的生图提示词是**一段自足的中文**，别人不看任何其他文档也能出这张图。
顺序建议：**景别视角 → 主体（人物） → 动作表情 → 服装道具 → 环境（前中后景） → 光 → 构图**。

### 4.1 人物：锁定特征必须每条重写

出图时虽有参考图垫图，提示词仍必须复述该角色的锁定特征（防漂移，也防资产卡改版）。
每个入画角色至少写到：

- **脸**：脸型、眉眼、神情（资产卡锁定项逐条落实——如唐真：丹凤眼、眼白偏多、下眼睑淡青）
- **标识物**：唐真额头正中直径约两厘米的竖椭圆哑光炭黑印记（边缘清晰、不反光、不发光）；
  红儿的双丸子头/带铃银簪与木棉花纹样；老拐子的右脚萎缩与乌黑木棍……
- **此刻状态**：姿态、重心、手在做什么、视线看哪、表情到什么程度、汗/泪/尘/血的位置
- **服装此刻的状态**：新旧、合身与否、哪里破、哪里脏、被风/水/动作弄成什么样

### 4.2 场景：每镜写出"这一机位看得见的部分"

不整段照抄场景卡，只写入画部分，但入画部分要写到位：地面是什么、墙是什么、
远景是什么、空气里有什么。场景锁定项（如 S01 的破洞位置）入画就必须写。

### 4.3 光：每镜必须能指出光源

「光从屋顶破洞直射而下」「唯一光源是地上的灶火，火光自下而上打在脸上」。
禁止无来源的亮。影子的方向要与光源一致——**洞天（S13）例外：全场无影，写明**。

### 4.4 细节的密度标准

一条主镜提示词 150-350 字；大场面群像可到 450 字。凡是画内可见的东西都要有着落：
手指、鞋、腰带、碗的豁口、墙上的手印。**宁可啰嗦，不可含糊。**

### 4.5 视频动态的写法

- 写清**这几秒内发生的全部运动**：人物动作（含幅度与速度）、环境运动（尘、旗、水、火）、运镜
- 静止镜头也要写「画面近乎静止，唯有×××微动」——AI 生视频需要明确的静
- 时长照抄剧本；剧本无时长的（E06 起部分集）按 doc/04 11.1 节奏基准自定并标注「（自定）」

## 五、静止世界：【现】镜头的画面语法（doc/05 2.3/4.2，一帧不许改）

剧本声音栏出现 `【现】` 的镜头，唐假现身、世界静止。写法：

1. **冻结**：画面内一切运动停住——飘的尘停在半空、泼出的水停成一串珠、人停在动作中途，
   **包括眨眼与呼吸**。表情停在原处，不做蜡像化
2. **唐假**：全画面唯一在动的东西。**二头身 Q 版男孩**：圆脸、大眼睛明亮好奇带笑意；
   额头正中黑色椭圆印记（**边缘略晕开、颜色比唐真本体淡一档**）；黑色短发略乱几缕翘起；
   洗旧的青灰色布袍、袍角毛边、麻绳腰带；赤脚或旧布鞋；**脚下没有影子**
3. **空间关系**：他站在画面的"纸面"上，不进入景深——从画框下缘探头、坐在画框边沿、
   贴着画面边缘走。**不碰任何东西、不遮挡剧情主体、不被任何角色注视**
4. **进出无特效**：某一帧起全停，说完转身或摆手即恢复。不做转场特效
5. **后期规则行**标注：「静止世界：降饱和一档、降亮度半档（后期统一处理）」——不写进提示词
6. 生图上通常一镜两张：**底图（冻结的世界）＋唐假叠加层**，提示词分开写

`【白】` 只出声不现身：画面照常流动，与普通镜头无异，不需要上述任何处理。

## 六、内容纪律（doc/04 摘要，写每条提示词前过一遍）

1. **原文没写的元素一律不加**——包括"看起来更好看"的元素。补全只为可生成，不为好看
2. **光有出处**（4.3）；**物有使用痕迹**：木裂、布皱、墙污、金属氧化
3. **不美化**：允许普通甚至难看。老拐子必须脏；齐渊不做魔气黑雾红瞳；修为不体现在外表
4. **无来由的风、悬浮花瓣、发光眼、人物自发光——禁**
5. **术法三禁令**：禁喷火放电直球特效；禁粒子堆砌符文环绕；禁招式名字幕。
   术法作用于真实的东西（风向、水、影子、灯火），有痕迹、有代价
6. **打斗**：出手就是抬手，回合少；镜头多给在打完之后（伤口、喘息、旁观者的脸）
7. **构图**：多用中景中近景；大特写留给关键情绪与关键物件；不完美对称；手持感克制
8. **梦境/回忆**：边缘轻微失焦可写入提示词；「色相偏冷、降饱和」写在后期规则行
9. **洞天（S13）**：全场景无影（写明"画面中没有任何阴影"）；什么都不动；
   唯一例外见场景卡变体（起风、影泥沼、唐真施法后的淡影）
10. **奇观克制**：极远景、短时长、"远到不真切"；剧本让给几秒就是几秒

## 七、写作流程与自查

1. 通读本幕剧本段落（含幕首场景卡与 ★ 导演备注——备注是硬约束，如"不插入任何仙境画面"）
2. 对照 `data/chapters/chNNNN.json` 的 `paragraphs`（或 `s16` 出图包里附的原文段）核对剧本引用的原文段落，把画面细节挖尽
3. 人物/场景一律先查资产卡与补充基准卡，锁定特征逐条落实
4. 逐镜写作；写完过第六节纪律清单与 1.1 黑名单
5. 镜号清点：与剧本逐一对得上

**自查五问**：画面里的东西原文有没有？光有出处吗？物有使用痕迹吗？人被美化了吗？在炫吗？
