# 第一季分集方案

第一季 = seq 1~200，**47 集**，每集 2~5 章。分集表在 `data/plot/episodes.json`（`season == 1` 的 47 条），
47 集剧本全部写完，**边界已随剧本锁定**：`s10` 重跑时把有 `剧本.md` 的集原样保留，只重排其余季。

本文记录这 47 集是怎么定下来的，以及沿途作废的两版时长规格——留着是为了后人不再走一遍。

| 项 | 值 |

## 二、决策历史：时长规格作废了两次

### 2.1 试点：E01-E02 人工走通全流程

E01（seq1-4）、E02（seq5-8）是流水线验证试点：人工完整走一遍「逐章分析 → 资产 → 分集 → 剧本」，
并产出一套人工基准集（`manual_analysis/`，8 章，逐字命中率 100%、台词覆盖率 100%）。

分集边界不是我们切的，是原著自己划的：前四章是现实线开篇，后四章是标题就叫《梦里回头（一）～（四）》的完整回忆单元。

| 集 | 章 | 台词 | 独白 | 旁白 | 若全部配音的时长 |
| --- | --- | --- | --- | --- | --- |
| E01 | seq1-4 | 144 条 / 2783 字 | 50 条 / 2157 字 | 29 条 / 1402 字 | **27.6 分钟** |
| E02 | seq5-8 | 88 条 / 1880 字 | 88 条 / 2467 字 | 74 条 / 2554 字 | **29.8 分钟** |

（按中文配音 4.5 字/秒，台词间留白 1.2 秒计。）

### 2.2 第一次作废：「4 章一集」与「8-12 分钟」无法同时成立

按原则二逐条保留，E01 纯语音就要 27.6 分钟，与原定的 8-12 分钟差近 3 倍；即使砍光独白与旁白，仅台词也要 12.7 分钟。
三条路里 A 缩章数（约 480 集）、C 大幅删减（违反原则二）都不可取，**采用 B：4 章一集、25~32 分钟，质量优先**。

### 2.3 第二次作废：写到 E06 时，「25~32 分钟」也不成立

逐镜配秒实测 E01~E06 为 19:41 / 25:33 / 25:40 / 41:29 / 38:38 / 48:34，散得很开且方向不一致。
「一集多长」根本不是可以先定后写的东西：它是「这一集有多少内容必须落地」的结果。
**结论：不对时长做预设，专注内容。** 47 集写完后的实测从 19:41 到 162:10（逐集见 `doc/15` 第三节）。

`doc/00` 的规格表已同步。`s14` 仍报每集逐镜秒数合计，但**只报不拦**。

### 2.4 求解器的交叉验证

全书分集由 `s10_episode_plan.py` 求解（时长模型 `语音字数 ÷ 4.5 字/秒 × 1.20`，1.20 由这两集试点标定）。
求解器在不知道试点存在的情况下，独立算出 `S01E01 = seq1~4`、`S01E02 = seq5~8`，与人工试点完全一致，
估值 28.2 / 30.7 分也对上上表。方法见 `doc/08` 第五节。

### 2.5 边界锁定

2026-09 重构后 timeline 的人物列改用三级别名解析，卷段随之变化，重跑 `s10` 时 S01 有 16 集的边界会移动——
而 47 集剧本早已按旧边界写完，`s14` 也按它对账。所以 `s10` 现在把已有剧本的集锁死：
**第一季这 47 条永远是现在这 47 条**，除非人手动改剧本。

## 三、心理活动与旁白怎么承载

完整规范见 [`doc/05_唐假旁白系统.md`](../../doc/05_唐假旁白系统.md) 第五节，标记写法见
[`doc/13_剧本格式规范.md`](../../doc/13_剧本格式规范.md)。要点：

- **心理活动一条不删，全部配音**——角色本人声音，低音量、近场、无混响（`【心·某某】`）。
- **旁白不再全部配音**，判据只有一条：这条旁白的信息，摄影机拍得出来吗？

| 类 | 是什么 | 承载 |
| --- | --- | --- |
| N1 设定交代 | 来历、身份、前史、地理、动机 | 唐假（`【现】` 现身 ≤ 6 次/集，或 `【白】` 只出声） |
| N2 眼前动作 · N3 环境气氛 · N4 时间推移 | 摄影机拍得出来的 | 画面（`【画】`） |
| N5 断语格言 | 作者的评述、警句、吐槽 | 唐假或字幕卡（`【卡】`） |
| N6 冗余可删 | 信息已被同集别处覆盖**且**不是招牌句 | `【删】`，必须写被谁覆盖，删除率 ≤ 15% |
| N0 无效条目 | 原文残留（「。。。」） | 剔除，不计入删除率 |

**没有任何一条被降级为「不管了」**——每条关键旁白都必须在剧本里落到一个承载上并写明镜号，删掉的也要在账上。
`python pipeline/s14_narration_ledger.py --episode S01Exx` 五道闸门全绿才算写完。

## 四、E01 / E02 的幕结构（试点留档）

### E01《破庙三只眼》= seq 1-4

现实线开篮。用四章建立三件事：他是谁、他在哪、他为什么活着像等死。全集埋四个谜：额头黑印、腰间枯枝、白噪音般的系统、他见姚安饶时的失神。

| 幕 | 章 | 内容 |
| --- | --- | --- |
| 冷开场 | seq1 [1-11] | 梦境：被逐出师门，一代天骄一朝散尽 |
| 一 | seq1 [12-63] | 惊醒破庙 → 讲仙宫故事换粥 → 施粥 → 见姚安饶失神 |
| 二 | seq2 全 | 红儿赏银指路 → 老拐子暴打劝进 → 姚安饶记下这个少年 |
| 三 | seq3 全 | 换新衣上工 → 看落日 → 送红儿回府 → 羊下水宴 |
| 四 | seq4 全 | 唐苟安得名 → 日子渐好 → 红儿消失 → 噩耗 |
| 钩子 | seq4 [68] | 「麻绳只在细处断，厄运专找苦命人。」 |

### E02《梦里回头》= seq 5-8

全回忆。把 E01 埋的四个谜一次性拆开，并给出全书最重的一次情感冲击。结构上是一场**只用四道术法、二十步走完的对决**。

| 幕 | 章 | 内容 |
| --- | --- | --- |
| 冷开场 | seq5 [1-2] | 高烧不退，坠入比以往更真实的梦 |
| 一 | seq5 [6-63] | 紫云仙宫禁地：压制长老 → 系统交易 → 清风散破圣级大阵 |
| 二 | seq5 [65-92] + seq6 [1-31] | 洞天即牢房 → 这里没有春天 → 定下浪迹天涯 |
| 三 | seq6 [32-91] | 一阵不该有的风 → 齐渊现身 → 三个字：人魔尊 |
| 四 | seq7 全 | 琉璃灯真相 → 二十步之赌 → 四道术法尽被点评 |
| 五 | seq8 [1-70] | 不准过线被一抹擦平 → 桃枝相托 → 灯碎，满树桃花开 |
| 收束 | seq8 [72-78] | 那一夜九洲星海震荡；一个失了生机的少年落入凡尘 |

E02 的收尾直接接回 E01 的开头，两集构成一个闭环。
