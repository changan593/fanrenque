**这一集红儿第一次走到天下人面前，而且是自己选的走法。**

玉屏山要去两个人。郭师兄不去，小胖不去，姚安饶不在，连峰主自己都举手说不去。
唐真看向红儿，红儿抬起头，两个人对视了一眼——

> **「我随你去。」**

当晚她找姚安饶要了一套「有些邪典的方案」，然后敲响了唐真的房门。
第二天凌晨，赵辞盈在昏暗的天光里对着一身白裙行礼，喊了声「姚姑娘，好」。

**而她要面对的那个「天上的世界」，是这样的：**
二十八主峰入场，左右两侧廊道按新旧两派分坐，一边鼓掌另一边就得死一样安静；
一个灵兽崖的长老过来打听一条鱼，唐真跟他握了个手，摸出一身魔气；
最后进来六个年轻人，摆开架势，开始表演无道六贼。

**「致敬你妹啊！」**

## 附三：被看的一天

这一集只做了一件事：**把红儿放到所有人眼前。**

玉屏山要去两个人。郭师兄不去，小胖要做饭，姚安饶不在，峰主自己举手说不去。
于是唐真看向红儿——原文在这里没有给任何台词，只写了一次对视：

> **唐真的眼睛里有问询，红儿的眼睛里只有笑意。**

然后是四个字：**「我随你去。」**

吕藏锋几次抬头想拦，最后都忍住了。他担心的是一件很具体的事：
一个女孩跟在唐真身后走进那个场子，八卦会炸开，而**八卦比圣人至理传得还快**。
但原文说他想得太简单了——

> **他没见过南红枝。**
> **这与红儿的自我定位和唐真的想法完全无关，只和眉眼有关。**

### 她的准备：一套「有些邪典的方案」

当晚她去找姚安饶。原文只写了结果，没写方案内容：

| 步骤 | 原文怎么写的 |
| --- | --- |
| 求助 | 「但今日，红儿有些急，她需要帮助，需要姐姐的意见。」 |
| 方案 | 「姚安饶觉得很有道理，并给出了一套方案，**有些邪典的方案**。」 |
| 决定 | 「红儿犹豫，然后决定。」 |
| 执行（一） | 「晚些时候，红儿敲响了唐真的房门。」——**她把红钗还了回去** |
| 执行（二） | 第二天凌晨走出来的是**一身白裙**，而且「画了妆，有些精致又有些刻意的改了眉眼」 |

**她把自己往那张脸上又推了一步。**
那身红得似火的裙子不见了，温柔的眉被画得有些锋利，如水的眼多了俏皮——
**那是姚安饶的模子，而姚安饶的模子后面还有一个人。**

三个人看见了她，三种反应：

| 谁 | 反应 |
| --- | --- |
| 赵辞盈 | 行礼喊了声「姚姑娘，好」——**她认错了人** |
| 吕藏锋 | 两个字：「不是。」**全场只有他一眼就看出来了** |
| 唐真 | 什么都没说。但一路上他做了个梦，**梦到一株白瓣红蕊的花在开放，花上凝着露，像是在哭** |

而她自己转了个身：**「白色的花像是要绽放，又像是要凋败。」**

> **她努力的想向情郎展示着自己的风采，又偏执的想向世界述说着自己的不同。**

### 而她要面对的「天上的世界」，是这样的

| 场面 | 内容 |
| --- | --- |
| 座位 | 左右两侧廊道按**革新派与守旧派**分坐 |
| 规矩 | 一边鼓掌，另一边就必须**安静得像没有活人**；唐真跟着鼓了两下，被周围人狠狠地瞪 |
| 玉女峰入场 | 这边全体起立，有人放烟花术法；赵辞盈挥手，两个漂亮姑娘一互动，**很多人的目光过来了** |
| 金童峰入场 | 这边整齐划一地落座，还刻意大声交谈；对面掌声雷动 |
| 百剑峰入场 | **全场第一次两边同时站起来** |
| 结果 | 「从为自己支持的鼓掌，开始演变成给对方支持的嘘声。」 |

唐真的评价是六个字：**「许圣的手段实在是朴实。」**
然后补了一句：**「但。。。很有用。」**

**红儿在这里做了这一集第二个动作**：深呼吸，拍打并无灰尘的裙摆，抿嘴唇，
把椅子往唐真身边挪了挪，坐直，**「像是一只要战斗的鸟雀」**。
吕藏锋看见了，想了想，也往那边坐了坐，与她形成对称，把响雷抱在怀里。
唐真不知道该说什么，于是倒了两杯茶。

### 然后那六个人走了进来

| 谁在演谁 | 台词 |
| --- | --- |
| 拿书的书生 | 「为天地立心！为生民立命！为往圣继绝学！为万世开太——平！」**（横渠四句）** |
| 同一个人，第五句 | **「为朋友守真情！！！」** |
| 小和尚 | 「贫僧此次不为除魔！只为守心！！」 |
| 瘦书生 | 「小生愿以吾道换吾友！」 |
| 绿袍女修 | 「落子！无悔！！」**（落子的同时袖袍里补了一张符箓，「大体应该是补个光效」）** |
| 披发提壶的女剑修 | 「什么几时长剑在手，什么什么圣人低头。。。」 |
| 紫袍道士（压轴） | 「圣人难算，我亦算！魔尊难阻，我亦阻！」**（外加一场桃花）** |

**六个人，一个名字都没报**——因为师门不让明面来。
吕藏锋一边鼓掌一边给唐真做解说，还嫌狂剑仙那位「差点意思」、桃花散那招「有点俗了」。
唐真从「有种不好的预感」一路瘫到「心死了」，最后说出五个字：

> **「致敬你妹啊！」**

**而这一整场闹剧真正的作用，只有最后两镜写了出来：**
身后有人给出评价——「我觉得还挺有意思。」
他怒目回头，看见的是**红儿捂着嘴笑面如花**。

她绷了一早上，是这场把她男人演成鬼畜的闹剧让她松开的。

### 最后一个地缝

原文用一个词把两个相隔千里的场景接了起来：

> **「这表演虽然让人想找个地缝……」**
> **「地缝是个很好的东西，但是并不是哪都有。」**
> **「周东东此时也像他的大师兄一样想找个地缝钻进去。」**

一个九岁的剑修，在通城河边最热闹的地方被几个十几岁的姐姐揉脸，
梗着脖子只问一句「我。。妹妹呢！？」。
胡九来解了围，幺儿递过来一个大苹果，他不接，坐到对面看窗外的江面夜景。

**然后小姑娘发现，这个「被全天下欠了钱的小道童」眼圈红红的。**

## 附四：六次现身档的分配理由

**第九次用满 `doc/05` 5.7 的六次上限**（前八次是 E20、E23~E29）。
这一集的六次只有两次是正条，其余四次都写了 `※`——
因为这一集最需要停下来的地方，恰好都是抽取归入心理活动而无归属人的判词。

| 镜 | 承载 | 为什么要停下世界 |
| --- | --- | --- |
| 031 | seq117[30] | **吕藏锋没说出口的那句话。** 他几次抬头都忍住了，唐假替他说完：一个女孩跟在唐真身后，这消息会炸开——**「八卦狗血的消息是天下传播最快的消息，比圣人至理还要快！」** |
| 058 | seq117[55]（非正条，写了 `※`） | **第二幕的落点，也是这一集的题眼。** 白裙转身定住，唐假把这个动作拆成两个方向：一半是给情郎看的，**一半是给全世界看的**。少了这一停，那个转身就只是好看 |
| 124 | seq119[12]（非正条，写了 `※`） | **全剧第一次为「观众知道而主角不知道」停下世界。** 唐真的推理走到一半就断了，而答案在 E11 镜175-186：那只蜘蛛、那一剑、以及尸体旁的一段对话。**唐假说的第一个字就是「唐真并不知道」** |
| 185 | seq119[70] | **第五幕的结账。** 掌声变成了嘘声——这是许圣那套「朴实手段」的产出物，**画面上只有一群人在起立坐下** |
| 266 | seq121[12][13]（非正条，两条都写了 `※`） | **全集最好笑的一次静止，也是唐假第一次替观众吐槽正在被扮演的那个人。** 「这是什么鬼畜小说描写。」——留满一拍——**「那是鬼畜的自己。」** |
| 281 | seq121[27]（非正条，写了 `※`） | **第七幕的落点，也是这一集真正的结论。** 上一镜是红儿捂着嘴笑，这一镜唐真给整场闹剧结账：**「也不算是全无作用吧」**——而它的作用就在上一镜那张脸上 |

**为什么镜026「我随你去」没有现身档**：
四个字，全集最重要的一句台词。
但原文写的是「她说的很轻，但很坚定」——**轻**是这句话全部的力量。
世界一停，它就变成了宣誓；不停，它才是一个人小声做完的决定。
**而它前面已经有一镜纯画面的对视了（镜025），那一镜才是它的重音。**

**为什么镜278「致敬你妹啊」没有现身档**：
五个字，本集最大的笑点。但它是**唐真被逼到极处的一句脱口而出**，
而且它需要立刻被下一镜打断——身后传来红儿那句「我觉得还挺有意思」。
**停下世界会让这个笑点变成结论，而它其实是个铺垫。**

**为什么第三幕（灵兽崖的长老）整幕没有现身档**：
那一幕是一场对话，两个人各说各的假话，全部的信息都在台词和一次握手里。
**唯一需要补的一句「他不仅见过，还做成鱼汤吃过好几次呢！」是个笑话**，
它得跟着唐真那张笑脸一起走，停下来就冷了。
