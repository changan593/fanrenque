**这一集有人送来了一份能改命的礼物，晚了五天。**

烧完的响林在天亮后被两个女人一寸寸翻检——一个用锄头拨开焦炭，
一个蹲下来捡还能用的祈愿牌，脸上黑得找不着人，**但她笑得很爽朗**。
唐真站在旁边说了六个字：「种树吗？我擅长。」

同一天，玉皇顶上一位准圣蹲着看一棵本该昨天就死掉的嫩芽；
南洲的通城河上，一个九岁的剑修、一个八九岁的丫头和一只九尾狐在船里买糖葫芦；
忘园的竹椅上，唐真给一个天赋一般的小丫鬟讲了一套专门为她设计的功法，
然后骗她说那是「我朋友」给的。

下午来了一个胖和尚。他从婆娑洲一路飞来，僧袍上那层尘土故意不肯拍掉，
因为那是用来压住修为的——**他本来是一位菩萨。**
他在悬空寺最底层坐了两年，坐出了一条能让唐真彻底摆脱「无法」的路。

**唐真说：「你来晚了。」**

## 附三：两份礼物

原文自己把这一集的两件事并到了一起（`seq115[61]`）：

> **「说到底这套‘心佛’就跟唐真为红儿改良的‘吞灵法’一样，
> 核心不是法术多么高妙，而是‘灵气实体’和‘佛宗大道’这种巨大的后台实在珍贵。」**

| | 第四幕：吞灵诀 | 第六~七幕：心佛 |
| --- | --- | --- |
| 收礼的人 | 红儿，天赋一般，认真刻苦却悟性一般 | 唐真，被「无法」锁了两年 |
| 功法本身 | 地阶，古老，简单老套，不讲悟性 | 三千佛经读出来的，能绕过「无法」 |
| 真正值钱的 | **那块凝结的灵气实体** | **佛宗大道这个后台** |
| 送礼的人怎么说 | 「来自我朋友的很新且未公开的版本」 | 「和尚我蹲在悬空寺底两年，给你想了个药方」 |
| 真相 | **是一套专门为红儿所设计的功法** | **阿难与摩诃伽叶轮班守着他，让他悟出来的** |
| 收下了吗 | 收下了，装在一只画着木棉花的破茶壶里 | **退了回去** |

**两份礼物的结构一模一样：一个人把最珍贵的东西藏在一句轻描淡写的话里，
送给一个自己觉得值得的人。** 区别只在最后一栏。

退回去的理由是两个字：**佛缓**。
那是 E27 第一幕唐真自己讲的一节课——「佛宗修士术法多是修身修心，
实在缺乏赶路的手段……即便是佛宗二圣也是出了名的慢腾腾」。
这一集它变成了一句判决：

> **「你若早十日，不！早五日！我或许真的会犹豫，最终也确实可能去尝试心佛。」**
> **「佛缓，佛缓。。。真是慢了一步啊。」**

### 红儿这一集只做了一件事：递了一杯茶

她见过三位「故人」：

| 谁 | 她的样子 |
| --- | --- |
| 野狐禅师（E12 第一幕） | **愤怒迷茫**——那时她还没意识到自己的敌人是谁 |

| 知了和尚（本集第六幕） | **沉默，但不是隐忍。她丝毫没有躲避的打算** |

第三次，她坐下来泡茶，「很坚定露出了自己那张不知道到底哪里像了谁的脸」。
胖和尚看懂了，于是他跟她说的第一句话是讨一杯茶。

而唐真在这一整段里做的事是：**垂着眼没有去看这一幕。**

**为什么镜275「假的，都是假的」没有现身档**：
这是全剧第二次唐假在故事里现身开口（第一次是 E24 第二幕，中间隔了五集），
但**这一次他是场上的角色，不是叙述者**——他站在唐真身后，
对着满天神佛说话，而那些神佛真的散了。
**给它一个现身档等于把它降格成一句旁白。** 它是这一幕的动作，不是这一幕的注解。

**为什么镜273 用的是字幕卡而不是现身档**：
原文在这里只写了两个字：「唐假。」
它是一个**名字的出现**，不是一句判词——对位 E24 镜056，
那个名字第一次出现时也是唐真自己起的。
**黑底白字两个字，比任何解释都准。**

**为什么第三幕整幕没有现身档**：
通城河那一幕全是外部观察：一个才子看痴了，一个九岁的剑修在生气，
一个丫头露出断了半颗的门牙说「人间真美」。
**这一幕唯一需要补的信息（周东东为什么同意来）由他自己的内心音讲完了**，
唐假在这里没有事做——**而且这一幕最好的效果就是让观众和那个才子一样，
看不出眼前这三个人到底是什么。**
