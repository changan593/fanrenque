## 这一版的修订（V5→V6）

V5 的图出来是**脸偏圆、没有特色、不够好看**。三个病根，逐条拆。

### ① `seq314[13]` 不是容貌定调，是念娘的一次侧写——**病根在这里**

V5 把这句话标成「★ 容貌定调（唯一一处正面评估）」当硬约束用。回原文看语境
（`seq314[6]~[17]`）：马车里念娘劝红儿把金银兑成银票，红儿只淡淡应了声「好。谢谢。」；
念娘替她着急，觉得她「没有什么危机感，还是那副平平淡淡的样子」——
**然后才是那句评价**，而紧接着的下一行是：

> 【原】「于是藏在心底很久的问题终于下意识的从嘴里滑了出来。」
> ——「红儿姐，我能问问真君是个什么样的人吗？」（`seq314[14][15]`）

三件事因此确定：

| | |
| --- | --- |
| **谁在说** | **念娘**，不是旁白。这是她「凭什么是她」的困惑，是人物心理，不是客观定妆 |
| **什么时候** | **第 314 章**，红儿早已成年（`seq65[26]` E01 后不久就接近十八）——与 E01 隔着三百章 |
| **干什么用** | 是**设问的铺垫**：这句评价存在的唯一理由，是让念娘问出下一句 |

所以它限制的是「**不要画成妖艳绝色**」，**并不授权「画成寡淡」**，
更管不到 E01 那个十五六岁的红儿。V5 把它当成母版的容貌上限，是**读错了层级**。

- ★ **明眸**：全片最亮、最清的一双眼。虹膜边缘锐利、瞳孔与虹膜对比高、

  这个世界满是缺牙、黄牙、黑牙（`C03` 老拐子锁定项4、`G01` 乞丐群像）。

- ★ **那点凶**：`seq2[13]` 唐真第一眼觉得她「有些凶」，`seq314[13]` 念娘觉得「眉眼温柔」。

  这是她的表情特色，也是与南红枝（暖笑迎人、静时也软）最清楚的分道。

「闪闪发光」怎么落地：`seq2[1]` 是唐真的**主观观感**（正午逆光、白裙小姐旁边那个红裙丫鬟），

全书「闪耀」类词一共只用过一次（`doc/10` 词频），用在她身上，所以这一条要认真做。

## dossier 硬约束（不许被覆盖）

### 「好看但不绝色」这句话管什么、不管什么

`seq314[13]` 是**念娘在第 314 章的侧写**，不是旁白定论（语境拆解见「这一版的修订」①）。
它是一条**上限**，不是一条**目标**：

| 它管住的 | 它**管不到**的 |
| --- | --- |
| 不许妖艳 | 清丽 |
| 不许攻击性的压倒式绝色 | 灵动、上镜、耐看 |
| 不许浓妆、成人性感 | 明眸皓齿这个**原文特色** |
| 不许强个性化的奇特长相 | 女主级的镜头中心感 |

原文自己给的正面词一条都不许打折：

- **明眸皓齿** ✅（`seq1[59]`，登场第一个词）
- **闪闪发光** ✅（`seq2[1]`，唐真的第一眼，用摄影做不用光效做）
- 好看 ✅（不是丑，也不是寡淡）
- 眉眼温柔 ✅　／　静时有点英气 ✅（`seq2[13]`，两者是同一张脸的静与笑）
- 唇色微淡 ✅（不是浓艳）
- **算不得妖艳绝色** ★（唯一的上限）

她的美感来自**明眸、皓齿、漂亮的同源眉眼、清透骨相、灵动利落和镜头中心感**，
不来自浓妆、尖脸、成人性感或猎奇长相。

## 灵动的具体化（是利落，不是幼态）

原文里她一直在动，画出来才是她。以下**都是可视化的状态倾向**，母版表情组要能覆盖。
★ 注意分寸：**灵动＝动作干净、反应快、落地轻**——是麻利能干的年轻姑娘，
**不是蹦蹦跳跳的小孩**。V2 拿「兔子」当总纲是错的：`seq3[42]` 的兔子
只是偷吃被抓那**一个瞬间**，不是人物基调。

- 「一分骄傲九分笑」是**表情基准**：嘴角微扬、下巴微抬、眼睛弯起——**常态而非偶尔**
- **歪头**：跟人说话时头略歪向一侧，招牌姿态
