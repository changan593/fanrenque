## ★ 这张卡与 `01_Q版` 的关系：几乎每一条都是反的

前 23 集观众看到的是一个二头身小人，站在画框边上念旁白，
**看久了会当成一个无害的画面装置**。`seq93` 的全部力量来自**这个装置忽然变成了人**：

| | `01_Q版旁白装置`（E01~E23） | `02_等身版`（E24 起） |
| --- | --- | --- |
| 比例 | 二头身 | **与唐真完全等身** |
| 世界 | **静止**（冻结一切） | ★ **不静止**——正常流动 |
| 空间 | 画框纸面上，不进景深 | ★ **在场**：有景深、有位置、坐在唐真对面 |
| 互动 | 不碰东西、不被注视 | ★ **对话**：唐真看着他、问他、他答 |
| 观感 | 无害的画面装置 | ★ **他一直都在这儿** |

★ **所以这张卡不许有一丝 Q 版的痕迹。** 揭底那一刻若还带着可爱感，机关就废了。

## 本形态的规格

### 一、与唐真等身、同脸、同衣——**唯一的分辨点是那四处**

★ **这一刻他和唐真长得一模一样地坐在对面。**
观众要靠 `00_身份母版` 的四处分道来分辨谁是谁：

| 分辨点 | 唐真（本体） | 唐假 |
| --- | --- | --- |
| ★ **抹额** | **在他身侧**（`seq93[50]`）——他刚摘下，黑印**外露** | **没有**，也永远不会有 |
| 黑印 | 工整、哑光炭黑 | **淡一档、边缘略虚** |
| ★ 眼神 | 死气、压着 | ★ **亮、活、好奇** |
| ★ 影子 | 有 | ★ **没有**——竹屋里两个人对坐，**只有一个人有影子** |

★ **「只有一个人有影子」是这场戏最好的一个镜头**，
建议给一个俯视或侧逆光的机位专门交代它。

### 二、唐真此刻的状态（对位用，不在本卡管辖）

`seq93` 时唐真处于 **`C01_唐真/03_白色抹额期`**，但**此刻抹额已摘下放在身侧**——
所以他**黑印外露**、白道袍、盘膝。对面的唐假穿的是**青灰旧布袍**（母版锁定项②），
**两人服装不同**，这也是一个分辨点。

### 三、表演

- 基准表情：★ **「笑了笑，露出一种悲哀的表情」**（`seq93[59]` 逐字）——
  **这是全片唐假唯一一次悲哀**，也是他最重要的一个表情。
  ★ 注意：**悲哀在眉与嘴，眼睛仍然是亮的**（母版锁定项④不许破）。
- 姿态：盘腿对坐 → **抬头看天花板** → **前倾逼近到面前**（`seq93[64][65]`）。
- 松垮（母版）：即使盘坐也**不做唐真式的挺直**。
