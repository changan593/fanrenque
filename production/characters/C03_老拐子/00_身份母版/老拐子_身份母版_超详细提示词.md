## 这张卡是全片质感的定盘星

`doc/04_风格规范.md` 2.4 的判据「允许普通，甚至允许难看」在他身上是**最硬**的一条。
`style_test/matrix.json` 的 T03 之所以被标成「★ 最关键的一测」，测的就是他：

> 出来的人必须让你觉得不太想靠近。缺牙必须真的缺、皱纹必须像干裂的泥地、脸必须脏。
> **看着像可爱老爷爷即为不合格。**

所有生图模型都强烈偏向把老人画成慈祥、干净、仙风道骨。这张卡的负面段比正面段更要紧。
**他做干净了，全片的底色就塌了。**

## 这一版的修订（V1→V2）：给「残疾」建一道反正常化防线

V1 的图**脸做对了**（脏、皱、缺牙、胎记都到位），**但右脚做成了正常脚**，
而且给他穿了草鞋——**把唯一的判据遮住了**。验收表第 4、5 条直接不成立。

病因和「慈祥老爷爷」是同一个：**生成端会把身体自动正常化**。
V1 只给「反美化」建了防线（那一段很有效，脸就是靠它守住的），
**却没给「反正常化」建**，右脚的规格还埋在 `Body:` 段中间一句话里。

V2 三件事：

1. ★ **把右脚提到提示词第一段**，和 `C02` 把「那个笑」提到第一段是同一个办法；
2. ★ **把萎缩写成解剖学而不是形容词**——不只是「脚小」，是**整条右下肢的失用性萎缩**
   （小腿围明显细于左侧、跟腱细、足弓塌陷、前足内翻、只有外侧缘着地）。
   给模型解剖链条，它才画得出来；只说「萎缩的脚」它会当成修辞；
3. ★ **脚部特写必须赤足、左右并置、同尺度**——**不许穿鞋**。
   V1 那双草鞋不是造型选择，是把验收判据遮住了。

**这一条是他的名字。** 他叫「老拐子」，全片所有人这么叫他；
`seq1[28]` 写明他因这只脚被父母卖掉、连人牙子都不收。**脚做不出来，这个人就不成立。**

## 跨版本不可变身份

1. 中国老年男性，视觉年龄约六十岁但看着更老（讨了一辈子饭）；身高约 160cm。
2. ★★ **先天右下肢萎缩**（`seq1[28]`）——**本卡第一锁定项，做不出来整张作废**。
   写成解剖学，不写成形容词：

   | 部位 | 规格 |
   | --- | --- |
   | 右足长 | 比左足**短约两指宽**（≈ 小一到两码），且**更窄更薄** |
   | 前足 | **内翻约 30°**，足底朝内；**只有外侧缘与小趾球着地**，第一跖骨头离地 |
   | 足弓 | 塌陷变形，足背高拱、趾骨蜷曲不能完全伸展 |
   | 踝 | 内踝异常突出，踝关节活动受限、位置比左踝低 |
   | ★ 小腿 | **右小腿围明显细于左小腿**（失用性肌萎缩），腓肠肌几乎没有隆起，跟腱细而突出 |
   | 皮肤 | 右足**外侧缘**有厚而黄的胼胝（长年只有这里受力），足背皮肤薄、青筋可见 |

   ★ **这不是伤，是先天畸形**，形状在所有视图中完全一致。
   ★ **萎缩是整条腿的事**——只把脚画小、小腿照常粗壮，是最常见的错法。
3. 因右下肢萎缩形成的**永久性代偿体态**：左肩明显高于右肩（**肩线倾斜可量，约 3~5°**），
   骨盆右低左高，整个躯干向右倾约十度，脊柱轻度侧弯，颈部反向代偿地向左偏一点。
   ★ **站着也倾，不只是走路时倾**；★ **重心永远压在木棍与左腿上，右腿只是点地**。
4. 明显佝偻，胸廓塌陷、背部上段隆起；这是长年拄棍与营养不良的结果，不是一时的弯腰。
5. **额头正中偏左有一块不规则褐色片状胎记**（`seq1[30]`）：边缘模糊、颜色深浅不匀、
   形状不规则。**必须与唐真那枚工整的竖椭圆黑印形成一眼可辨的对照**——
   老拐子把唐真误认成同类，观众要一眼看出两块印记根本不是一回事。
6. 深褐色的日晒风吹脸，颧骨突出、两颊深陷、太阳穴凹；
   **皱纹极深且交错纵横如干裂的泥地**（原文「像是旧抹布」`seq1[31]`）。
7. 眼小而浑浊，上眼睑下垂盖住部分瞳孔，眼白发黄，下眼睑外翻露出一线红；
   眼角常年有干涸的泪痕与污垢。
8. 鼻头肥大、鼻翼外张、毛孔粗，鼻背有细密破裂的红血丝。
9. **缺三到四颗牙**（上门牙区缺一颗、下侧后方缺两到三颗），
   剩余牙齿发黄发黑、参差不齐、牙龈萎缩露出牙根。嘴唇干瘪起皮、常年抿不严。
10. 双耳大、耳垂长而下坠、耳廓边缘有老年角化的粗糙感。
11. 头发花白稀疏、打绺结块、发际线后退且不整齐；胡须杂乱未修剪、长短不齐、常沾食物残渣。
12. 双手枯瘦，青筋暴起，指关节粗大变形，指甲厚黄开裂、缝里全是黑泥。
    原文两次强调这双手：「用**干枯的手**去揉了揉唐真乱糟糟的头发」`seq2[11]`、
    「**干瘪的骨头硌唐真心疼**」`seq2[35]`——**手必须瘦到硌人**。
13. **乌漆麻黑的粗木棍**（`seq2[49]`）：约齐胸高，棍身乌黑发亮、被手掌磨出包浆，
    握持段有一块明显更亮的磨损区；底端因常年戳地而劈裂发毛。**它是身份的一部分，不是道具。**

## 身份母版画面规范

- 横版 3:2，浅暖灰摄影棚背景，无环境叙事。
- 85mm 等效焦距、视平线机位、无景深、无广角畸变。
- 左侧大幅中性三分之四胸像；额头胎记特写；张口露牙口特写；双手特写。
- ★★ **双脚对照格（必须有）**：**赤足**，左右脚**并置同尺度**，正面 ＋ 前三分之四两个角度。
  要能直接比出：长度差、前足内翻、外侧缘胼胝、内踝高低差。
- ★★ **双小腿对照格（必须有）**：**赤足**，左右小腿并置同尺度，比出**小腿围的差**。
- ★ **两格都不许出现鞋、草鞋、裹布**——遮住脚等于遮住本卡第一判据。
- 右侧同一眼线、同一尺寸的 0° 正脸、45° 三分之四、90° 侧脸。
- 下方全身正面、侧面、背面三视图，**赤足**。**注意：他不能站 A-Pose 标准直立**——
  三视图必须如实呈现右倾体态、倾斜的肩线、更细的右小腿与内翻的右脚，用木棍支撑。
  **这是身份不是姿势**，也不许把两腿画匀。
- 表情组：中性疲惫、咧嘴笑（皱纹全挤在一起、露缺牙、眼眯成缝）、近乎凶恶的张嘴、
  低头看自己右脚时的松弛、暴怒咬牙。
- 色板：日晒肤色、阴影肤色、胎记褐、发色花白、虹膜浑浊褐、牙黄黑、破袄深褐、木棍乌黑。

## 身份验收

### 先过残疾四条（V2 新增；不过就不用看别的）

- [ ] **双脚对照格存在且赤足**，左右并置同尺度
- [ ] 右脚**明显更短更窄**，前足**内翻**、只有外侧缘着地，外侧缘有胼胝
- [ ] ★ **右小腿明显细于左小腿**（有双小腿对照格为证）——只把脚画小不算过
- [ ] 三视图里**站立静止**时右倾体态与倾斜肩线都在，两腿受力不均

### 再过原有各项

- [ ] 各角度瞳孔间距、鼻翼宽度、嘴宽、下颌宽度稳定
- [ ] 正脸与侧脸属于同一头骨
- [ ] 额头胎记**不规则**、边缘模糊，且与唐真的工整黑印明显不同类
- [ ] 张嘴视图里缺牙数量与位置固定，牙色发黄发黑
- [ ] 双手瘦到看得出骨头，指甲缝有黑泥
- [ ] 木棍的包浆磨损带位置固定
- [ ] **他是脏的**——脏在皱纹里、指甲里、头发里、衣襟上
- [ ] 看着不像可爱老爷爷（T03 验收线）

## 硬性拒收条件

- 脸干净、皱纹柔和、牙齐全或洁白
- ★★ **右脚被画成正常脚**，或**右小腿与左小腿一样粗**——V1 就是栽在这一条
- ★★ **穿了鞋／草鞋／裹布**把脚遮住——判据被遮住即不合格，不看其他项
- 体态挺拔、肩线拉平、两脚均匀受力站直
- 木棍变成雕花手杖或法杖
- 额头胎记被画成工整几何形，或与唐真的黑印同款
- 出现慈祥感、仙气、圣光、轮廓光美化
- 任一格脸部骨相偏离身份母版
