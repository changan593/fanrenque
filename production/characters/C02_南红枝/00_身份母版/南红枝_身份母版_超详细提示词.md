## 这一版的修订（V3→V4）

V3 的图出来是**脸偏圆、笑容泛泛**，和红儿（`C04`）同批被退。**两张卡犯的是同一个错。**

### ① 去圆脸：把否定词换成正向骨相——**病根**

V3 这一节写的是「颊部保留十六岁少女的柔软度但**无**婴儿肥」「**不做**肉圆脸」，
而且开头就是「**柔润**的小鹅蛋脸」、修订说明里还写着「**保留娇养感**」——
**一边用否定词压、一边用正向词要圆**，生成端当然给圆脸。

V4 改成正向骨相：颧弓、颊侧平面、下颌缘逐项给形，判据换成**三条可量的线**
（见「骨相」一节）。她**仍然比红儿柔**，但柔体现在**比例参数**上（面型更短、下颌更宽一档），
**不体现在脂肪上**。

### ② 「那个笑」从描述升格为可验收的记忆点

`seq302[49]` 逐字写着她的记忆点「**从不是长相**，而是……那**永远温柔让人舒适的笑容**」——
**这张卡的全部价值就在这一个笑上**，她只活到十六岁，全书 91 章只以回忆出现，
观众记不住这个笑，这个角色就立不住。

V3 已经把笑写得很细，但**没有写进英文提示词的开头**，也没有进硬性拒收条件，
结果生成端把它当成了普通的「微笑表情」。V4 把它提到提示词第一段，
并且**把左颊单酒窝与月牙眼定为拒收项**：没有这两样，整张卡作废。

### ③ 与红儿的分道写实

同源锁只管眉眼，**颊部以下本来就归各卡自己**（同源锁不动）。
V4 把两人的分道全部数值化，见「骨相」一节的对照列。

此后 91 章里她**只以回忆、遗物、灵位和别人的转述出现**。

**三条使用规则**（同源锁原文，两张卡都要遵守）：

1. **上半脸必须高度同源**：同源段锁的是从眉骨、眼眶、双眼皮折线到卧蚕的完整模块，
   不是只锁一个抽象的“眼型”。近景把两人的眉眼裁下混排，应先读成同一母系近亲，
   轮廓叠合感不低于八成。脸型、鼻、唇、下颌、肤色、身形、发式仍要分开——两人不是双胞胎。
2. **分道分在肉上**：南红枝的默认表情是**暖笑迎人、眉尾放松下落**；
   红儿的默认表情是**收着的、一分骄傲九分笑**。区别全在表情肌，不在骨头。
   各自的**固定不对称也不共享**（南红枝：右眼外角略低＋左颊单酒窝；
   红儿：笑时右嘴角略高）。
3. **距离规则**：这份相像只在**近景与眉眼特写**里成立，且要**认识南红枝的人**才看得出。
   全身远景、画像、通缉令上**不许认错人**——
   【原】「天命阁那画像也没见和红枝姐多像！」（`seq227[42]`）。

## 跨版本不可变身份

### 年龄与体格

- **剧情年龄十六岁**，视觉预设为十六至十七岁的清丽少女——**不做幼童，不做二十岁以上的成熟脸**。
  她死在这个年纪，全书的每一次闪回都停在这里。
- 身高约 159cm，**7.5 头身**；身量轻长、腰细、四肢纤长，脖颈修长，肩窄但打开，
  **锁骨是一条清晰但纤细的横线**，**锁骨上窝可见**。她比红儿更柔、更静，
  柔在**比例**（面型更短一档、肩更薄、骨架更未长成），**不在脂肪**。
- 体格清瘦匀称、骨量轻，不干瘪、不病弱、不做成年曲线。宗门嫡传、被父亲藏起来保护的女孩，
  **没有劳作痕迹**：手指纤细、指甲干净、掌心无茧。
  ★ 与红儿（丫鬟，`C04`）的手**必须明确不同**——那是阶层最诚实的证据。

### 脸（眉眼以同源锁为准，以下是她独有的部分）

- **小鹅蛋脸，骨相读得出来**——规格见下面的「骨相」一节（V4 新增，替代 V3 的否定式写法）。
  ★ 与红儿的分道**只在颊部以下**，且是**比例差**不是**胖瘦差**；两人上半脸必须高度相像。
- 鼻梁**低而直**，鼻头**圆钝小巧**，鼻翼窄。★ 与红儿（鼻梁直而秀、略挺）**明确不同**。
- **嘴唇偏厚，唇珠明显，嘴角自然上扬**，唇色是健康的**淡樱色**，不涂不描。
  ★ 与红儿（唇形轮廓清晰、唇色微淡）方向相近但**厚度与色感不同**。
- 皮肤白皙细腻**有血色**，清透而保留真实肌理；不做颊红妆——脸红是情绪（`seq6[55]`），不是常态。
- ★ **美感定位**：清丽、灵动、温暖、第一眼就有女主级镜头吸引力；这种好看来自眉眼同源骨相、
  轻长比例和会先笑起来的眼睛，不来自浓妆、尖脸、夸张大眼、珠宝或成人性感。
- **固定不对称（母版锁定项，不与红儿共享）**：右眼外眼角比左眼低约 0.5mm；
  笑起来**左颊有一个浅酒窝，右颊没有**。所有角度、景别、表情必须保留。

### 骨相（V4 新增，替代 V3 的否定式写法）

★ **生成模型对否定词不敏感、对结构描述敏感。** V3 那句「柔润的小鹅蛋脸……无婴儿肥」
是自相矛盾的指令，**圆脸就是这么来的**。下面每条都写「是什么」。

| 部位 | 南红枝 | 对照：红儿 `C04` |
| --- | --- | --- |
| 面长 ÷ 颧宽 | **≈ 1.28**（更短一档，这是她「柔」的来源） | ≈ 1.35 |
| 下颌宽 ÷ 颧宽 | **≈ 0.76**（下半脸略宽，轮廓更圆和） | ≈ 0.72 |
| 颧弓 | 位置中等、弧度柔缓，**中性光下仍能看出一道横向转折**——只是比红儿浅 | 偏高，转折明确 |
| 颊侧 | 颧弓下方到下颌缘之间**仍是微微内收的平面**，内收幅度比红儿浅；**面中部无脂肪垫** | 内收明显 |
| 下颌缘 | 从耳垂下方到颏部是**一条连续清楚但柔和的线**，下颌角圆和而**位置可辨** | 下颌角可辨认，线更利落 |
| 颏部 | 圆而收，不短、不尖、不前突 | 颏尖圆而不钝 |
| 颈肩 | 颈细长；**肩比红儿更薄**（十六岁尚未长成），肩峰点清楚 | 肩窄而打开 |

★ **她的「柔」是比例给的，不是肉给的。** 这一条是 V4 的全部要义：
把 1.35 换成 1.28、把 0.72 换成 0.76，两张脸自然分得开，**不需要给她加一层脂肪**。

#### ★ 三条可量判据（与 `C04` 同一套，验收只查这三条）

1. 正面中性光下，**颧弓转折与下颌缘两条线都读得出来**（可以浅，但必须存在）；
2. 侧 45° 时，**颊侧是内收的平面**，不是外凸的圆弧；
3. 颈根部**锁骨上窝有窝**。

**三条任一不成立即判「画胖了」，退回重做。**

### 头发

- 黑色长直发，发量足，发质好（有人打理），**齐腰**。
- 常态：**双环髻或简单低髻**，素色绢带与一两支素木簪／白玉小簪，**无繁复金饰**。
  ★ 与姜羽（`C17`，满头珠钗宝玉）**位于对立面**：
  南红枝是被保护起来的清素，姜羽是天生凤凰的华贵。
- 鬓角碎发柔软，垂在耳前。发际线圆润，中分或极浅的偏分。

### 那个笑容（本卡的核心）

四条原文全部指向同一件事：**她的记忆点不是长相，是笑容。**

- **【原】`seq302[49]`**　「周东东对红枝姐的记忆点**从不是长相**，而是一种模糊的感觉，
  最显着的是那**永远温柔让人舒适的笑容**」

所以身份母版**必须把这个笑做成锁定项**，标准如下：

| 要素 | 规格 |
| --- | --- |
| 眼 | **眼睛先笑**——下眼睑上抬，眼裂弯成月牙，眼尾下沉，**不是只咧嘴** |
| 嘴 | 嘴角上扬幅度**中等**，露上齿 2~4 颗，**不做八齿大笑，不做抿嘴微笑** |
| 颊 | 左颊酒窝出现，苹果肌上推，眼下卧蚕更明显 |
| 眉 | 眉尾**放松下落**，眉头不锁——这是「亲和」的解剖学来源 |
| 头 | 微微偏向对话者，下颌略收，视线迎上去**不躲** |
| 温度 | **让人舒适**：不是讨好的笑，不是甜妹的笑，是「我很高兴见到你」的笑 |

★ **反面**：不做嘴角上扬眼神冷的营业笑，不做垂眼羞怯笑，不做仰头大笑。
★ **与红儿的分道全在这里**：同一副眉眼骨架，她的表情肌是**打开迎人的**，
红儿的是**收着的**。两张卡的表情组并排看，必须一眼分出谁是谁。

## 服装（跨全季不变）

**紫云仙宫嫡传弟子女装制式**，与 `G05` 弟子群像同制，但用料等级更高：

- **青蓝色交领右衽长袍**（沉青蓝，与 `G05` 同色号），中袖，及踝。
  ★ **无织带**——她是弟子不是长老（分档见 `G05` 位阶对照表）。
- 素白内衬，**浅青或月白布带束腰**，系法简单。
- 用料是**上等素绸**：垂坠更好、光泽更含蓄、织纹更细——这是与 `G05` 普通弟子唯一的
  可见差别，靠**材质**不靠装饰。
- 无纹、无绣、无金、无玉、无法器、无佩剑。
- 素色布鞋或软底缎鞋，鞋面干净（她不下山）。

### 桃花崖的白裙（`seq6`~`seq8`，闪回专用）

- 被藏在桃花崖的那一年，她穿的是**素白或极浅粉的常服长裙**，不是道袍——
  那不是修行场合，那是软禁。裙摆略长，行动受限。
  **这套衣服本身就是"她被关起来"的视觉说明。**

### 十二面琉璃灯（伴生灵宝，唯一持物）

- **【原】`seq7[5]`**　「一盏琉璃灯，**琉璃灯有十二个面**，每一面上都绘着**一个人影**」
- 尺寸：可单手托起，约 20cm 高，十二面棱柱形，青铜或深色木质灯架。
- 每一面是一块**半透明的琉璃**，面上有**一个人影的绘像**——影是绘的，**不是活的**。
- 光是**奇异光谱**（`seq7[44]`「发出奇异光谱的琉璃灯」）：不是暖黄，不是冷白，
  是那种说不清颜色、看久了不舒服的光。
- ★ **不做粒子、不做符文流转、不做旋转特效。** 它的可怕来自"十二个人影"这件事本身。
