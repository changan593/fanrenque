## 用途与地位

**紫云仙宫二师姐，南季礼（`C09`）之女，唐真（`C01`）的爱人，全书第一个死者。**

她在 `seq1[9]` 就已经死了——「你！害死了南红枝！！」是全书对唐真的第一句指控。
此后 91 章里她**只以回忆、遗物、灵位和别人的转述出现**。

- **【原】`seq7[17]`**　「可南红枝才**十六岁**！」
- **【原】`seq7[11]`**　「当时发现这情况的紫云仙宫宫主，也就是**南红枝的父亲**，唐真的师父」
- **【原】`seq6[23]`**　「其实南红枝真的很乖，从小就受到严格的教育，是**非常传统的乖乖女**。」

★ **她是全剧最重要的一张「只出现在回忆里的脸」。** 正因为几乎不出场，
才更不能每次闪回都长得不一样——这张卡的存在价值全在这里。

**执行规则（双向硬约束，两张卡都要遵守）**：

1. **骨相层面：眉形、眼型、眼距、眉眼距离与红儿同源**——柳叶眉、眼裂较大的浅双眼皮、

2. **表情层面：南红枝永远带着暖笑，红儿不是。** 区别**不在骨头上，在肌肉上**——
   南红枝的默认表情是眼角下垂的、松弛的、迎向人的；红儿的默认表情是收着的、留着余地的。
3. **绝不能做成双胞胎。** 脸型、鼻子、嘴、下颌**必须明确不同**：
   南红枝脸型更圆润饱满（十六岁、锦衣玉食、被保护得很好），
   红儿鹅蛋脸偏小、下颌线更清晰（`C04` V2 已锁）。
4. 两人**共有**一条：把所有感受藏在眼睛最深处（`seq302`「那双**藏的满满的**眼睛」）。
   这是**演出方向**，不是造型项——眼神要有东西，但不外溢。

## 跨版本不可变身份

### 年龄与体格

- **十六岁**，看起来就是十六岁——**不做成年女性的身材，不做二十岁的脸**。
- 身高约 158cm，**7 头身**（比红儿的 7.5 略矮略圆，这是两人第一眼的区分点）。
- 体格匀称偏软，肩窄，锁骨不明显。宗门嫡传、被父亲藏起来保护的女孩，
  **没有劳作痕迹**：手指纤细、指甲干净、掌心无茧。
  ★ 与红儿（丫鬟，`C04`）的手**必须明确不同**——那是阶层最诚实的证据。

### 脸

- **圆润饱满的鹅蛋脸偏圆**，颊部软组织充盈，下颌线柔和、不见骨。
  **不做尖下巴、不做锥子脸、不做高颧骨。**
- **柳叶眉**，眉毛柔和上扬，眉尾自然收细。★ 与红儿同源。
- **眼裂较大的浅双眼皮，眼尾略上翘**，眼距略宽（约 1.05 眼宽）。★ 与红儿同源。
  眼球饱满，**上眼睑弧度圆**——这是「笑弯了眼」能成立的结构前提。
- 鼻梁低而直，鼻头圆钝小巧，鼻翼窄。★ **与红儿明确不同**（红儿鼻梁略挺）。
- **嘴唇偏厚，唇珠明显，嘴角自然上扬**，唇色是健康的淡樱色，不涂不描。
  ★ 与红儿（唇色微淡、嘴角天然上翘）**方向相同但厚度不同**。
- 皮肤白皙细腻有血色，**不做颊红妆**——脸红是情绪（`seq6[54]` 面有桃色），不是常态。
- **固定不对称（母版锁定项）**：右眼外眼角比左眼低约 0.5mm；笑起来**左颊有一个浅酒窝，
  右颊没有**。所有角度、景别、表情必须保留。

### 头发

- 黑色长直发，发量足，发质好（有人打理），**齐腰**。
- 常态：**双环髻或简单低髻**，用素色绢带与一两支素木簪／白玉小簪，**无繁复金饰**。
  ★ 与姜羽（`C17`，满头珠钗宝玉）**位于对立面**——这是全书两种「贵女」的分野：
  南红枝是被保护起来的清素，姜羽是天生凤凰的华贵。
- 鬓角碎发柔软，垂在耳前。发际线圆润，中分或极浅的偏分。

### 那个笑容（本卡的核心）

四条原文全部指向同一件事：**她的记忆点不是长相，是笑容。**

- **【原】`seq302[48]`**　「周东东对红枝姐的记忆点**从不是长相**，而是一种模糊的感觉，
  最显着的是那**永远温柔让人舒适的笑容**」

所以身份母版**必须把这个笑做成锁定项**，标准如下：

| 要素 | 规格 |
| --- | --- |
| 眼 | **眼睛先笑**——下眼睑上抬，眼裂弯成月牙，眼尾下沉，**不是只咧嘴** |
| 嘴 | 嘴角上扬幅度**中等**，露上齿 2~4 颗，**不做八齿大笑，不做抿嘴微笑** |
| 颊 | 左颊酒窝出现，苹果肌上推，眼下形成一道浅卧蚕 |
| 眉 | 眉尾**放松下落**，眉头不锁——这是「亲和」的解剖学来源 |
| 头 | 微微偏向对话者，下颌略收，视线迎上去**不躲** |
| 温度 | **让人舒适**：不是讨好的笑，不是甜妹的笑，是「我很高兴见到你」的笑 |

★ **反面**：不做嘴角上扬眼神冷的营业笑，不做垂眼羞怯笑，不做仰头大笑。

## 服装（跨全季不变）

**紫云仙宫嫡传弟子女装制式**，与 `G05` 弟子群像同制，但用料等级更高：

- **青蓝色交领右衽长袍**（沉青蓝，与 `G05` 同色号），中袖，及踝。
  ★ **无织带**——她是弟子不是长老（分档见 `G05` 位阶对照表）。
- 素白内衬，**浅青或月白布带束腰**，系法简单。
- 用料是**上等素绸**：垂坠更好、光泽更含蓄、织纹更细——这是与 `G05` 普通弟子唯一的
  可见差别，靠**材质**不靠装饰。
- 无纹、无绣、无金、无玉、无法器、无佩剑。
- 素色布鞋或软底缎鞋，鞋面干净（她不下山）。

### 桃花崖的白裙（`seq6`~`seq7`，闪回专用）

- 在桃花崖被藏起来的那一年，她穿的是**素白或极浅粉的常服长裙**，
  不是道袍——那不是修行场合，那是软禁。
- 裙摆略长，行动受限。**这套衣服本身就是"她被关起来"的视觉说明。**

### 十二面琉璃灯（伴生灵宝，唯一持物）

- **【原】`seq7[5]`**　「琉璃灯有**十二个面**，每一面上都绘着**一个人影**」
- 尺寸：可单手托起，约 20cm 高，十二面棱柱形，青铜或深色木质灯架。
- 每一面是一块**半透明的琉璃**，**面上有一个人影的绘像**——影是绘的，**不是活的**。
- 光是**奇异光谱**（`seq7`「发出奇异光谱的琉璃灯」）：不是暖黄，不是冷白，
  是那种说不清颜色、看久了不舒服的光。
- ★ **不做粒子、不做符文流转、不做旋转特效。** 它的可怕来自"十二个人影"这件事本身。

不能演成英勇就义，也不能演成崩溃。
