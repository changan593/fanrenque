# production —— 成片工作目录

**这里的东西是人写的，删了就没了。** 与 `data/` 的分界线就在这儿：
`data/` 全是脚本算出来的，重跑就有；`production/` 里的判断、取舍、文笔，
重跑不出来。所以改这里的文件要当心。

| 目录 | 内容 |
| --- | --- |
| `style_assets/` | **全片"怎么画"的唯一入口**：统一风格提示词、统一角色提示词、场景参考包 |
| `characters/` | **跨季**人物视觉资产：角色卡图片与超详细提示词，一角色一目录 |
| `s01/` | 第一季：分集方案、角色/场景资产卡、47 集剧本与分镜提示词、人工基准分析 |
| `style_test/` | 画风选型矩阵的配置与留痕。**选型已结束**，保留作复盘用 |

后续 `s02/` ~ `s06/` 按 `s01/` 的结构展开。

**`characters/` 与 `sNN/` 怎么分**：跨季通用的放 `characters/`（唐真出现在全部六季，
身份母版不是第一季的资产）；只属于某一季的放 `sNN/`（分集方案、剧本、当季新增实体的锁定卡）。

## `s01/` 里都有什么

| 文件 | 是什么 |
| --- | --- |
| `00_分集方案.md` | 每集章数与时长的决策过程。两版时长规格（8-12 分、25~32 分）都已作废，现行结论是**不做预设** |
| `02_角色资产.md` | 第一季角色卡，**面向出图的提示词**，写到能直接喂给模型 |
| `03_场景资产.md` | 同上，场景 |
| `EXX_剧本.md` | **分镜脚本**，E01~E47 全季 47 集完成。台词/独白/旁白逐字来自原文 |
| `EXX_旁白承载账.md` | 每集旁白六类分派（N1~N6）的承载记录，`s14` 的闸门依据 |
| `prompts/` | **画面提示词层**，一集一目录、一幕一文件。总则与模板见 `prompts/00_总则与模板.md` |
| `manual_analysis/` | 8 章**人工手写**的章节分析稿，`s2m_manual.py` 的输入 |

`manual_analysis/` 是**人工基准集**：用来验证整条流水线走得通，
也用来当模型产出的对照组。它的引用写成位置引用（`{"para": N, "q": K}`
＝ 第 N 段的第 K 条引号内容）而不是抄原文——人抄原文一定会抄错，
让程序去原文里取就不会。

> 角色资产卡（`02_角色资产.md`）与 `data/characters/名字_角色深度档案.md`
> 是互补关系，不是重复：前者是**能直接出图的提示词**，
> 后者是**全书性格与轨迹的取证**。两者冲突时以原文段号为准。

## `style_assets/` 里都有什么

全片"**怎么画**"的唯一入口。详见 [`style_assets/README.md`](style_assets/README.md)。

| 路径 | 是什么 | 状态 |
| --- | --- | --- |
| `统一风格提示词.md` | **场景/环境**怎么渲染：材质、光照、空间层次、色彩、负面清单 | ✅ 定稿 |
| `统一角色提示词.md` | **人物**怎么塑造与锁身份：骨相、皮肤、毛发、服装受力、表演、跨镜头一致性 | ✅ 定稿 |
| `refs_场景参考_image2/` | 20 张场景参考图 + 逐图反推提示词，渲染质感的视觉锚点 | 参考，**不可直接入生产** |

两份提示词是并列关系，一份管环境一份管人；同一镜头里同时出现时两份都要追加。
正式镜头还必须带**项目克制版追加约束**——原则三「严禁浮夸」是硬约束，不是可选项。

新加参考包的规矩（自带 README、写清四件事、图片体积）见
[`style_assets/README.md`](style_assets/README.md) 末节。

## `characters/` 里都有什么

已批准的角色卡图片与超详细提示词，一角色一个目录，跨全六季通用。
详见 [`characters/README.md`](characters/README.md)。

| 角色 | 身份母版 | 阶段卡 |
| --- | --- | --- |
| `C01_唐真/` | ✅ | 3 个（真君期 / 乞丐期 / 白色抹额期） |

**出图顺序不能颠倒**：先出身份母版 → 派生阶段卡 → 阶段卡进剧情镜头。
绝不从不同剧情截图反向平均出一张新脸。

> `characters/`（图 + 超详细提示词，跨季、已批准）、`s01/02_角色资产.md`
> （第一季角色的原文依据与补全裁定）、`data/characters/名字_角色深度档案.md`
> （全书性格与轨迹取证）三者互补不重复。冲突时一律以原文段号为准。
