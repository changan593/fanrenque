# production —— 成片工作目录

**这里的东西是人写的，删了就没了。** 与 `data/` 的分界线就在这儿：
`data/` 全是脚本算出来的，重跑就有；`production/` 里的判断、取舍、文笔，
重跑不出来。所以改这里的文件要当心。

| 目录 | 内容 |
| --- | --- |
| `s01/` | 第一季：分集方案、角色/场景资产卡、E01/E02 剧本、人工基准分析 |
| `style_test/` | 画风选型矩阵的配置与提示词 |

后续 `s02/` ~ `s06/` 按同样结构展开。

## `s01/` 里都有什么

| 文件 | 是什么 |
| --- | --- |
| `00_分集方案.md` | 每集章数与时长的决策过程。两版时长规格（8-12 分、25~32 分）都已作废，现行结论是**不做预设** |
| `02_角色资产.md` | 第一季角色卡，**面向出图的提示词**，写到能直接喂给模型 |
| `03_场景资产.md` | 同上，场景 |
| `E01_剧本.md` / `E02_剧本.md` | 两集完整剧本试点，确立了剧本的数据结构与模板 |
| `manual_analysis/` | 8 章**人工手写**的章节分析稿，`s2m_manual.py` 的输入 |

`manual_analysis/` 是**人工基准集**：用来验证整条流水线走得通，
也用来当模型产出的对照组。它的引用写成位置引用（`{"para": N, "q": K}`
＝ 第 N 段的第 K 条引号内容）而不是抄原文——人抄原文一定会抄错，
让程序去原文里取就不会。

> 角色资产卡（`02_角色资产.md`）与 `data/characters/名字_角色深度档案.md`
> 是互补关系，不是重复：前者是**能直接出图的提示词**，
> 后者是**全书性格与轨迹的取证**。两者冲突时以原文段号为准。

## `style_test/` 里都有什么

| 文件 | 是什么 |
| --- | --- |
| `matrix.json` | **配置源**：10 个画面目标 × 11 个画风。要改提示词改这里 |
| `prompts.md` | `s6 --dump` 导出的 110 条完整提示词，**是产物，改了会被覆盖** |
| `refs/` | 八部参考片的截图，**原始参考**。采集清单见 `refs/README.md` |
| `out/` `sheets/` | 出图与拼图产物，几百 MB，已 gitignore，随时可重新生成 |

跑法见 [`../doc/07_画风矩阵测试.md`](../doc/07_画风矩阵测试.md)。
