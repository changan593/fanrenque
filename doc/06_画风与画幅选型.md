## 一、决策依据

### 1.1 规模

| 项 | 数值 |
| --- | --- |
| 两集实测分镜 | 422 个 / 45.2 分钟 |
| 每集平均 | 约 211 个镜头 |
| **全剧（300 集）** | **约 63,000 个镜头** |
| 按 3 次生成出 1 个可用镜计 | **约 19 万次生成** |

**结论**：选型的第一标准不是"哪个好看"，而是**"哪个能在六万镜里不崩"**。
单张出彩没有意义，一致性才是全部。

### 1.2 景别分布（从 E01-E02 的 422 个分镜统计）

| 景别 | 占比 |
| --- | --- |
| 近景 | 32.7% |
| 中景 | 27.5% |
| 特写 | 12.8% |
| 全景 | 7.1% |
| 大特写 | 3.1% |
| 远景 + 大远景 | 4.8% |
| 其他（空镜/主观/蒙太奇等） | 12% |

- **中景及更近占 76%** —— 这部剧活在脸上，**人脸一致性是生死线**
- **广角只占 10%** —— 16:9"容纳群像"的优势没有想象中大
- 每集 144 条台词 —— **大量对口型与微表情**

### 1.3 原著给的额外约束

| 约束 | 出处 | 对选型的影响 |
| --- | --- | --- |
| 旧、脏、有尘 | 「旧」526 次、「脏」152 次 | **平涂难以承载材质**，利好厚涂/写实 |
| **不美化人物** | 「长得并不出彩」「面相憨厚不断抹汗」；老拐子皱纹如龟裂、缺牙、口臭 | ⚠ **这是最大的风险点**——所有生图模型都强烈偏向美型，二次元模型尤甚 |
| 光有出处 | `doc/04` 12.2 | 各风格均可 |
| 术法朴素 | 作者嘲讽"喷火放电是街边杂耍" | 各风格均可，写实更容易做"不像特效" |

## 二、画风载体：四个候选

### A. 半写实厚涂（我的推荐）

参照：国产动画电影的厚涂质感；《雾山五行》的笔触感但更写实；概念设定图的完成度。

| 维度 | 评价 |
| --- | --- |
| 承载"旧脏有尘" | ★★★★★ 最好。笔触本身就是材质 |
| **人脸一致性** | ★★★☆☆ 中等偏上。比照片级好控，比平涂难 |
| **不美化的可行性** | ★★★★☆ 好。厚涂能画出皱纹、缺牙、污渍而不显廉价 |
| 对口型与微表情 | ★★★☆☆ 中等。需要额外的口型方案 |
| 视频生成友好度 | ★★★☆☆ 中等。运动伪影会被笔触部分掩盖 |
| 单镜成本 | 中 |
| **63,000 镜的风险** | 笔触密度会漂移——有的镜头笔触重有的轻，看起来像换了美术 |

**最大隐患**：厚涂的"笔触风格"本身是一个难以锁定的变量。需要在参考图阶段就把
笔触粗细、颜料厚度、边缘处理定死，并在提示词里量化描述。

---

### B. 2D 赛璐璐（平涂 + 线稿）

参照：国产/日式番剧的标准做法。

| 维度 | 评价 |
| --- | --- |
| 承载"旧脏有尘" | ★★☆☆☆ **最弱**。平涂天然干净，脏是画上去的不是长出来的 |
| **人脸一致性** | ★★★★★ **最好**。变量最少，LoRA 训练效果最佳 |
| **不美化的可行性** | ★★☆☆☆ **最差**。二次元模型对"丑"和"老"的表达极其贫乏，老拐子极易被画成慈祥爷爷 |
| 对口型与微表情 | ★★★★★ 最好。口型是有限状态，成熟方案多 |
| 视频生成友好度 | ★★★★☆ 好。伪影读作风格 |
| 单镜成本 | **最低** |
| **63,000 镜的风险** | 最低。这是唯一一个"工业上被验证能撑几百集"的方案 |

**最大隐患**：与本书的美学**正面冲突**。这是一本讲市井、落魄、脏旧的书，
而赛璐璐的语法是干净、明确、悦目。做出来很可能好看但不对。

**但要公平地说**：2D 也能做脏（《恶童》《雾山五行》都可以），
只是需要主动对抗模型的默认倾向，成本会回升。

---

### C. 照片级写实

| 维度 | 评价 |
| --- | --- |
| 承载"旧脏有尘" | ★★★★★ 最好 |
| **人脸一致性** | ★★☆☆☆ **最差**。跨镜人脸漂移是当前 AI 生成最难压的问题 |
| **不美化的可行性** | ★★★★★ 最好。真实感天然反美化 |
| 对口型与微表情 | ★★☆☆☆ 差。恐怖谷，一点不自然就出戏 |
| 视频生成友好度 | ★★☆☆☆ 差。伪影读作"错误"而非"风格" |
| 单镜成本 | 高 |
| **63,000 镜的风险** | **最高**。观众对真人脸的辨识极其敏感，漂移一次就出戏 |

**判断**：质感最对，但**在六万镜的尺度上，人脸漂移几乎必然发生**。
除非上 3D 角色模型或成熟的换脸管线，否则不建议。

---

### D. 水墨 / 国风绘本

| 维度 | 评价 |
| --- | --- |
| 气质契合度 | ★★★★★ 与「余事无可记述」的编年体收尾极其相配 |
| **叙事密度** | ★☆☆☆☆ **致命伤**。留白语法承载不了每集 144 条台词、211 个镜头 |
| 人脸一致性 | ★★☆☆☆ 差。水墨的随机性正是它的美，也正是一致性的敌人 |
| 对口型 | ★☆☆☆☆ 基本做不了 |

**判断**：**不适合作为主载体**，但**极其适合做局部**——
比如 E02 收束段的"那一夜九洲星海震荡"四个远景异象，
或每季片头、章回字幕卡。建议保留为**特殊段落的备选**。

---

### E. 补充选项：3D 资产 + 风格化渲染（三渲二）

不在原来的四个选项里，但对 300 集的体量应该被提出来：

- **一致性最高**：角色是模型，永远不会漂移
- **长线成本最低**：前期建模贵，但六万镜的边际成本极低
- **这是国产长篇动画的工业答案**

**代价**：前期需要真正的 3D 制作能力，且**这就不再是"AI 漫剧"了**。
如果你的定位是 AI 生成，这条可以排除；如果只是"要做出来"，它值得认真算一笔账。

## 四、画幅

### 4.1 前提已经被锁定了大半

上一个决策（每集 25-32 分钟）实际上已经把画幅推向 16:9：

- 30 分钟的内容形态是**长视频**，主战场是 B站/优酷/腾讯/爱奇艺 —— 全是 16:9
- 抖音快手能放长视频，但 30 分钟竖屏在那里不是原生形态

### 4.2 三个选项

| | 16:9 横屏 | 9:16 竖屏 | 双版本 |
| --- | --- | --- | --- |
| 与 30 分钟时长匹配 | ★★★★★ | ★★☆☆☆ | ★★★★☆ |
| 承载 10% 的广角镜头 | ★★★★★ | ★★☆☆☆ | ★★★☆☆ |
| 承载 76% 的中近景 | ★★★★☆ | ★★★★★ | ★★★★☆ |
| **双人对话（本剧主体）** | ★★★★★ | ★★☆☆☆ | ★★★☆☆ |
| 唐假在画框边缘 | ★★★☆☆ | ★★★★★ 竖屏底部空间更好放 | ★★★☆☆ |
| 成本 | 基准 | 基准 | **+30~50%** |

### 4.3 关键判断

**支持 16:9 的决定性理由**：这部剧的主体是**双人对话戏**——
唐真与老拐子、唐真与红儿、唐真与南红枝、唐真与齐渊。
竖屏拍双人只能靠过肩或上下堆叠，两种都会削弱表演的对手感。
而 E02 的核心场面「二十步」本身就是**一条横向的距离**，竖屏根本装不下。

**支持 9:16 的唯一理由**：76% 是中近景，竖屏对单人特写更有压迫感；
且唐假坐在画框下缘的设计在竖屏里更自然。

**双版本不建议**：+30~50% 成本换来的是两个都不够好的构图——
横向构图必须迁就中央安全区，等于放弃 16:9 的全部优势。

**我的推荐：16:9。** 它是被 25-32 分钟这个决策带出来的必然结果。
如果你想要竖屏，那应该回头重新考虑时长——两者要一起定。

## 五、测试提示词套件

**用途**：拿去 image-2 出图，亲眼比较后再决定。
**方法**：同一个场景、同一段描述，只换画风部分。**必须用同一个模型、同一批参数**，否则不可比。

### 测试二：老拐子·面部特写（★ 最关键的一测：测"不美化"）

**这一测最能分出高下。** 原著的老拐子必须丑、脏、缺牙、皱纹如龟裂。
生图模型会拼命把他画成慈祥老爷爷——**哪个风格最能顶住模型的美化倾向，哪个就赢。**

```
一名约六十岁的中国老年乞丐面部特写，正面偏侧；
深褐色被日晒风吹的脸，颧骨突出双颊凹陷，皱纹极深且交错纵横如干裂的泥地；
小而浑浊的眼睛，眼白发黄，眼角有泪痕与污垢；
额头有一块不规则的褐色片状胎记，边缘模糊；
嘴唇干瘪起皮，咧嘴笑时露出缺失三四颗牙的牙床，剩余牙齿发黄发黑；
花白稀疏的头发打绺结块，胡须杂乱未修剪，沾有食物残渣；
表情：咧嘴大笑，笑时所有皱纹挤在一起，眼睛眯成一条缝——丑陋而亲切；
衣领可见看不出原色的深褐色破棉袄，油亮发黑；
光线：正午硬顶光，皮肤上的沟壑被打出强烈明暗对比；
配色：低饱和，泥褐、灰黑、暗黄。
【负面】慈祥,和蔼,干净,整洁,圣诞老人,仙风道骨,美化,年轻化,牙齿整齐,皮肤光滑,磨皮,温暖光晕,可爱
```

四个画风变体同测试一。

**验收标准**：出来的人**必须让你觉得不太想靠近**。如果看着像个可爱的老爷爷，这个风格就不合格。

### 测试三：洞天桃花崖·空景（测环境 + ★ 无阴影规则）

```
一方与世隔绝的小天地全景，无人物；
一块从浓密云海中横向伸出的岩台，长约三十米，三面临空，
只有一侧连着一条狭窄的碎石山道通向远处；崖顶覆一层薄薄的干燥黄土与短草；
崖顶有一间两层木构小楼，面阔一间，悬山顶，未上漆的原木本色，木材已风化发灰，
一门一窗，窗棂样式极简，没有匾额没有雕花没有任何装饰；
小楼旁一棵高约十二米、明显高过小楼的大桃树，主干需两人合抱，树皮粗糙布满裂纹与老疤，
树冠极其巨大、向小楼一侧倾斜，枝叶浓密翠绿，遮蔽画面上方半边天空；
树下有一张天然青石打磨的圆石桌与一把旧木摇椅，摇椅扶手被抚摸磨得光滑发亮；
崖下是浓密不透光、纹丝不动的白色云海，像凝固的海面，一望到天的尽头；
远处天边挂着一轮低而不落、边缘清晰的白色太阳；
★关键：均匀的白日光从上方与远方同时照来，画面中没有任何阴影——
树、楼、石桌、山道全部没有投影；
配色：翠绿、原木灰、云白、土黄，低饱和。
【负面】阴影,投影,光影对比,逆光,丁达尔效应,飘落花瓣,光晕,仙气,祥云,过饱和,唯美,梦幻
```

四个画风变体同测试一。

**验收标准**：**地面上不能有任何投影。** 这一条各模型都会翻车，
正好用来测哪个风格更容易压住它。

### 测试四：一致性测试（★ 决定性的一测）

**这才是真正要看的东西。** 单张好看没用，要看同一个人在两个镜头里像不像同一个人。

做法：用测试一选出的那张图作为**参考图/垫图**，再出下面两张：

**四-1（换景别）**：

```
【垫图：测试一的成图】
同一名男子的面部特写，正面，表情为伸手用食指按在额头黑印上，指尖略陷入皮肤，淡笑；
其余特征、服装、光线、画风与参考图完全一致
```

**四-2（换场景与状态）**：

```
【垫图：测试一的成图】
同一名男子的全身像，站在盛夏正午的河边码头，已换上全新的粗麻上衣与长裤（未染色的本白偏米黄，
```

## 六、出图后怎么定

建议按这个顺序看，**不要先看哪张好看**：

1. **先看测试二**（老拐子）。哪个风格顶不住模型的美化倾向，直接淘汰
2. **再看测试四**（一致性）。哪个风格三张图不像同一个人，直接淘汰
3. **然后看测试三**（无阴影）。哪个风格压不住阴影，扣分
4. **最后才看测试一**（好不好看）。在活下来的候选里选
5. **画幅看测试五的双人构图**，风景那张只是参考

**如果两个风格都过了前三关**，那就选**你自己看着不腻的那个**——
你要看它 300 集。
