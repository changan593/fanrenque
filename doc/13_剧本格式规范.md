# 剧本格式规范

第一季 47 集剧本、77 份幕文档、47 份承载账都按同一套格式写。这套格式不是排版偏好——
`s14_narration_ledger.py` 按它解析声音栏对账，`s16_shot_pack.py` 按它读幕文档装配出图包，
`s17_citation_check.py` 按它核对原文引用。**格式错一处，闸门就会漏一条或多报一条。**

本文只定「怎么写」。旁白该派给谁、什么时候现身，见 `doc/05` 第五节；画面内容怎么写，见
`production/s01/01_总则与模板.md`。

---

## 一、一集的文件

```
production/sNN/ENN/
├── 剧本.md                    分镜脚本：镜号 / 景别 / 时长 / 画面 / 声音，唯一事实来源
├── 旁白承载账.md              由 s14 --out 生成，不要手改（改剧本里的标记，然后重跑）
├── 出图台账.md                出图阶段才有：哪一镜用了哪一版、谁验收的（doc/16，s18 管）
└── NN_幕别_幕题/              一幕一目录，与剧本的幕一一对应
    ├── 提示词.md              这一幕逐镜的画面内容提示词（不含风格）
    └── 分镜草图.svg           线条构图稿（目前只有 E01 有）
```

集号 `SNNENN`（如 `S01E07`），目录只取后半 `E07`。集的 seq 范围以 `data/plot/episodes.json` 为准；
**有剧本的集，边界已被 `s10` 锁定，不会再被重排**。

## 二、剧本抬头

```markdown
# E03《乞丐翻墙入府》分镜脚本

**对应**：seq 9-12（第9~12章）　**预计时长**：约 27 分钟　**画幅**：16:9　**画风**：`production/style_assets/` 的两份风格段（`doc/04` 第十四节已定）

**台词 111 条、心理活动 55 条全量保留，逐字来自原文，一条不删。**
**关键旁白 19 条全部上账**，按 `doc/05` 第五节分类承载。

**声音标记**（口径见 `doc/05_唐假旁白系统.md` 第五节）：
`【现】`唐假**现身**，世界静止｜`【白】`唐假**只出声**，画面照常流动｜
`【画】`**由画面承载，不出声**｜`【台】`抽取误判、实为现场台词｜
`【心·某某】`角色内心音（低音量近场无混响）｜无标记为现场台词。
`※` 后面是保留理由，`★` 后面是给导演的备注。

**验收**：`python pipeline/s14_narration_ledger.py --episode S01E03`　五道闸门须全绿。
```

- 标题行 `# ENN《集名》分镜脚本`，不带「草稿」——写完就是定稿，改动走 `CHANGELOG.md`。
- 「预计时长」是 `episodes.json` 的求解估值，**不是验收标准**（时长不做预设，`doc/00` 第二节）。
- 台词 / 心理活动 / 关键旁白三个数字来自这一集各章 `analysis` 的条目数，写剧本前先数一遍。
- 抬头之后可以写「本集在全季里的位置」与「通用约束」，随意，但不要写进表格。

## 三、幕

```markdown
## 冷开场｜烧退　seq9 [1-13]　约 1:25

**场景卡**（复用 S01 破庙）：夜转晨。唯一光源从破洞进来……

| 镜 | 景别·秒 | 画面 | 声音 |
| --- | --- | --- | --- |
| 001 | 全景 10s | 破庙夜。唐真裹在所有人的被褥里发抖…… | 【画】矮矮小小的破庙塞满了痛苦的喘息声……[1] |
| 004 | 近景 6s | 唐真靠墙，有气无力地笑 | 唐真：「菩萨可保佑不了我。……」[4] |

**转场**：硬切。原文 [13] 是省略号，无内容，不入镜（N0）。
```

- 幕标题 `## 幕别｜幕题　seqN [起-止]　约 m:ss`。幕别用「冷开场 / 第一幕 / … / 收尾」；
  幕题就是幕目录名 `NN_幕别_幕题` 里的幕题，去标点。
- 幕首一段**场景卡**：场景码、时辰、唯一光源、本幕的构图母题与「不要」。`★` 开头的是导演硬约束。
- 表格固定四列：`镜 | 景别·秒 | 画面 | 声音`。**镜号三位数字，全集连号，一镜不缺一镜不加**；
  镜号可以加粗（`**012**`），`s14` 两种都认。快切 ×3 算一个镜号。
- 每幕末一行 `**转场**：…`，未注明按 `doc/04` 第十节。
- 附表（勘误、抽取误判记录、承载说明）放在 `## 附一` `## 附二`……里，**第一个 `## 附` 之后的内容
  `s14` 不解析**——附表行的首格也常是三位数字，不切开会被当成真镜头。

## 四、声音栏

声音栏是被程序对账的那一列。每条内容 = **标记 + 正文 + 段号**，一格里多条用 `<br>` 分开，
按出现顺序写（拆条要拼回原句，顺序就是拼接顺序）。

| 写法 | 含义 | 冻结世界 | 谁在管 |
| --- | --- | :-: | --- |
| `角色：「台词」[段]` | 现场台词，无标记 | 否 | 台词覆盖由 `s3` 在章节层管 |
| `【心·角色】正文[段]` | 角色内心音 | 否 | — |
| `【现】正文[段]` | 唐假现身 + 世界静止 | **是** | `s14`：每集 ≤ 6 次（`config.FREEZE_MAX`） |
| `【白】正文[段]` | 唐假只出声 | 否 | `s14`：派给唐假的白描必须写 `※` 理由 |
| `【卡】正文[段]` | 字幕卡 | 否 | — |
| `【画】正文[段]` | 由画面承载，不出声 | 否 | `s14`：上账即可 |
| `【删】正文[段]` | 按 N6 删除 | 否 | `s14`：删除率 ≤ 15%，必须写「被…覆盖」 |
| `【台】正文[段]` | 抽取把台词误判成旁白，实为现场台词 | 否 | `s14`：算上账 |

规则：

1. **正文逐字来自原文**，一个字不改。唯一例外是全剧的更名裁定「南天礼 → 南季礼」
   （`common/names.RENAME_CANON`），`s14` 比对前会归一。
2. **段号 `[n]` 是该镜所属 seq 的 1 基段号**，与 `data/chapters/chNNNN.json` 的 `para` 同一套。
   一集横跨几章，段号会撞——`s14` 用镜头正文回查它属于哪一章，所以**每一镜声音栏里至少要有
   一段够长（≥ 6 字）的原文**，纯字幕卡、纯改写的画面提示认不出章，会继承前后邻居的判定。
3. 只承载一段旁白的一部分时写 `[n 节选]`；一条旁白拆到相邻两镜时两镜各写同一个 `[n]`，
   `s14` 会把两片拼回去与原句比对（多一个字少一个字都过不了）。
4. 段号以 `analysis` 里记的 `para` 为准。抽取偶有错位（`doc/15` 第一节有逐例记录），
   此时仍写 `analysis` 的值，并在 `★` 备注里注明原文行号——否则 `s14` 对不上账。
5. `※` 后写保留理由（为什么这条白描要让唐假说），`★` 后写给导演的备注。两者都不参与比对。
6. 一条关键旁白只能有一个承载镜；同一句在两镜都整句出现会被判「重复承载」。
   原文自己重复的（章节接缝处上一章末两行原样重写在下一章开头，见 `doc/15` E40）必须拆成两镜、各带各的段号。

## 五、`s14` 的五道闸门

```bash
python pipeline/s14_narration_ledger.py --episode S01E03          # 检查
python pipeline/s14_narration_ledger.py --episode S01E03 --out production/s01/E03/旁白承载账.md  # 同时重写承载账
```

| 闸门 | 判据 | 阈值来源 |
| --- | --- | --- |
| 关键旁白全部上账 | 该集各章 `analysis.narration` 每一条都能在声音栏找到承载（任一标记） | 原则二 |
| 无重复承载 | 一条旁白只落一镜；拆条的拼回去等于原句 | `doc/05` 5.3 |
| 删除率 | `【删】` 条数 ÷ 关键旁白条数 ≤ 15%（`。。。` 这类 N0 不计入） | `config.DELETE_RATE_ALARM` |
| 现身档 | `【现】` ≤ 6 次 | `config.FREEZE_MAX`，`doc/05` 5.7 |
| 白描留声有理由 | 派给唐假（`【白】`/`【现】`）却不属于关键旁白的句子都写了 `※` | `doc/05` 5.4 |

`pipeline/check_all.py` 会对每一集有剧本的集跑一遍。

## 六、幕文档 `提示词.md`

模板与写法在 `production/s01/01_总则与模板.md` 第三、四节，这里只列被程序读的部分：

- 首行 `# ENN｜第X幕《幕题》画面提示词`；前 12 行内要有一行含「对应剧本」。
- `## 本幕人物与状态` 表：第一列角色名，`s16` 按它去 `production/characters/` 找卡。
  按排行写（「三师兄」）也行，对照表在 `common/names.CARD_ALIASES`；括号注记（「唐真（梦中·仙宫期）」）
  会被剥掉再匹配。`★` 开头的行和第二列为 `——` 的行是说明，不当角色。
- 正文里出现的场景码 `SNN`（前后不是 ASCII 字母数字即可，「场景S01城隍庙」认得出）会被收集去找场景卡。
- 正向提示词里不写风格词，黑名单见总则 1.1，`s15` 会扫。

## 七、承载账 `旁白承载账.md`

`s14 --out` 生成。每行一条关键旁白：`seq[段] | 功能 | 旁白 | 处置 | 镜号`。
处置取值：唐假现身 / 唐假声音 / 字幕卡 / 画面 / 建议删除 / 实为台词 / 内心音。
要改账就改剧本标记再重跑；直接改这个文件下次会被覆盖。

## 八、写完一集的自查

1. `python pipeline/s14_narration_ledger.py --episode SNNENN` 五道全绿
2. 镜号连号、与幕目录的镜号区间一致
3. `python pipeline/s17_citation_check.py --path production/sNN/ENN` 全绿（剧本里 `【原】「…」` 引用不多，但有就查）
4. 附表里记下这一集查出的抽取误判，并把有普遍性的条目补进 `doc/15`
