# 项目总纲

把《穿越后，系统变成白噪音了怎么办》改编成 AI 漫剧。

## 一、三大原则

这三条高于一切。任何环节的任何决策与它们冲突，改决策，不改原则。

### 原则一：最终目标是高质量成片

所有环节都要谨慎细致，人物、场景保持高一致性。
宁可某一步多花时间、多花成本，也不把问题往下游传——
上游一个错误的人物设定，到成片阶段就是几十集的返工。

**落地要求**：每个环节都要有可验证的质量闸门，不能靠「看着还行」放行。

### 原则二：严格遵守原文

- 原文有多少人物、多少场景，就多少人物、多少场景，不增不减
- 原文怎么描写人物和场景，就怎么呈现，不做二次创作
- 人物对话、心理活动、关键旁白，一个都不能漏
- 不允许为了「戏剧效果」加原文没有的情节、台词、动作

**落地要求**：逐章分析里所有引用必须逐字来自原文，由程序做字符串精确匹配核验，
不依赖模型自觉。详见 `doc/02_章节分析规范.md`。

### 原则三：画面风格朴素真实

场景和人物都要朴素真实，**严禁浮夸**。

这本书的底色是市井、落魄、克制的——开篇主角是破庙里的小乞丐，
老拐子的幸福想象是「天天吃羊下水」。美术风格必须接得住这种质感，
不能做成流光溢彩的网游 CG。

**落地要求**：风格规范在第 4 阶段成文（`doc/04_风格规范.md`），
所有人物、场景资产的提示词都要受它约束。

## 二、规格

| 项 | 值 |
| --- | --- |
| 原著 | 1200 个分析单元（详见 `doc/01_原文数据说明.md`） |
| 每集 | 3~5 章，8~12 分钟 |
| 总集数 | 约 308 集 |
| 季数 | 6 季，每季 45~55 集 |

按 1200 单元 ÷ 308 集 ≈ 每集 3.9 单元，与「3~5 章一集」吻合。
实际分集不平均切，按剧情节奏走，单元数在 3~5 之间浮动。

```
① 原文标准化          txt ──→ novel.json                      【已完成】
② 逐章独立分析        每章一个 json，含审查留痕                【脚本就绪，待本地跑】
③ 资产与结构规划      角色资产、场景资产、全书剧情线、六季分集  【待②完成】
④ 风格定稿与资产深化  画风/动作/打斗/对话/转场/特效规范        【待③完成】
⑤ 第一季深化          剧情线、分集、可直接落地的超详细脚本      【待④完成】
⑥ 第一季制作          做片、迭代、发布                         【待⑤完成】
```

### 阶段一：原文标准化 ✅

`pipeline/s1_normalize_novel.py` → `source/novel.json`

已完成。产物与已知缺陷见 `doc/01_原文数据说明.md`。
**注意其中第三部分：全书最后约 90 章内容有缺失，影响第六季，需要补原文。**

### 阶段二：逐章独立分析 ◀ 当前

`pipeline/s2_analyze_chapters.py` → `data/chapters/chXXXX.json`

每章独立分析，互不干扰。每章固定三次模型调用（抽取 + 结构审查 + 一致性审查），
中间夹一道程序逐字核验，不达标自动触发修订轮。
审查记录（分数 + 详细分析）全部留在章节 json 里。

**这一步是后续一切的基石，质量必须守住。** 规范见 `doc/02_章节分析规范.md`。

由你在本地用 deepseek-v4-flash 官方 API 跑：

```bash
python pipeline/selftest.py                        # 先离线验管道
export DEEPSEEK_API_KEY=sk-xxx
python pipeline/s2_analyze_chapters.py --smoke 3   # 跑 3 章，人工看质量
python pipeline/s2_analyze_chapters.py             # 跑全书
python pipeline/s3_validate_chapters.py            # 体检
```

### 阶段三：资产与结构规划

有了 1200 份章节分析，才谈得上全局判断。产出：

- `data/characters/` —— 角色资产：出场章节、称呼演变、原文描写汇总、关系网、成长弧线
- `data/scenes/` —— 场景资产：地理体系、出现频次、原文描写汇总
- `data/plot/` —— 全书剧情线、主线支线、伏笔回收表、势力关系
- `data/seasons/` —— 六季划分方案 + 每季 45~55 集的分集表（含每集对应章节）

### 阶段四：风格定稿与资产深化

回过头统一确认整部剧的风格：画风、人物风格、动作风格、打斗风格、
对话风格、场景风格、观感风格、转场风格、特效风格。
然后把角色、场景资产深化到能直接落地的程度（详细提示词），确保跨集一致性。

### 阶段五：第一季深化

第一季的剧情线、每集安排、分镜脚本，细到能直接开工。

### 阶段六：第一季制作

做片、迭代、发布。
