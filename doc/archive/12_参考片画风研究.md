1. **八部里六部是追光**（除大圣归来、姜子牙）。你选的其实是一家公司的美术体系，

## 二、逐片拆解

每片只记对我们有用的东西，不做影评。

### 2.1 西游记之大圣归来（2015）

- **造型**【证】：大圣的比例是**上身长、手臂粗、下身短、大脚**，
  刻意削弱肌肉感、增加亲近感；江流儿是圆头短身的孩童比例。
  这是这批片子里**最不美型的角色设计之一**，长脸马面，不讨好。
- **风格定位**【证】：除片头段落强风格化外，其余场景**在风格化与写实之间取平衡**，
  刻意避免两个极端。艺术团队追求「中国的艺术风格」，主要靠**氛围与意境**表达。
- **绘画参照**【证】：视觉总监从**吴冠中**的作品汲取灵感——
  这解释了它山水段落的黑白灰关系与线的用法。
- **元素**【证】：融合了皮影戏、水墨氤氲、自然细节。
- **对我们最有用的一条**：它证明了在三维 CG 里做**不讨好的造型**是成立的，
  而且不靠丑化，靠**比例失衡**（上下身比、手脚大小）。
  这正是 `doc/04` 4.1「配角靠特征而非美貌」的可执行版本。

### 2.2 白蛇：缘起（2019）

- **考据**【证】：晚唐末年，永州捕蛇村取自柳宗元《捕蛇者说》「永州之野产异蛇」；
  对晚唐建筑、饮食起居、服饰做过严谨考察。
- **场景**【证】：捕蛇村、蛇妖洞、永州城、宝青坊各自是**独立完整的空间**，
  宝青坊建筑细节极密，配五行八卦符号。山水是全片美术最大亮点。
- **技术**【证】：在毛发、水、布料这类复杂材质上推进了国产 CG 的边界；
  背景常常「近似传统中国水墨画」。水墨元素从这一部开始成为追光的招牌。
- **对我们最有用的一条**：**分空间设计**——每个场景是一个有自己规矩的完整世界，
  而不是一套通用美术换贴图。我们有 1364 个场景，这个做法直接对应到场景资产分档。

### 2.3 姜子牙（2020）

- **风格定位**【证】：选了一种**介于写实与极致简约之间**的风格，需要大量手绘工作；
  强化场景空间的开阔性，**颜色区块划分明确，构图简单利落**。
- **色彩**【证】：按**五行（金木水火土）**做分场配色——「归墟」是金色调，「北海」是蓝色调。
- **光照**【证】：接近真电影的做法，每个模型都用「室内、室外、阴天」三种光源验证。
- **造型**【证】：姜子牙的脸型、胡子、耳朵、鼻子全部用**三角结构**，迭代 123 版；
  申公豹躯体多为方形，显魁梧；四不相改了 80 余版。
- **对我们最有用的两条**：
  1. **分场色彩剧本**是可以工程化的——这直接给 `doc/04` 12.3（分季色彩，至今空着）提供了做法。
  2. **几何母题定人物**（三角＝姜子牙，方＝申公豹）比「谁更好看」更能撑住一致性。

### 2.4 新神榜：哪吒重生（2021）

- **世界观美术**【证】：东海市 = 1920–30 年代上海滩 + 曼哈顿 + 蒸汽时代 + Art Deco，
  平民区原型是老上海弄堂，富人区参考二三十年代曼哈顿；缺水导致大片沙漠，做出废土感。
  主色调红蓝。
- **技术**【证】：开发了**程序化建模**，像搭乐高一样自动生成虚拟城市。
- **人物**【证】：三维建模细腻，面部微表情丰富，但角色是明确的**偶像级美型**。
- **对我们最有用的一条**：**程序化生成城市**这件事本身与我们无关（我们不建模），
  但它背后的思路可以借——**先定"营造规则"再生成**，比逐个设计更能保住一致性。
  我们的 1364 个场景如果每个都单独想，一定会漂。
- **不取**：朋克混搭与红蓝主色，与原著的九洲世界无关。

### 2.5 白蛇2：青蛇劫起（2021）

- **修罗城的设计逻辑**【证】—— 这是全篇最值得抄的一条：
  主创明确说他们**没有刻意借用废土或赛博风格**；修罗城之所以破败，
  是因为**这座城缺乏生产力、能源匮乏**。虽有西方工业元素，
  但刻意结合中式视觉经验，比如远处的废弃建筑按**山水画**来处理。
- **视觉转向**【证】：从唯美国风转向暗色废土，混入现代与后现代元素，
  打破了传统「好看的古风」表达。
- **技术**【证】：水的特效是重点；狐狸出水时尾巴的**毛发逐根可辨**。
  黑风洞一战用**水彩**做流动感，而非传统水墨。
- **对我们最有用的一条**：**「破败必须有内在原因，不是美术趣味」**。
  这条和 `doc/04` 5.3「每个场景至少有一个细节在交代信息」是同一件事，
  但说得更狠——破败本身要能被追溯到经济与物理原因。
  我们书里的北阳城、破庙、码头正该这么处理。

### 2.6 新神榜：杨戬（2022）

- **考据**【证】：全片美术参考**魏晋南北朝**，筹备约一年，去过敦煌、陕西历史博物馆；
  蓬莱、方壶、瀛洲三大仙岛以**秦汉**为基准、融合南北朝特点。
- **三维水墨**【证】：这是追光最标志性的视效。做法是**不做完全二维平涂**，
  而是保留**一定的光影厚度**，让画面有层次、立体关系正确，
  再配云雾与消散的粒子。太极图段落用了 **20% 程序化纹理 + 80% 纯手绘叠加**，
  收集了 30 多种投射笔刷把山石树木转成二维效果，水墨粒子约 **1.3 亿**。
- **人物**【证】：杨戬定位是「落魄的帅哥」——曾经的战神失了神力，隐于市做赏金猎人；
  身高设定 1.9 米、九头身。
- **对我们最有用的一条**：**「保留光影厚度的水墨」这个思路本身**——
  即：风格化不等于放弃立体关系。这一条是我们做「朴素但不平」的技术依据。
- **不取**：水墨粒子、飞天、仙岛奇观。这些是全片的奇观层，与原则三正面冲突。

### 2.7 长安三万里（2023）

**这一部是八部里对我们最重要的。** 它是唯一一个**主角也不美型**的样本。

- **造型**【证】：人物设计参考**唐俑的造型比例**——唐人崇尚孔武有力，
  所以**上半身较长、腰带下褪**；整体圆润饱满、温软浪漫。
  李白 15 个造型，高适 22 个造型，**从 8 岁到 60 岁**。
- **风格克制**【证】：相比前作，美术做了**克制处理**——画面不那么挤，
  **留白更多**；**弱化透视，像传统山水画一样更平面**。
- **争议**【证】：李白、高适的造型在舆论里长期背着「不好看」的评价。
  追光的人物造型（尤其非美型的那些）一直有争议，
  三维动画领域里「不够美型」几乎被当成原罪。
- **对我们最有用的两条**：
  1. **它已经替我们趟过 T03（反美化）这一关**——中年发福的李白、老年的高适，
     是这个参考集里唯一能直接对标老拐子的证据。
  2. **「弱透视 + 留白」**给了我们一个不靠奇观撑画面的办法。
     我们的书 76% 是中近景，广角只有 10%，这个思路正好。
- **要有心理准备**：走这条路，「不好看」的批评是**结构性的**，不是做得不好。
  原著本身要求「长得并不出彩」，所以这个代价是必须付的。

### 2.8 白蛇：浮生（2024）

- **时代与色彩**【证】：从晚唐移到南宋，**在色彩上找宋代更雅致的感受，把整个色调往下降一点**；
  追求宋韵的**清冷感**，体现内蕴与克制；灰、赤、青三色勾勒层次。
- **市井**【证】：从**《清明上河图》**汲取素材，西湖、酒楼瓦肆、街巷人家、市井日常，
  按一年中的传统节日为时间线索铺陈。
- **材质**【证】：皮肤肌理细腻可见；**隔着大屏幕能看出衣服是丝质还是棉质**。
- **纪律**【证】：全片坚持**「特效不能喧宾夺主」**，所有特效与艺术效果都往
  **写实的古典美**靠，画面清新淡雅。
- **对我们最有用的两条**：
  1. **「把整个色调往下降一点」**——这是我们「低饱和」要求的成片级参照，
     不是理论，是一部能看到的片子。
  2. **「特效不喧宾夺主」**——这正是 `doc/04` 7.3 奇观额度制的同一条纪律，
     由一部商业片证明过它不影响观赏性。

## 三、抽象：七层共性

下面每一层给三样东西：**共性**（八部一致的）、**离散**（八部分歧的）、**我们取什么**。

### L1 载体与渲染签名

| | 内容 |
| --- | --- |
| **共性** | 三维建模 + 物理着色渲染的**风格化写实**。形体、解剖、透视按真实构建；表面物理着色；细节密度**低于真人摄影**——皮肤瑕疵、镜头颗粒、镜头畸变都被去掉。无描边线、无平涂色块、无全片性的可见笔触。 |
| **离散** | 手绘表面只在**段落**出现（大圣归来片头、杨戬太极图），不是全片语法。 |
| **我们取** | 全取。**这一层就是"这类片子"的定义**，风格段的主体来自这里。 |

### L2 材质签名 —— 这批片子真正的投资点

| | 内容 |
| --- | --- |
| **共性** | 布料能分辨材质（丝／棉／麻）、有垂坠与二次动态；毛发是**成束分组**的，不是逐根乱飞也不是块面；皮肤有次表面散射但毛孔被柔化；木石金属有粗糙度差异与风化氧化；水是每部片的英雄资产。 |
| **离散** | 精细度逐年上升，浮生最高。 |
| **我们取** | 全取，而且这是**关键收获**：`doc/04` 3.2 的质感基线（木有裂、布有褶、墙有污渍、金属有氧化）在这个载体上是**天然可实现**的，比二维厚涂更容易稳定——因为它是材质属性，不是笔触表演。 |

### L3 造型签名

| | 内容 |
| --- | --- |
| **共性** | 七至七头半身，不做二次元比例；东亚骨相——眼裂细长、鼻梁不高耸、面中平缓、下颌不锐；表情由面部肌肉驱动，微表情丰富但不夸张。 |
| **离散** | ★ **美型度是八部里分歧最大的一项。** 主角/情侣普遍美型（小白、小青、杨戬、哪吒、青年李白），而**老人、配角、群众、非人角色普遍不美化**（老年高适、姜子牙、四不相、大圣、江流儿、修罗城众生）。长安三万里是唯一把「不美型」贯彻到主角的。 |
| **我们取** | **取它的"配角层做法"，扩展成全片规则。** 即：把这批片子对待老人和群众的诚实，用在每一个角色身上。锚点是长安三万里。 |

### L4 场景、建筑与自然

| | 内容 |
| --- | --- |
| **共性** | 每部锁定一个具体朝代做**营造做法考据**（魏晋南北朝／晚唐／南宋／盛唐），斗拱、举折、瓦垄、木构关系正确；但**装饰密度低于实物**，雕花彩画被简化；规模靠**体量与重复**（柱列、台阶、层数），不靠金碧。 |
| **离散** | 哪吒重生、青蛇劫起混入了工业与现代元素。 |
| **我们取** | 共性全取。它与 `doc/04` 5.2「庄重但不奢华，木石为主，规模感靠体量不靠装饰」**逐字对上**——说明我们的场景规范本来就是照这类片子写的，只是当时没意识到。不取混搭。 |

### L5 鸟兽虫鱼

| | 内容 |
| --- | --- |
| **共性**【观】 | 解剖写实 + 比例风格化（常比真实更大）；毛发／鳞片／羽毛做足；**眼神略拟人**，但不做卡通表情；体量感是主要表现手段。 |
| **离散** | 姜子牙的四不相走可爱化，其余偏写实。 |
| **我们取** | 写实解剖与材质取，**拟人眼神与可爱化不取**——原著里的兽是兽。 |

### L6 光照签名

| | 内容 |
| --- | --- |
| **共性** | 光有明确出处；戏剧化单主光 + 环境补光，不做均匀照明；**逆光／侧逆光 + 轮廓光是最强的一个签名**；体积光几乎标配；暗部不死黑，保留冷色环境反弹。 |
| **离散** | 亮度基调各片差异大。 |
| **我们取** | 「光有出处」「暗部不死黑」取。**轮廓光与体积光要限量**——它们正是这批片子「仙气」的主要来源，滥用就会漂向仙侠。 |
| **注意** | 明暗基调**不写进风格段**。原因见第五节：目标描述里已经规定了光，风格段再规定一遍会污染对比。 |

| | 内容 |

## 四、参考集与三原则的冲突，以及怎么切

必须把这件事挑明：**这批片子里有几部是国产动画里最奇观化、最美型的作品。**
杨戬的仙岛飞天、哪吒重生的赛博东海市、白蛇系列的唯美仙侠，
如果整体照搬，会直接撞上原则二（不做二次创作）和原则三（严禁浮夸）。

但这不构成矛盾，因为这批片子可以沿一条缝切开：

```
┌─────────────────────────────────────────┐
│  工艺层                                  │  ← 全取
│  渲染、材质、布料、毛发、大气、           │
│  建筑考据、分场色彩、光有出处             │
├─────────────────────────────────────────┤
│  奇观层 / 美型层                          │  ← 全砍
│  仙岛飞天、水墨粒子、赛博混搭、           │
│  统一美型脸、轮廓光泛滥                   │
└─────────────────────────────────────────┘
```

**关键在于：切完之后剩下的东西，在这个参考集内部就有现成样本。**
不是我们发明的折中方案——

| 我们要的 | 参考集里谁已经做到了 |
| --- | --- |
| 主角也不美型 | 长安三万里（唐俑比例、中年李白、老年高适） |
| 低饱和、克制 | 白蛇：浮生（「把整个色调往下降一点」） |
| 破败有内在原因 | 青蛇劫起（修罗城因缺能源而破，不是废土风） |
| 特效不喧宾夺主 | 白蛇：浮生（明确纪律） |
| 空间开阔、构图利落、色块分明 | 姜子牙 |
| 不讨好的造型 | 大圣归来（比例失衡而非丑化） |
| 弱透视、留白 | 长安三万里 |

**所以我们的目标画风可以一句话定义**：

> **这批片子的工艺层，取它们克制的那一半，再加上我们原著自己的脏与旧。**

## 五、风格段（可直接使用）

### 5.1 设计约束

写这段之前，三条硬约束（来自 `doc/07` 第三节和接口现实）：

1. **只写「怎么渲染」，不写「画面里有什么」。** 十个目标描述在各画风下逐字相同，
   风格段一旦掺进内容或配色，对比就无法归因。
2. **不写明暗与色调。** 目标描述里已经规定了光源与配色
   （T06 要求无阴影、T07 要求火光自下而上）。风格段再规定一次会打架。
3. **Images API 没有 `negative_prompt` 字段。** 反面词由脚本去重合并后，
   以自然语言追加在末尾。

### 5.2 主候选：S9「国风三维·克制版」

**中文**：

```
画风：中国院线三维CG动画电影，风格化写实。
形体、解剖与透视按真实构建，表面为物理着色——皮肤有次表面散射但毛孔被柔化，
布料能分辨出麻、棉、丝的织纹与垂坠，木石金属有真实的粗糙度差异与风化氧化；
细节密度低于真人摄影：不做皮肤瑕疵，不做胶片颗粒，不做镜头畸变。
头发为成束分组的发丝，有体积与走向，既不逐根散乱也不做块面。
造型为东亚骨相的古典写实：七至七头半身，眼裂细长、鼻梁不高耸、面中平缓、下颌不锐；
面容按人物的年龄、劳作与阶层如实塑造，老与丑照实做，全片没有统一的美型模板。
空间有大气层次，远中近三层由空气透视拉开；暗部不是死黑，保留环境光的冷色反弹。

不是美式三维卡通，不是游戏引擎实时渲染，不是真人摄影。
```

**English**：

```
style: contemporary Chinese theatrical 3D CG animated feature, stylized realism.
Forms, anatomy and perspective built realistically; surfaces physically shaded —
skin with subsurface scattering but softened pores, fabric with legible hemp, cotton or silk
weave and true drape, wood, stone and metal with real roughness variation and weathering.
Detail density below live action: no photographic skin blemishes, no film grain,
no lens distortion.
Hair groomed in grouped clumps with volume and direction, neither individual flyaway strands
nor flat blocks.
Character construction is East Asian classical realism: seven to seven-and-a-half heads tall,
narrow eye openings, low nose bridge, flat midface, soft jawline; faces built honestly from
each person's age, labour and social class, the old and the ugly rendered as such,
no single idealized beauty template anywhere.
Space reads in three depth planes separated by atmospheric perspective;
shadows are never crushed to pure black, they keep a cool environmental bounce.
Clean render: no outline strokes, no flat cel shading, no visible brushwork,

Not an American 3D cartoon, not a real-time game engine, not live-action photography.
```

这段话里没有一句是修辞，每句都在压一个已知的失败模式。

| 从句 | 对抗的失败模式 |
| --- | --- |
| 中国院线三维CG动画电影 | 模型默认把「动画」解成美式或日式 |
| 风格化写实 | 把它钉在写实与卡通之间的中间态 |

## 七、顺带发现的一个方法问题：现有风格段不干净

读 `matrix.json` 时发现的，**它会影响你怎么读矩阵结果**：

`doc/07` 第三节立了单一变量原则——风格段「只写怎么渲染，绝不改画面内容」。
但现有八个风格段里有几个越了界：

| 画风 | 越界的内容 | 后果 |
| --- | --- | --- |
| **S6** | 「美术根植于中国五代十国乱世——**破败城池、旧木旧石、战乱后的灰尘与损耗**；配色为灰褐、土黄、墨黑、暗红、冷青，**暗部占比高**」 | 这是美术内容 + 配色 + 明暗。它在 T01／T03 这类「要脏要旧」的格子上**天然占便宜**，在 T06「要无影要通透」的格子上**天然吃亏** |
| **S5** | 「场景取东方山水构图，注重远中近三层与留白；配色以青灰、墨黑、灰白为主」 | 构图 + 配色越界 |
| **S1** | 「大面积黑色暗部」「身形修长」 | 明暗 + 体型越界 |
| **S3** | 「大量留白，散点透视」 | 构图越界 |

干净的是 S2／S4／S7／S8。

**我没有擅自改 S1–S8**——那是你设计的实验，改了就不是原来那个实验了。
我只做了纯增量（加 S9–S11，且它们是干净的）。

要不要把配色／明暗／构图／美术内容从八个旧风格段里剥掉，请你拍板。
剥了才真正可比，代价是已有的选型设计要动一次。

### 8.1 一个顺带冒出来的设计机会（我的想法，你定）

`doc/05` 的唐假要解决一个难题：**让观众前二十多集不觉得他是故事里的人。**
现在靠的是「世界静止」这条规则。

如果主载体定成三维 CG，那就多出一个几乎免费的表达：

> **第一阶段的 Q 版唐假用二维手绘，站在三维世界里。**
> 他不是被渲染进这个世界的，他是画在画面上的。
>
> 到第 93 章那一集——他变成**三维等身**，坐在唐真对面，世界不静止。
> 观众不需要任何台词，光凭「他变成和这个世界同一种材质了」就知道出事了。

这把「二维／三维不统一」从缺陷变成了机关，而且和 `doc/05` 2.3
「他站在画面的纸面上，不进入景深」的设计**本来就是同一个意思**——
只是现在有了具体的实现手段。

代价：Q 版唐假要单独做一套二维美术，与主管线不共用。
收益：`doc/05` 2.4 那个揭底时刻的冲击力会强很多。

## 九、下一步：角色映射（第二步）

你已经给了三条：**唐真←杨戬、姚望舒←白素贞（小白）、姚安饶←小青。**

**材料是齐的**：`production/characters/_深度档案/` 里有 14 份逐字取证的角色深度档案，
含唐真、姚望舒、姚安饶、老拐子、南红枝、齐渊、尉天齐、王玉屏、吕藏锋、
姜羽、魏成、葛道人、南季礼、执法堂长老。每份都带原文段号，偏移量能被原文约束住。

**方法我打算这么做**（等你确认）：

```
角色 = 参考片基线角色  +  偏移量（每条偏移都要有原文段号支持）
                          ↑
                    没有合适基线时，写「无基线」，直接从原文长出来
```

**先给一个判断，说明这个方法为什么成立**——以唐真←杨戬为例：

这个映射在**处境结构**上准得惊人：杨戬是「曾经的战神，失了神力，隐于市做赏金猎人」；
唐真是「道法无双的少年天才，被人魔尊废了修为，成了破庙里的小乞丐」。
是同一个人物母题。

但在**外形**上要做大幅反向偏移：杨戬 1.9 米、九头身、美型、有胡茬；
唐真原文是二十二岁、「长得并不出彩」、「面如死灰，毫无灵气」、满脸尘土。

所以映射必须**分层取**：**取气质与处境，不取颜值与体量。**
这需要你确认——因为如果你要的是「唐真看起来像杨戬」，那是另一个决定，
而且它会和原则二冲突，我需要你明确说一声再往下走。

**这一步开工前需要你回答的**：

1. 映射是取**气质与处境**，还是取**造型外观**，还是分层？
2. 第一批映射做多少人？建议先做 E01–E02 用得上的（唐真、老拐子、南红枝、姚安饶、红儿、赵护卫、齐渊），
   够跑通就行，其余等画风定稿后批量做。
