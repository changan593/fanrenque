# 术语与编号表

全项目用到的词和编号，各自指什么、归谁管。看到一个不认识的记号先来这里。
字段级的含义在 `doc/09_数据字典.md`，这里只解释概念。

---

## 一、原文与章节

| 术语 | 含义 |
| --- | --- |
| **分析单元** / `seq` | 全项目的章节主键，1~1200，按原文文件顺序编号。站点把多章并在一页的算一个单元。**任何地方的章节号都是它。** |
| `declared_num` | 作者自己标的章号（第 N 章）。有 14 处重号、5 处跳号，只作参考，不做键。 |
| **合并单元** `is_merged` | 站点把 2~3 章塞进一页抓下来的单元，共 19 个，正文只有一章的量。清单见 `doc/11`。 |
| **段号** `para` / `[n]` | 一章正文按段切开后的序号，**一律 1 基**：模型看到的 `[n]`、章节 json 的 `para`、剧本声音栏的 `[n]`、取证文档的 `seqN[i]`、`s8` 卷宗的 `[n]` 都是同一套。 |
| `seqN[i]` / `seqN[i-j]` / `seqN[i][j]` | 取证文档里的段号引用：第 N 单元第 i 段；i 到 j 段；第 i 段与第 j 段各一处。解析在 `common/cite.py`。 |
| `【原】` / `【补】` | 只在 md 文档里用。`【原】` 后面的 `「…」` 是原文逐字引用，`s17` 会核对；`【补】` 是为了能出图而推断补全的内容，须写理由。 |
| 白噪音 | 书名里的那个——主角的系统坏掉后只剩「没了信号的老旧电视」那种声音。也是第一季的季名。 |

## 二、逐章分析与质量

| 术语 | 含义 |
| --- | --- |
| 抽取 / 结构审查 / 一致性审查 / 修订 | `s2` 每章的三次模型调用与可选的第四次。留痕在章节 json 的 `reviews`（抽取那一次记为 `extract_meta`）。 |
| **逐字核验** | 程序把每条引用（台词 / 心理活动 / 旁白 / 外貌与场景描写）回原文做归一化后的精确匹配。三档：exact 逐字、near 改写、miss 臆造。`common/verbatim.py`。 |
| **逐字命中率** `verbatim_rate` | exact ÷ 引用总数，合格线 95%。 |
| **臆造** miss | 原文里根本找不到的引用。合格线 = 0，**唯一不放宽的指标**。 |
| **改写** near | 原文里有很像的一句但不逐字（改了字、拼了句、混了旁白）。`s5` 能程序化对齐回原文。 |
| **台词覆盖率** `dialogue_coverage` | 原文带引号的说话有多少进了 `dialogues`。专盯漏抽，合格线 90%。与逐字率互补：一个防编造、一个防漏抄。 |
| **质量闸门** `quality.passed` | 结构分 ≥ 85、一致性分 ≥ 90、逐字率 ≥ 95%、臆造 = 0、台词覆盖 ≥ 90%，任一不过就修。实现只有一份：`common/quality.py`。 |
| **人工基准集** | `production/s01/manual_analysis/` 的 8 章手写分析，引用写位置不抄原文，由 `s2m` 装配。`run.model == "人工"`，不看模型分数。 |
| T1 / T2 / T3 | `s3` 体检的三级：T1 臆造（必须清零）、T2 逐字率 / 覆盖率 / 审查分不达标（要重跑 `s2`）、T3 登记不全 / 简介短 / 段号越界（只提示）。退出码只看 T1 / T2。 |
| 人名登记表 / 前文提要 | `s2` 抽取时喂给模型的两样上下文：已完成章节里的人物主名（统一写法）、前几章简介（审连贯性）。 |

## 三、人物身份

| 术语 | 含义 |
| --- | --- |
| **主名** `canonical_name` | 一个人的规范称呼，`s4` 归并别名后定的。 |
| **别名** `aliases` | 同一个人的其他叫法。归并用并查集，闸门建在簇上（成对检查挡不住传递性）。 |
| **PRESETS** | 人工逐字核实过的 17 个身份（别名边界 / 跨人歧义 / 排除词），带考据 `note`。在 `common/names.py`，`s4` 归并、`s8` 卷宗、`s9`/`s11`/`s13` 解析都以它为最高优先。 |
| `ambiguous` 存疑 | 可能指本人也可能指别人的称呼（「师妹」「姚姑娘」），单独统计，不并入。 |
| `exclude` 排除 | 含别名字样但另有所指的词组（「寿与天齐」不是尉天齐），先抹掉再匹配。 |
| **泛称**（严口径 `is_generic`） | 「老人」「小丫头」「众人」这类不指向具体某人的称呼。不进人物名单，不参与别名归并。 |
| **无名角色**（宽口径 `is_unnamed`） | 说话人 / 在场者带泛称词（「守城甲士」「永和楼楼主」）就不要求登记在册。只用于 `s3` / `s5` 的登记判断。 |
| **别名解析三级** `build_resolver` | 别名 → 主名：① PRESETS；② 索引里只有一个主名认领的；③ 多方认领 / 本身也是主名的**不猜**，原样保留并标存疑。 |
| **更名裁定** `RENAME_CANON` | 全剧对原文唯一一处更名：seq15[4] 的「南天礼」读作「南季礼」（笔误，全书仅此一次）。证据层不动，成片一律读南季礼。 |
| 主要 / 次要 / 龙套 | `s13` 按季的档位：本季出场 ≥ 10 章 / 3~9 章 / 其余。 |

## 四、剧本与旁白

| 术语 | 含义 |
| --- | --- |
| **集号** `S01E07` | 季两位 + 集两位。目录 `production/s01/E07/`。集的 seq 范围在 `data/plot/episodes.json`。 |
| **幕** | 一集里按场景切的段，`## 幕别｜幕题　seqN [a-b]`。一幕一目录 `NN_幕别_幕题/`。 |
| **镜号** | 三位数字，全集连号，是剧本、幕文档、承载账之间唯一的对位键。 |
| **关键旁白** | `analysis.narration`：交代设定、背景、时间推移、伏笔、重要情节的旁白。纯环境白描不算。受原则二保护。 |
| **白描** | 剧本里派给唐假、但不属于关键旁白的描写句。派了就要写 `※` 理由。 |
| **唐假** | 原著里那个「来书里躲班的读者」，被本剧用作旁白装置：第一阶段 Q 版、只在世界静止时现身。设计在 `doc/05`。 |
| **现身档** `【现】` / **声音档** `【白】` | 唐假出现且世界静止 / 只出声画面照常。现身每集 ≤ 6 次。 |
| **世界静止** | 现身档的视觉语法：一切运动冻结（含眨眼呼吸）、降饱和一档、唐假是唯一动的东西、无影子。 |
| **承载** / **承载账** | 每条关键旁白落到哪一镜、用哪种方式（现身 / 声音 / 字幕卡 / 画面 / 删除 / 实为台词 / 内心音）。账由 `s14` 生成，缺一条就是漏一条。 |
| **拆条** | 一条旁白拆到相邻两镜，各带同一个段号，拼回去必须等于原句。 |
| N0 ~ N6 | 旁白六类处置（`doc/05` 5.2）：N1 设定交代→唐假；N2 眼前动作 / N3 环境气氛 / N4 时间推移→画面；N5 断语格言→唐假或字幕卡；N6 冗余可删（判据窄，要登记）；N0 原文残留（「。。。」）剔除。 |
| `【台】` | 抽取把台词误判成旁白，剧本按现场台词落镜。 |
| `【心·某某】` | 角色内心音，低音量近场无混响，不给口型。 |
| `※` / `★` | 保留理由 / 给导演的备注。都不参与比对。 |

## 五、视觉资产

| 术语 | 含义 |
| --- | --- |
| **国风三维** | 画风载体：中国院线三维 CG 动画电影，风格化写实。金标准，`s15` 查冲突。 |

| **克制版追加约束** | 原则三落到提示词上的那一段，正式镜头必须带。 |
| **留痕豁免** | `s15` 对选型期文档（`doc/archive/`、`style_test/`）里旧载体词的放行，每条豁免都写了理由。 |
| **出图包** | `s16` 按幕把剧本、幕提示词、角色卡、场景卡、风格段装配成的一份可开工文档。 |

## 六、四套编号，各归各管

**别再开第五套。** 四套编号长得像，管的东西完全不同：

| 编号 | 样子 | 归谁 | 稳定性 |
| --- | --- | --- | --- |
| 章节 | `seq 27` / `ch0027` | `s1` 按文件顺序 | 补原文后 seq1118 之后会后移（`doc/11` 第四节） |
| 数据资产 | `c001_唐真` `s001_玉屏观`（**小写**，三位） | `s4` 按出场章数排序生成 | **重跑会变**，不要在任何人写文档里引用它 |
| 视觉资产卡 | `C01_唐真` `G05_紫云仙宫弟子群像` `S01_北阳城城隍庙`（**大写**，两位） | 人定，见下表 | 稳定，一旦分配不复用 |
| 集 / 幕 / 镜 | `S01E07` / `03_第三幕_寻香` / `镜 012` | 剧本 | 有剧本的集边界锁定 |
