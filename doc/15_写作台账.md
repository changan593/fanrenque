## 一、抽取误判逐集记录

### 1.0 先看结论：错法分成几族

47 集一条条对下来，`analysis` 三张表（`dialogues` / `monologues` / `narration`）的错误可以归成下面几族。
**逐字率 100% 保证的是「抄下来的字没错」，保证不了「放对了表、认对了人、标对了段」。**

| 族 | 表现 | 典型例 | 出现频度 |
| --- | --- | --- | --- |
| **同一行第二句引语没有继承说话人** | `speaker` 写「未明说」，而归属语就在同一行 | E21 `seq84[39][55]`、E33 `seq135[20][30]`、E35 `seq143[58][77]` | 自 E21 起连出十四例，**全书最稳定的一种错法** |
| **说话人指错** | 把听者当说者；给假设 / 转述 / 设想中的话安上人；把主角级角色认错 | E24 `seq93[55][56]`（唐真 vs 心魔）、E33 `seq135[81][86][88]`（红儿 vs 姚安饶）、E32 `seq127[4]` | 十余例，E33 最重 |
| **给没有人说的文字找说话人** | 银针上的字、玉符书信、一道目光 | E42 `seq175[16]`「银针上的字」、E43 `seq178[16]`「玉女峰使者」、E47 `seq198[6][7]` | `speaker` 字段永远会被填满，哪怕填进去的不是人 |
| **同一句挂两张表** | 同时进 `narration` 与 `dialogues` / `monologues`，正文一字不差 | E22 `seq88[50][62]`、E39 `seq164[33][37]`、E45 一集三例 | 比段号错位更常见；剧本用 `【台】` 或按内心音处置 |
| **段号错位** | `para` 与原文行号差 1~2，逐条产生、不是全局位移，同一句可被记两个位置 | E20 `seq78[44]`、E25 `seq99`、E38 一集四例、E46 `seq195[23/24]` | 十余例。**剧本段号以 `analysis` 为准，备注原文行号** |
| **切分点落在引号里** | 条目从头截断、吞掉上一行 / 下一行、两段引语加中间叙述并成一条 | E24 `seq93[46]`、E26 `seq101[27]`、E43 `seq181[57]` | 会让 `s14` 逐字检查误报，**属可放过的误报** |
| **收录不完备** | 整章只抽出几条 `narration`，全集的收束句都不在任何表里 | E34 `seq140[53]`「地底升起了太阳。」、E42 `seq174` 收录率 14% | 相邻章之间收录率可差八倍；剧本一律自己落镜 |
| **`function` 没有闭合词表** | 前 99 章用过 26 个值，全书 112 个 | E31 `seq123[34]`「过渡」 | `s3` 只统计不判错；写剧本时当提示不当依据 |
| **凭空造正文** | 一条原文不存在的台词 | E28 `seq108[17]`「姚安饶：为什么？」 | 全书仅此一例，同章真的那句「为什么？」却漏了 |
| **原文自身的问题** | 章节接缝重复、同一句两处引用末尾不同、人名异写 | E40 `seq167[52]`=`seq168[1]`、E41 `seq171[21]`、E31 杜有才 / 杜有为 | 不是抽取错，剧本照抄并注明 |

两点**不算错**，别当成问题去修：`speaker` 写「未明说」而原文此刻确实没说是谁（E38 `seq156[50]`「揭！」）；
`speaker` 写「弟子」「有人」而原文本来就只写了「这个弟子」「有人大喊」（E45）。

## 四、这份台账怎么用

- **写后续季的剧本**：先读第一节 1.0 的族表，逐条核对时按族防；`para` 一律以 `analysis` 为准并备注原文行号。
- **改抽取提示词 / `s5`**：第一节是需求清单——「同一行第二句引语继承说话人」「不许给假设 / 转述 / 无人说的文字安说话人」
  「一句只进一张表」「不确定就留空」这四条治得住大半。改完在人工基准集 8 章上对照。
- **评估某章数据可信度**：`dialogues` 最可信，`narration` 收录不完备，`speaker` 与 `para` 要核；
  `function` 只是提示。
- **新查出一类错**：先记进该集剧本的附表，有普遍性的再补进本文第一节；改了 `s14` 就补第二节。
