# 风格规范（草案）

本片一切视听决策的总约束。人物资产、场景资产、分镜脚本的提示词都必须受它管辖。

> **状态：画风载体已定稿，其余仍为草案。**
> 结论全部从原文统计与笔法取样中得出（第二节列了证据），不是凭印象。
> **待定项 A（画风载体）已落槌为国风三维**，见 3.1 与第十四节；
> B~F 仍待拍板。

## 一、总基调

**一句话：九洲是个有尘土味的世界，修行是门手艺，圣人也会老。**

三条判据，任何画面存疑时按这个顺序问：

1. **它像不像真的？** 布会皱，木会裂，脸会脏，光会被灰尘挡住。
2. **原文有没有？** 原文没写的元素一律不加——包括"看起来更好看"的元素。
3. **它炫不炫？** 炫就是错的。见下。

### 关键认识：这本书自己就是反奇观的

「严禁浮夸」不是我们外加的审美偏好，而是**原著自带的美学自觉**。作者在文本内部就嘲讽炫技：

> 「我说，这些术法看起来怎么跟**杂耍**似的？……」吕藏锋饮了口酒，有些无聊的抱怨道。
>
> 这不是他眼界高，他说其实是对的，大多数展示的术法都像是街边杂耍，
> **甚至还有喷火啊、放电啊这种几千年前道门就快研究透了的术法。**　　—— seq698

所以做成"喷火放电、流光溢彩"的网游 CG，不只是难看，是**违背原文**。
原则二和原则三在这本书上是同一件事。

## 二、证据

结论的可信度来自这里。全书 275 万字的词频统计与笔法取样。

### 2.1 作者刻意回避"炫"的词汇

| 词 | 全书出现次数 |
| --- | --- |
| 闪耀 | **1** |
| 刺目 | **2** |
| 华光 | **3** |
| 绚烂 | 12 |
| 璀璨 | 16 |

对照组（朴素/破败质感）：

| 词 | 次数 | | 词 | 次数 |
| --- | --- | --- | --- | --- |
| 旧 | **526** | | 尘土 | 56 |
| 脏 | **152** | | 灰尘 | 50 |
| 破烂 | 73 | | 皱纹 | 27 |
| 泥土 | 38 | | 干瘪 | 27 |

275 万字里"璀璨"只有 16 次，"脏"有 152 次。**质感基线由此确定。**

### 2.2 色彩极度克制

白 429 / 黑 422 / 金 370 / 红 349 是四大主色，之后断崖：
黄 127、紫 114、青 78、绿 63、灰 39、血色 38、蓝 25、墨色 6、**银色 2、暗色 0**。

全书色彩词总量约 2000 次，摊到 1200 章**平均每章不到 2 个**。
作者不靠颜色堆画面。

光效词也集中在朴素的那几个：光芒 168、白光 110、流光 109、金光 70、霞光 43、光柱 42。

### 2.3 出手动作是极简的

| 词 | 次数 | | 词 | 次数 |
| --- | --- | --- | --- | --- |
| 震 | 381 | | 一剑 | 185 |
| 斩 | 296 | | 一拳 | 37 |
| 刺 | 294 | | 一掌 | 32 |
| 轰 | 230 | | 崩碎 | 4 |
| **抬手** | **202** | | 炸裂 | **0** |

**「抬手」202 次**——高手出手就是抬一下手，没有起手式、没有喊招名。
「炸裂」0 次、「崩碎」4 次——不追求爆炸场面。

### 2.4 人物描写反美化

原文取样（逐字）：

> 瘦瘦的白脸男子，面色古板，**长得并不出彩**，第一眼看上去有些木讷。
> 右客位上则坐着一个穿着常服的**小胖子，面相憨厚，此时正不断抹着额头上的汗**。　　—— seq70

> 眼前这个看起来如同老拐子的老人**身穿着一件破破烂烂的儒袍，有些地方甚至露出干瘪而衰老的身躯**，
> 但他确实是那个儒门领袖、大夏帝师、洛学的创始人——程圣程伊！　　—— seq1185

> 那是一个**穿着道袍，但敞着衣襟，露出一身腱子肉的青年**，
> 此时正一边饮酒，一边与酒肆老板的闺女逗闷子。　　—— seq680

儒门领袖穿破烂儒袍露出干瘪身躯，重要人物"长得并不出彩"。
**修为高低不体现在颜值和排场上。**

### 2.5 抒情的上限在这里

全书最诗意的笔法长这样，用**比喻**而非堆形容词：

> 只见远处的道路旁站着一个身着白衣的身影，他正忘情的吹奏着洞箫，
> **白色衣摆被风带起，像是一竖白幡，孤高清傲。又像是一柄长剑，冷冽潇洒。**　　—— seq55

一个白衣、一支箫、风、两个比喻。没有花瓣、没有光晕、没有粒子。**这就是天花板。**

### 2.6 暴力靠冷静而非血浆

全书最暴力的段落之一（五百活尸屠城）：

> 今夜，北阳城内出现了一场奇怪的骚乱……但一切都很快出现又很快消失，像是一阵阵潮水时起时落。
>
> **只要死亡跑得快，恐惧便不会蔓延。**
>
> 太少了！……可如今的北阳城里的这么点人**根本不足以喂饱师父的手指和活尸**！　　—— seq32

屠城被写成**资源核算**。恐怖来自冷静的旁白和视角的冷酷，不是来自画面刺激。

### 2.7 术法是技术，不是神迹

> 「剑道最初不过也是**直刺**而已，所有惊世的术法刚开始也不过是简单的杂耍……
> 它被评为**乙等二类**……如果买入宗门之中，经过**几代人甚至十几代人的研究与开发**，
> 最终，它就有可能成为天下知名的巧斗之术。」　　—— seq698

术法有**评级体系**（乙等二类/三类）、有**研发**、有**买卖**、有**方向**。

作者还持续祛魅——迦叶讲"斩缘"：

> 「如今九洲上流传的『斩缘』功效是**经过一定的艺术加工的**……
> 实际上斩缘的核心在于『斩』，是一种**割离，而非抹除**。」　　—— seq652

民间传得神乎其神，真实原理平实。**这个祛魅态度要贯穿到画面上。**

### 2.8 结尾定调

> 螺生之乱，五十年
> 南洲二次月牧，怀素执掌月轮，独夫与道圣于南洲月上饮了一夜美酒，随后一同不见。
> 同年冬，魔尊阿难被高人斩于东海，天下佛宗共颂往生。
> **余事无可记述。**

编年体，极度收束。**全片的收尾气质以此为准。**

### 2.9 篇幅与对话密度

单章中位 2153 字，对话占比中位 **19.1%**（最高 69.1%）。
这是一本**对话戏和心理戏很重**的书，不是动作书。分镜要按这个比例分配。

## 三、画风

### 3.1 载体

**国风三维**——中国院线三维 CG 动画电影，风格化写实。✅ **已定稿**（原待定项 A）。

理由：

- **参照系本身就是三维。** 指定的八部参照片（大圣归来／白蛇三部／姜子牙／哪吒重生／
  杨戬／长安三万里）**没有一部是二维厚涂**。拆解见 [`12_参考片画风研究.md`](12_参考片画风研究.md)
- **跨集人脸一致性只有三维扛得住。** 全片 12,958 镜、268 集，靠的是
  「身份母版 → 阶段卡 → 剧情镜头」的派生链（见 `production/characters/README.md`）。
  三维的头骨几何可以逐项锁定并在所有景别复现；厚涂的笔触每次重画都是一次重新解释
- **「旧、脏、有尘」在三维里靠 PBR 而不是笔触。** 粗糙度、织纹、氧化、磨损是材质参数，
  比笔触更可控也更稳定，同样承载得住 2.1 的质感基线
- 修行元素（术法、法相）在风格化写实框架下不出戏

**落地资产**（写任何提示词前先读这两份）：

| 管什么 | 文件 |
| --- | --- |
| 场景与环境怎么渲染 | [`../production/style_assets/统一风格提示词.md`](../production/style_assets/统一风格提示词.md) |
| 人物怎么塑造与锁身份 | [`../production/style_assets/统一角色提示词.md`](../production/style_assets/统一角色提示词.md) |

**定稿不等于放松第三节其余各条。** 三维只是载体，2.1 的质感基线、3.3 的负面清单、
7.3 的奇观额度一条不减——国风三维电影普遍偏奇观、偏美型，那正是本片要反着做的地方。
正式镜头必须带「项目克制版追加约束」。

### 3.2 质感基线

| 项 | 要求 |
| --- | --- |
| 表面 | 一切物体有使用痕迹：木有裂、布有褶、墙有污渍、金属有氧化 |
| 空气 | 允许可见的浮尘、雾、烟；空气不是绝对通透的 |
| 布料 | 有重量、有垂坠、有磨损。**不飘、不发光** |
| 皮肤 | 有晒痕、污渍、色差。老人有斑和皱纹。**毛孔柔化**——细节密度低于真人摄影，但不磨皮 |
| 边缘 | 干净柔顺、抗锯齿良好。**无笔触、无颗粒、无锐化光晕**（3.1 定稿为三维后此条已改） |
| 材质 | 麻、棉、绢、丝、皮革、金属、木石有可辨认的粗糙度、织纹、厚薄与反射差异 |

### 3.3 不要什么

**渲染层面的负面清单**（写进每个提示词的 negative）：

```
璀璨, 绚烂, 华丽, 闪耀, 光效泛滥, 粒子特效, 镜头光晕, 廉价发光,
过饱和, 霓虹, 塑料感, 油光, 磨皮, 网游CG, 手游立绘, 卡通渲染,
完美对称, 全新无磨损, 悬浮的花瓣, 无来由的风, 背景虚化到糊
```

3.1 定稿为三维后，**追加**这一组（防的是国风三维最容易滑过去的三个方向：
美式卡通、游戏感、真人化）：

```
皮克斯风格, 迪士尼三维, 美式三维卡通, 大眼睛, 圆脸萌化, 头身比缩短,
统一美型脸, 网红脸, 蜡像感, 游戏CG, 实时渲染感, 游戏引擎截图, 低多边形,
线稿描边, 赛璐璐平涂, 厚涂笔触, 水墨渲染, 照片写实, 真人剧照,
轮廓光泛滥, 仙气, 飘带, 花瓣, 胶片颗粒, 过度锐化, 过度HDR
```

**完整可复制的负面段以
[`../production/style_assets/统一角色提示词.md`](../production/style_assets/统一角色提示词.md)
的「公共负面约束」为准**——那份还含身份漂移类的约束（换脸、混脸、眼距漂移、
阶段标志物误继承等），本节只列渲染层面的。两处冲突时以那份为准。

## 四、人物风格

### 4.1 长相

**允许普通，甚至允许难看。** 原文明说「长得并不出彩」「有些木讷」「小胖子，面相憨厚」。

- 主角唐真额头正中有黑色椭圆形印记（"三只眼"由来），这是**必锁特征**
- 配角要有辨识度靠**特征**（跛脚、皱纹、胖瘦、口音带来的表情习惯），不靠美貌
- 反派不做成骷髅妆和血红瞳；魔道人物外表可以完全正常

### 4.2 修为不体现在外表

原文的圣人穿破烂儒袍。所以：

- **不给高修为角色自动加光环、法衣、悬浮、发光眼**
- 身份靠**服制**区分（儒袍/道袍/僧衣/官服/常服/短打），不靠特效
- 唯一例外：原文明确写了异象的场合，按原文写的来

### 4.3 服饰

原文出现过的服饰词：儒袍、道袍、常服、长裙、短打、足衣、戏服、锦袍、甲。

| 阶层 | 参考 |
| --- | --- |
| 乞丐/贫民 | 粗布、麻布、补丁、草鞋、赤脚。**颜色是脏掉的土色，不是设计过的做旧** |
| 市井 | 常服，素色，洗得发白 |
| 修士/宗门 | 制式但不华丽；紫云仙宫紫、佛宗僧衣、儒门儒袍 |
| 权贵 | 锦袍，有纹样但不金光闪闪 |

### 4.4 表情与体态

- 情绪靠**微表情和小动作**：抹汗、掐手指掐红、挠后背、打哈欠
- 原文的情绪表达是压着的，画面也压着。**不做夸张变形和漫画式表情符号**
- 站姿有性格：唐真"一身破烂却站的笔直"

## 五、场景风格

### 5.1 主场景是生活空间

词频：院子 297、街道 195、酒楼 122、客栈 30、小巷 21、摊子 15、集市 4。
**这是一本大量发生在院子和街上的书**，不是一直在洞天福地。

### 5.2 三档空间

| 档 | 例子 | 处理 |
| --- | --- | --- |
| 市井 | 城隍庙、街道、酒楼、院子、茶馆 | 最重要的一档。脏、旧、拥挤、有生活垃圾和气味感 |
| 宗门 | 紫云仙宫、佛寺、书院 | 庄重但**不奢华**。木石为主，规模感靠体量不靠装饰 |
| 异境 | 秘境、法相、月上、海眼 | 全片的奇观额度都在这。**每季不超过 3-5 处**，且必须原文明写 |

### 5.3 环境叙事

原文的场景描写总带信息：
「从屋顶的**破洞**照进这间小庙，照的一切金晃晃，已是正午时分」——
破洞交代了贫穷，金晃晃交代了时间。

**每个场景至少有一个细节在交代信息**（贫富、时节、时辰、有人住多久），
不做纯装饰性的美术堆砌。

## 六、动作与打斗

### 6.1 核心原则：快、短、有代价

- 出手就是**「抬手」**（202 次）。没有起手式，没有喊招名，没有摆造型
- 交手回合少，一两个动作定胜负。原文「一剑」185 次，是一剑的事
- 「炸裂」0 次——**不做爆炸奇观**

### 6.2 打斗的重量感来自后果

原文的打斗强度体现在**结果**上：谁倒下、谁吐血、谁修为废了、谁死了。
过程反而简短。所以分镜配比：

```
起手 10%  ──  交手 30%  ──  结果与反应 60%
```

**镜头要多给在打完之后**：伤口、喘息、周围人的脸、地上的痕迹。

### 6.3 打斗的层级

| 层级 | 表现 |
| --- | --- |
| 凡人/低阶 | 完全写实的搏斗，刀剑、拳脚、疼痛、笨拙 |
| 修士 | 速度和力量超常，但仍是**人的动作**。术法作为工具介入 |
| 圣人/魔尊 | 极简。抬手、一句话、一个眼神。**天地异象要有，但要短** |

层级越高，动作越少。**这是本片的铁律**——反直觉但忠于原文。

## 七、术法与特效

**这是最容易做坏的一环，约束最严。**

### 7.1 三条禁令

1. **禁喷火放电。** 原文明说这是「街边杂耍」（2.7）。任何元素系直球特效都要重新设计
2. **禁粒子堆砌。** 不要漫天光点、能量流、符文环绕
3. **禁招式名字幕。** 原文没有喊招的写法

### 7.2 术法该长什么样

按原文的"技术"定位来设计：

- **有物理逻辑**：术法作用于真实的东西——风向、水、影子、镜面、纸笔、灯火
- **有痕迹**：用完留下痕迹（地面刻痕、水面涟漪、纸上墨迹、灯灭）
- **有代价**：施术者会累、会流汗、会伤。原文「手中术法掐的死死地，手指间都掐红了」
- **可复现**：同一个术法每次出现的视觉表现必须一致（写进术法资产）

举例：「镜中假身」（原文乙等二类）应该表现为**镜面/水面里多出一个身影**，
而不是"分身炸出金光"。原文借吕藏锋的话点明破法方式是「**看看风向或者环境**」——
说明假身与环境的交互是有破绽的，这个破绽本身就是最好的视觉设计。

### 7.3 奇观额度制

全片按季分配奇观额度，**用超了必须砍**：

| 类型 | 每季上限 | 说明 |
| --- | --- | --- |
| 天地异象级 | 3 次 | 云层撕裂、山峦落下、法相显现这类 |
| 大范围场面 | 5 次 | 巨大建筑、万人场面 |
| 单体强术法 | 每集 ≤ 1 次 | 且必须原文明写 |

原文里「一只巨大的凤凰背负起一整片塌落天空，**这是多么震撼的一幕**」（seq923）——
作者自己都要点明"震撼"，说明这种场面在书里是**稀有事件**。稀有才震撼。

### 7.4 特效的色彩

沿用 2.2 的统计：白、黑、金、红为主。
**禁用**霓虹色、渐变彩虹、赛博蓝紫。银色几乎不用（全书 2 次）。

## 八、对话风格

### 8.1 台词一律用原文

原则二的硬要求。台词逐字来自原文，逐章分析里的 `dialogues[].text` 就是台词表，
已由程序做过逐字核验。**编剧环节不改台词**，只做删减（选择呈现哪些）和分配。

### 8.2 语域分层

原文的人物说话是分层的，配音和口型都要照这个来：

| 层 | 特征 | 例 |
| --- | --- | --- |
| 市井 | 大量语气词、方言味、粗话 | 「饿死你们这帮瘪犊子！」「得嘞，谢谢赵爷！」 |
| 江湖/同辈 | 半文半白，带调侃 | 「我就说我那姐姐不会如此想的。」 |
| 宗门/长辈 | 文言化，端正 | 「你行事偏激，愧对圣位，不及你师父多矣。」 |
| 圣人/说理 | 格言体，短句 | 「人之所思不由人，人之所悟不由心。」 |

**同一角色在不同场合会切换语域**（唐真对乞丐和对圣人是两种说法），这点要保住。

### 8.3 表演基调

克制。原文的人物很少嘶吼。情绪最激烈处（第 1 章宫主暴喝）也是**几句话说完**。
配音**不飙戏**，靠停顿和气声。

## 九、旁白与心理活动

原文有大量关键旁白和心理活动，你要求一个都不能漏。
处理方式已定，**完整规范在 [`doc/05_唐假旁白系统.md`](05_唐假旁白系统.md) 第五节**，这里只记结论：

- **旁白不全给声音。** 判据一条：**这条旁白的信息，摄影机拍得出来吗？**
  拍得出来（眼前动作、环境气氛、时间推移）→ **画面演，不出声**；
  拍不出来（来历、前史、动机、制度、主观感受、作者断语）→ 唐假念
- **角色内心音**：心理活动**全部**用角色本人的声音，**低音量、近场、无混响**，与台词区分
- **字幕卡**：留给全书级的格言式句子和编年体段落。**每集不超过 2 次**，优先给作者断语
- **可删的那一档很窄**：原则二原话保的是「**关键**旁白」。
  只有「信息已被同集别处覆盖」**且**「不是招牌句」两条同时成立才判可删，
  且只标建议、由你点头才真删。**不许用「意义不大」当理由**——那是感觉不是判据
- **承载账**：每条 `narration` 都必须在剧本里落到一个承载上并写明镜号，
  删掉的也要在账上并写明被哪一条覆盖。**账上缺一条 = 漏一条**。
  这是把「用画面表达」「按判据删掉」和「悄悄删掉」区分开的唯一办法

> 早先的方案是「`narration` 全给唐假」。看完 E01/E02 剧本后改了——
> 唐真把桃木枝别回腰间这种纯动作，画面演一遍再用嘴说一遍就是啰嗦，
> 而且它挤掉了唐假真正该说的那几句。E01 实测：唐假开口从 29 条降到约 12 条。

原文有大量这类适合画外音的句子：

> 只要死亡跑得快，恐惧便不会蔓延。
> 一代天骄，一朝散尽。
> 他不讲你的情绪怎样，他只讲死后的人可能怎么想。

这些是这本书的味道所在，**丢了就不是这本书了**。

## 十、转场

### 10.1 基调：硬切为主

朴素真实的反面是花哨转场。**禁用**：翻页、旋转、粒子消散、水墨晕开、光效擦除。

| 场合 | 转场 |
| --- | --- |
| 同场景内 | 硬切 |
| 换场景 | 硬切，或 3-6 帧短黑场 |
| 时间跳跃 | 黑场 + 字幕（「三日后」等，**须原文有依据**） |
| 回忆/梦境进出 | 降饱和 + 声音先入。原文第 1 章就是梦境开场，这是全书重要手法 |
| 集与集之间 | 黑场 |

### 10.2 梦境与回忆的处理

原文开篇就是梦境闪回（唐真被逐出师门），且全书多次使用。
**统一处理**：色相偏冷、饱和降低、边缘轻微失焦、环境音抽空只留人声。
**不要**用泛白光晕或波纹特效。

## 十一、观感与节奏

### 11.1 节奏基准（待定项 D）

**倾向：动画常规节奏，平均镜头 4-6 秒，允许静止和留白。**

理由：对话占比中位 19.1%，这是对话戏和心理戏很重的书。
切成 2-3 秒的短剧快节奏会把对话戏剁碎，与克制气质冲突。

分层建议：

| 段落类型 | 平均镜头长度 |
| --- | --- |
| 日常/市井 | 5-7 秒，可有空镜 |
| 对话/说理 | 4-6 秒 |
| 冲突/转折 | 2-4 秒 |
| 打斗交手 | 1-3 秒 |
| 打斗后的反应 | 4-8 秒（重点，见 6.2） |

### 11.2 每集结构

```
0:00-0:30   前情提要（第2集起）
0:30-1:30   冷开场：从上一集的钩子接续，或本集最强画面
1:30-末2分  正片，2~5 个章节单元
末 60 秒    钩子 + 下集预告
```

> 上面的时间轴是**结构比例，不是时长规格**。时长规格先后作废过两版
>（8-12 分钟 → 25~32 分钟）：E01~E06 实测散在 19:41 到 48:34 之间，
> 因为一集多长是「这一集有多少内容必须落地」的结果。
> **现已决定不对时长做预设**，见 `doc/00_项目总纲.md` 第二节。

### 11.3 镜头语言

- **多用中景和中近景。** 这是一本讲人和人关系的书
- **少用大特写。** 特写留给关键情绪和关键物件
- **手持感克制。** 允许轻微呼吸感，不做剧烈晃动
- **构图不追求完美对称**，允许人物偏离中心

## 十二、色彩与光

### 12.1 全片调色

| 项 | 设定 |
| --- | --- |
| 主色 | 白、黑、金、红（2.2） |
| 饱和度 | 整体偏低。市井段落最低 |
| 对比 | 中等。**不做高反差硬调** |
| 色温 | 随场景走，室内偏暖（灯火），室外按时辰 |

### 12.2 光源要有出处

每个画面的光必须能指出来源：日、月、灯、火、术法。
**禁止**无来源的环境发光、人物自发光、背景霞光泛滥。

### 12.3 分季色彩（待定，需等剧情线）

留待阶段三剧情线出来后，按每季的情绪基调定各季调色偏移。

## 十五、怎么用这份文档

1. **阶段四**：结合角色/场景资产复核本文档，把 B~F 也定下来，届时去掉"草案"字样
2. **写角色资产提示词**：第三、四、十二节是硬约束；具体特征从 `data/characters/` 里的
   原文描写逐字取，**不得自行发挥**。渲染与身份锁定段直接用
   [`../production/style_assets/统一角色提示词.md`](../production/style_assets/统一角色提示词.md)，别另写一套
3. **写场景资产提示词**：第三、五、十二节是硬约束；具体细节从 `data/scenes/` 取。
   渲染段直接用 [`../production/style_assets/统一风格提示词.md`](../production/style_assets/统一风格提示词.md)
4. **写分镜脚本**：第六至十一节逐条对照，末尾用第十三节自查表过一遍
5. **审片**：第十三节自查表就是验收标准

**本文档与原文冲突时，以原文为准。** 本文档只在原文没有明确规定的地方作数。
