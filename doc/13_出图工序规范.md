# 出图工序规范（阶段六 6.1／6.3）

**本规范只管出图。** 视频、配音、剪辑不在本文范围——
用户已定：**先把每一张图做好，视频后续再想办法**。
各幕提示词里已经写好的 `**视频动态**` 字段**原样保留不动**，等做视频时再用。

配套闸门：`python pipeline/s18_render_ledger.py`

---

## 一、先分清四类图，它们的规矩完全不同

| 类 | 是什么 | 入库？ | 权威性 |
| --- | --- | --- | --- |
| **① 角色卡** | 身份母版 + 状态卡 | ✅ **入库** | ★ 验收后是身份的最高权威 |
| **② 场景卡** | 场景母版 + 状态卡 + 平面图 | ✅ **入库** | ★ 验收后是几何的最高权威 |
| **③ 镜头首帧** | 每一镜的画面 | ❌ **不入库** | 成片素材，不是权威 |
| ④ 视频 | （后续） | ❌ | — |

**为什么 ③ 不入库**：第一季 47 集 12,958 镜，一镜至少一张、平均 2~3 版，
按每张 2MB 算是 **50GB 以上**。仓库存不下，也不该存——
它们**由「卡 + 幕提示词 + 风格段」确定地推导出来**，属于
根 `README.md` 说的「删了能重跑」那一类。

★ **但「选了哪一版」是人的判断，删了就没了。**
所以**入库的是台账**（`出图台账.md`），不是图：
台账记着每一镜用的哪一版、什么参数、谁验收的、什么时候。
`production/style_test/out/` 早就是这个规矩（已在 `.gitignore`），本规范只是把它推广到成片。

## 二、依赖顺序：不许倒着来

```
① 角色卡验收通过 ─┐
                  ├─→ ③ 镜头首帧
② 场景卡验收通过 ─┘
```

**一镜里出现的每一个角色、每一个场景，其卡必须已经验收通过。**

★ 这不是流程洁癖。`production/characters/README.md` 的身份优先级链写着
「**已批准**身份母版图片 > 已批准阶段卡图片 > ……」——
**「已批准」是前提不是形容词**。拿没验收的卡去出 212 张镜头，
等卡改了（红儿 V5→V6 就是这么改的），212 张全部作废。

**当前状态**：E01 的卡 PNG 已全部生成，**验收 0 张**——所以 ③ 还不能开工。

## 三、一镜怎么出：九步装配

不要手工拼提示词，用装配器：

```bash
python pipeline/s16_shot_pack.py s01/E01/01_第一幕_北阳城城隍庙 -o pack.md
```

它按 `production/style_assets/README.md` 的九步顺序，把
剧本 → 幕提示词 → 角色卡 → 场景卡 → 风格段 装配好，并列出该幕要挂的参考图。

**九步的优先级不许颠倒**，越靠前越高：

```
1 原文与镜头事实 ＞ 2 身份母版 ＞ 3 阶段卡 ＞ 4 画面内容
＞ 5 统一角色提示词 ＞ 6 角色卡追加段 ＞ 7 克制版 ＞ 8 公共负面 ＞ 9 统一风格提示词
```

★ **第 7 步克制版不是可选项**（原则三是硬约束）。

### 双层镜头

剧本声音栏标 `【现】` 的镜头（唐假现身、世界静止）**一镜出两张**：
**底图**（冻结的世界）＋ **唐假叠加层**，两份提示词分开写、分开出，后期合成。
规格见 `production/s01/_总则与模板.md` 第五节与 `production/characters/C53_唐假/`。

E01 有 5 处：镜 006 / 088 / 192 / 211 及第八幕另一处（见 `E01/旁白承载账.md`）。

## 四、参数

| 项 | 值 | 说明 |
| --- | --- | --- |
| `IMAGE_MODEL` | `gpt-image-1` | `.env` |
| `IMAGE_SIZE` | **`1536x1024`** | ★ 接口给不出 16:9，最接近的是 3:2 |
| `IMAGE_CROP_169` | **`1`** | 出完**本地居中裁成精确 16:9**（→ 1536×864），全片画幅已定 16:9 |
| `IMAGE_QUALITY` | `high` | |
| 每镜张数 | 一批 **3** 张，挑一张 | 挑不出就改提示词重来，不要盲目加量 |

★ **尺寸档位是踩过坑的**（`doc/10` 5.3）：`1792x1024` 是 dall-e-3 的档位，
`gpt-image-*` 只认 `1024x1024 / 1536x1024 / 1024x1536 / auto`；
拿错会被上游拒掉、网关包成 502「Upstream network error」，看着像网络故障。
`config.image_size_check()` 会在发请求前自查。

## 六、出图台账（入库的那份）

每集一份 `出图台账.md`，一镜一行（双层镜头两行）：

```markdown
| 镜 | 幕 | 层 | 采用版本 | 验收 | 日期 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 012 | 01 | — | E01_M012_t03.png | ✅ | 2026-08-28 | |
| 013 | 01 | — | — | ❌ | 2026-08-28 | 黑印被画成反光，改幕提示词负面段后重出 |
| 006 | 00 | base | E01_M006_base_t02.png | ✅ | 2026-08-28 | |
| 006 | 00 | tangjia | E01_M006_tangjia_t01.png | ✅ | 2026-08-28 | |
```

- **验收**：`✅` 通过 ／ `❌` 退回重做 ／ `—` 还没做
- **采用版本**：通过时必填，且必须是真实存在过的文件名
- ★ **退回的行要写清楚「改了哪一层」**——这是返工决策的留痕，见下一节

闸门 `s18_render_ledger.py` 会查：
每一镜都有行、镜号与幕文档对得上、通过的行有采用版本、文件名合规。

## 七、验收判据：三层，逐层过

### 第一层　身份与几何（最硬，不通过就不看后面）

- [ ] 每个入画角色**与已验收的角色卡是同一个人**（脸、比例、固定不对称、标志物）
- [ ] 阶段变化项正确（服装、发式、伤势——不能拿错阶段）
- [ ] 场景**几何与场景卡一致**（机位在平面图上找得到、锁定项在位）
- [ ] 该幕的**光源出处唯一且正确**（E01 第一幕：只有破洞日光柱）

### 第二层　画面内容与原文

- [ ] 镜头做到了「元素清单」里的每一条
- [ ] 没有违反「负面/禁改」里的任何一条
- [ ] ★ 没有原文没有的东西——**原则二**

### 第三层　风格

- [ ] 国风三维、朴素克制（原则三）
- [ ] 没有光效、粒子、镜头光晕、过饱和、磨皮
- [ ] 与同幕已通过的镜头**放在一起看是同一部片子**

★ **第三层要成组看，不要单张看。** 单张都合格、放一起风格跳，仍是不合格。

## 八、返工决策树：出了问题该改哪一层

★ **这一节是本规范最要紧的部分。**
最常见的错误是「哪不对就在单镜提示词里补一句」——**那是画风与身份漂移的起点**。

| 症状 | 病根在 | 改哪里 | 影响面 |
| --- | --- | --- | --- |
| 人脸不像 / 换了个人 | ② 身份母版 | **回角色卡**，必要时重出卡并重新验收 | 全季 |
| 服装、发式、标志物错 | ③ 阶段卡 | 回该角色的状态卡 | 该阶段所有镜 |
| 场景几何、机位对不上 | ② 场景卡 | 回场景母版（含平面图） | 该场景所有镜 |
| 构图、动作、表情、视线不对 | ④ 画面内容 | **改该幕提示词的这一镜** | 仅本镜 ✅ |
| 光源出处不对 | ④ 或场景状态卡 | 先看幕基调，再看场景状态卡 | 本幕或该状态 |
| 风格跑偏（浮夸、光效、饱和） | ⑨ 风格段 | **改 `style_assets/`** | ★ 全季一改全生效 |
| 画面里有原文没有的东西 | ① 原文 | 回剧本与原文核对 | 看情况 |

**三条纪律：**

1. ★ **身份问题绝不在单镜提示词里修。** 在一镜里补一句「她的脸更瘦一点」，
   等于给这一镜开了一张私有的角色卡——`C01_唐真` 曾经三张阶段卡各手写一段渲染锁，
   就是这么来的（`s15` 现在会查）。
2. ★ **风格问题绝不在单镜提示词里修。** 第 4 步画面内容层**刻意不含风格词**
   （`production/s01/_总则与模板.md` 第一节），风格段由程序统一追加——
   改一次全季生效，不必回改 12,958 条。
3. **改了上游就要往下同步。** 角色卡改版后，
   **该角色已通过的镜头全部退回**（台账把那些行改回 `❌` 并注明原因）。
   ★ 红儿 V5→V6 正是这种情况——幸好还没开始出镜头。

## 九、批次策略：先立标杆，再放量

**不要一上来就跑 212 镜。**

1. **第一批：一幕的关键镜**（3~5 镜）——建立镜（establishing shot）＋
   每个角色的首次入画镜。**人工逐张验收**。
2. 通过后**补齐这一幕剩余镜头**，成组看第三层（风格一致性）。
3. 一幕全部通过，再开下一幕。
4. ★ **第一幕是全季的标杆**，它定下的质感会被后面 46 集抄——慢一点值得。

**建议的 E01 第一批**（第一幕，21 镜里挑 4 镜）：

| 镜 | 为什么选它 |
| --- | --- |
| 012 | 建立镜：确立本幕唯一光源（破洞日光柱）与庙的破败质感 |
| 016 | 唐真首次正脸入画，黑印锁定项的第一次检验 |
| 019 | 老拐子首次入画，★ 右脚锁定项与「反美化」的第一次检验 |
| 030 | ★ 唐真黑印 vs 老拐子胎记的同框对照——本幕的构图母题 |

## 十、闸门

```bash
python pipeline/s18_render_ledger.py                # 全季
python pipeline/s18_render_ledger.py --episode E01  # 单集
```

查五件事：

1. 台账文件在不在、表头对不对
2. **幕文档里的每一镜在台账里都有行**（漏镜是最常见的错）
3. 台账里没有幕文档里不存在的镜号
4. 验收 `✅` 的行**必须有采用版本**，且文件名合规
5. 双层镜头（`【现】`）**两层都要有行**

**跑通不代表图好看**——它只保证「没有漏镜、没有糊账」。质量靠第七节的人工验收。
