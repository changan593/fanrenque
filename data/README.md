# data —— 机器产出的数据资产

**这里的东西全部由 `pipeline/` 的脚本算出来，删了能重跑。** 要改这里的内容，正确做法是去改产生它的脚本
（或它的输入），而不是手改文件。对照：`production/` 里的东西是人写的，删了就没了。

**唯一例外是 `manual/`**：人定的输入，脚本只读不写，改了它就重跑下游。

每个文件、每个字段的详细含义见 [`../doc/09_数据字典.md`](../doc/09_数据字典.md)。

| 目录 | 内容 | 产出脚本 |
| --- | --- | --- |
| `chapters/` | 逐章分析，一章一个 `chNNNN.json`，共 1200 个 | `s2` / `s2m` / `s5` |
| `characters/` | 角色资产 997 个（`cNNN_名字.json`）+ `index.json` | `s4` |
| `scenes/` | 场景资产 1364 个（`sNNN_名字.json`）+ `index.json` | `s4` |
| `dossiers/` | 17 份角色原文卷宗的阅读稿 `dossier_名字.md`（机器读的 `.json` 不入库，重跑即得） | `s8` |
| `plot/` | 全书结构：剧情线、卷段、分集表、每集资产、按季清单、同框、探查 | `s0` / `s4` / `s9` ~ `s13` |
| `manual/` | ★ 人定的输入：`seasons.json` 六季定义、`arcs_manual_p02.md` 人工卷段、`threads.json` / `structure_signals.json` 一次性分析产物 | 人 |

## 三种角色文件，各干各的

| 文件 | 是什么 | 谁写的 | 能不能重跑 |
| --- | --- | --- | --- |
| `characters/cNNN_名字.json` | **角色资产**：出场章节、称呼、原文描写汇总、状态、行为 | `s4` 从 1200 份分析聚合 | ✅ 重跑会变，编号也会变，**别在文档里引用 `cNNN`** |
| `dossiers/dossier_名字.md` | **原文卷宗**：这个角色在全书的每一次出现 + 上下文 | `s8` 从原文扫描 | ✅ 逐字节可复现 |
| `../production/characters/_深度档案/名字_角色深度档案.md` | **深度档案**：性格、轨迹、关系的成文分析 | 人（读卷宗后逐字取证写成） | ❌ 所以不在 `data/` |

写角色文档的顺序是 **卷宗 → 深度档案 → 卡**，不能跳过卷宗直接写——凭印象写人物等于把没验证过的东西往下游传。
